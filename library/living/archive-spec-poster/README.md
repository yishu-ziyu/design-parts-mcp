# archive-spec-poster — 古典图像混技术标注的四张海报

含原作素材，只留本机。

来源：[x.com/ayushsoni_io/status/2093284574243824100](https://x.com/ayushsoni_io/status/2093284574243824100)，2026-08-28。原帖是四张 1639×2048 的静态图，没有动效，所以本页也不加。插画从原帖截图裁出（`source-assets/`），代码自写，品牌名 Vorflux 换成占位名 Nomark。

## 机制逐条

- **画幅**：SVG 视口 1601×2000，文字都是真文字。
- **字**：大标题 Inter 300，字距 -2.2%；小字 JetBrains Mono 370，数字 0 借用 Inter，因为原作的 0 不带斜线。
- **骑手**：底色上压橙色窗口，紫色剪影再压窗口，剪影描一圈底色细线；窗口里的等宽字被挡掉一半。剪影按紫色连通区域抠出。
- **黄金分割**：矩形边长按比例递减，线 1.6 单位、#8a8a86。灰色等宽小字贴线放。
- **比例格**：外圆半径 482，内方 797，二进制字沿身体右对齐和左对齐。本页这组连同头像是原帖裁切图。
- **斑点色块**：橙色带白斑，再叠一层黑色点线描边。本页这块是原帖截图。
- **印章**：双椭圆，上弧等宽字，下弧无衬线字。

## 可学 / 不学

- **可学**：只用三四种颜色，古典图像做主体，技术小字只做纹理。
- **不学**：原作的插画本身。本页用的是原帖截图，只能留在本机。
