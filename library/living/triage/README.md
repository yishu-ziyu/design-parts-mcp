# triage — 批量选择 → 工具条浮现（红鲱鱼与枪内容版）

活笔记。复刻 lab01.dev UI Experiment #02（收件箱）的「勾选 → 批量操作条浮现」交互，
内容全部换成用户自己的 GitHub 项目「红鲱鱼与枪」（user-project，AI 信息核查系统）的产品词汇。

打开方式：`file://` 直开 `index.html`，无网络、无构建。
测试参数（不影响正常打开）：`?demo=checked / tooltip / all / mainclick / archive / dispatch`。

## 来源

- 源：lab01.dev UI Experiment #02（即其 experiments/04 页），原版是英文收件箱。
- 原版机制从其 `main.js` 逐行读出（本地考据拷贝在 /tmp/exp04.js / exp04.html / exp04.css）。

## 原版机制逐条记录（本页 1:1 对应实现）

| 源 main.js 函数 | 行为 | 本页对应 |
|---|---|---|
| `syncMainFromItems()` | 主复选框三态由条目勾选数推出：0 = 空、部分 = `indeterminate`、全部 = `checked` | 同名函数，逻辑逐行等价（`index.html` 脚本头有注释标明） |
| `onMainChange()` | 点主框：有任何条目勾选 → 全清；没有任何勾选 → 全选；随后 sync + 更新工具条 | 同名函数，等价 |
| `onItemChange()` | 条目勾选变化 → 重算主框三态 + 工具条可见性 | 同名函数，等价 |
| `updateEmailActionsVisibility()` | 主框或任一条目勾选 → 工具条从 `hidden` 变 `flex`；全取消 → 收回 | `updateActionsVisibility()`，改用 `.show` 类切 display |
| tooltip | 按钮的兄弟 span，`scale(.95)+opacity:0` → hover `scale(1)+1`，origin bottom，transition scale+opacity | 相同结构（`.act:hover + .tip`） |
| 视觉 | 540px 方形框、bg #F6F8FC、白卡 450×520、侧栏 248px、对比色 #202124/#868FA0、accent #E8EDF7、Geist Mono 500、18px 实心图标 | 配色与框全部保留；白卡收窄到 276 以便 540 框内可见更多内容，卡片 520 高照旧被框裁掉一点（原版同样裁） |

## 内容映射（红鲱鱼与枪）

- 侧栏导航：队列（选中）/ 争议 / 尚缺 / 待补证 / 已留存 / 归档，队列带计数（归档后递减）。
- logo：自绘鱼形 SVG 标 + 「红鲱鱼与枪」。
- 搜索框占位：「搜命题或来源」。
- 列表 = 待核查命题队列，7 行。每行 = 复选框 + 一句可核查的说法 + meta（来源域名 · 证据计数「支持2 · 反驳1 · 尚缺3」 · 可信度 0–100 或状态词）+ 状态片。
- 状态片只用：待核查 / 排查中 / 还查不清 / 争议 / 待补证。
- 批量操作条：派发核查 / 标记争议 / 归档，各带深色 tooltip。
- 命题全部是中性虚构但口吻真实的说法（咖啡/维C/蓝牙耳机/燃油车禁售/站立办公等），不用真事故真悲剧。
- 产品宪法纪律：不出现实现层词汇（Agent / provider / tool call / token / pipeline）。

## 克制的加戏（不碰核心逻辑）

- 点「归档」：被选行先量高，收到 0 并右移淡出后摘节点，侧栏队列计数同步减一。
- 点「派发核查」：被选行状态片变「排查中」+ 1.8s 呼吸脉动。
- 点「标记争议」：状态片变「争议」。
- 动作完成后全部取消勾选，回到三态起点。
- reduced-motion：动画/过渡全关，直达终态，交互逻辑不变。

## 可学

- 三态复选框是「先选后操作」列表的地基：十几行 JS，主框永远是条目的投影，不要反向维护两份状态。
- 工具条浮现的入场感来自子项错峰上升（40ms 一档），不是整条飞入。
- tooltip 用「按钮兄弟 + scale+opacity」最省事，pointer-events:none 防抖动。
- 方形框 overflow:hidden 裁掉白卡一角，是原版气质的一部分，不必把所有内容塞进去。

## 不学

- 原版列表卡 450px 宽，在 540 框里只露出一半多——那是收件箱演示的将就，真做产品信息密度会浪费。本页把卡收到 276。
- 原版 meta 一行塞 sender + preview + 时间，本页行高换成了「命题 + 来源/证据」两段式，核查场景更需要证据计数而不是时间戳。
- 原版每行一个星标（important）——核查队列里「标星」语义太弱，换成状态片更有信息量。

## 启示

- 「勾选即上下文」：操作条不占常驻空间，出现的瞬间列表自己变暗（选中行反色），用户视线不用找按钮。
- 队列类产品的侧栏本质是状态分布（队列/争议/尚缺/待补证/已留存/归档），不是功能菜单。
- 批量操作条只需要三个动作：推进（派发核查）、存疑（标记争议）、退出（归档）。

## 可拆

- `#tri-state` 三态复选框（全选/部分横线/全清）
- `#toolbar` 勾选浮现的批量操作条（含 hover tooltip、状态片脉动）
- `#tooltip` 深色 tooltip（scale+opacity 过渡）
- `#archive-collapse` 行折叠归档 + 计数递减
