# triage — 批量选择 → 工具条浮现（红鲱鱼与枪内容版）

活笔记。复刻 lab01.dev UI Experiment #02（收件箱）的「勾选 → 批量操作条浮现」交互，
内容全部换成用户自己的 GitHub 项目「红鲱鱼与枪」（user-project，AI 信息核查系统）的产品词汇。

打开方式：`file://` 直开 `index.html`，无网络、无构建。
测试参数（不影响正常打开）：`?demo=checked / all / archive / tooltip / focus / keyx / hover / copied / dispatch / mainclick`。

## v2 重做（2026-09-13）

### v1 为什么被否

v1 机制对、工艺空：白页上摊一块 540 框，字是系统 monospace 假装 Geist Mono，图标是平涂实心块，
行是「一句话 + 灰字」，没有 hover、没有来源、没有键盘。用户的原话是「很没感觉」。
根子是**栖息地和工艺密度都丢了**：原实验活在 lab01 的黑舞台上，靠的是像素级产品工艺。

### v2 改了什么

- **栖息地回来了**：整页黑底 #0A0A0A + 一格 68px 极淡网格（2.8% 白），居中 540 方框，框下 meta 一行：
  `UI EXPERIMENT · 批量选择`、`Aa Geist Mono` 字体标注、纸飞机图标 + `18px 双层` 图标标注、
  三色票 #F6F8FC / #868FA0 / #202124（点击复制，亮色 tooltip 报十六进制）、右下外链箭头。
- **字体是真的**：Geist Mono woff2（可变字重 100–900，拉丁子集）下载进 `fonts/`，@font-face 相对路径引用，
  中文回退 PingFang SC 等系统字体。file:// 打开零网络请求。
- **像素级工艺**：三态复选框 18px / 圆角 4 / 白底 + 1px ring，checked = #868FA0 灰底 + 内侧白色高光 + 描边对勾，
  indeterminate = 一横；行 = 复选框 + 来源头像点（域名首字母，颜色按域名稳定散列）+ 命题 + 两行 meta，
  hover #E8EDF7 过渡、勾选反色 #202124；操作条子项 40ms 错峰上升，内含「已选 N 项」；按钮 tooltip 走 scale+opacity 180ms。
- **键盘路径**：j/k 移焦点行（1px 深色描边）、x 切勾选、esc 清空。焦点行、鼠标点行、复选框自身走同一条 `toggleItem → refresh`，
  三态、操作条、已选计数不会分叉。搜索框里打字不吃键。
- **机制一行没改**：三态同步 / 主框全清全选 / 操作条显隐 / 归档折叠 + 计数递减 / 派发变「排查中」/ reduced-motion 直达，全是 v1 已验收的逻辑。

### 从 lab01 作者那儿查证到的手艺点

- 作者 Sebastiano Guerriero 的 Lab01 就是把作品集图片**逐像素转成活代码**——所以这里追求的也是像素级：18px 图标、
  1.5 描边、0.3 实心 + 轮廓双层，间距按源（侧栏 p-4、导航 h-9 px-3.5 gap-3、搜索 h-9.5 pl-11.5、卡片 p-4、行 h-9 px-3.5 gap-3）。
- 源用 Geist Mono + Nucleo 18px 图标；字体标注和三色票是 lab01 展台的惯例。
- 源的主框/条目复选框用 `:checked` / `:indeterminate` 双套样式：灰底 + `inset-shadow-2xs`（上缘 1px 白 20%）+ ring，
  半选画一横而不是方块。本页照这套画（自己写的形状，不抄路径数据）。
- 源的入场曲线是 `--ease-spring`（线性弹簧）+ 子项 0/50/100/150/200ms 错峰；本页取 40ms 一档。
- tooltip 用「按钮的兄弟 span + `origin-bottom` + scale .95→1 + opacity」最省事，`pointer-events:none` 防抖动。

### 与原版的取舍登记

- **复选框 18px vs 源 14px**：源是 `size-3.5`（14px 盒、横线约 5.4px）。本页做 18px（横线 9px 等比）——中文命题行高 59px，14px 框在其中过小、点击目标也偏窄；取可读与可点优先。
- **侧栏 232 vs 源 248、白卡 308 vs 源 450×520**：真 Geist Mono 加载后最宽 meta 实测 233.7px，按源宽会折两行、末行出框；取信息完整优先（源本身是右侧裁切的展示框，本页不裁）。
- **tooltip 180ms vs 源 150ms**：按契约口径实现，便于截图定格核对。
- **行 hover #E8EDF7 vs 源 3% 黑**：本页取与 accent 同族浅蓝，导航 / 选中 / hover 三层色阶更一致。

## 原版机制逐条记录（本页 1:1 对应实现）

| 源 main.js 函数 | 行为 | 本页对应 |

| `syncMainFromItems()` | 主复选框三态由条目勾选数推出：0 = 空、部分 = `indeterminate`、全部 = `checked` | 同名函数，逻辑逐行等价（`index.html` 脚本头有注释标明） |
| `onMainChange()` | 点主框：有任何条目勾选 → 全清；没有任何勾选 → 全选；随后 sync + 更新工具条 | 同名函数，等价 |

## 内容映射（红鲱鱼与枪）

- 侧栏导航：队列（选中）/ 争议 / 尚缺 / 待补证 / 已留存 / 归档，队列带计数（归档后递减）。
- logo：自绘鱼形 SVG 标 + 「红鲱鱼与枪」。
- 搜索框占位：「搜命题或来源」。
- 列表 = 待核查命题队列，7 行。每行 = 复选框 + 来源头像点 + 一句可核查的说法 + 两行 meta（域名 · 证据计数「支持2 · 反驳1 · 尚缺3」 / 可信度 0–100 或状态词 + 状态片）。
- 状态片只用：待核查 / 排查中 / 还查不清 / 争议 / 待补证。
- 批量操作条：派发核查 / 标记争议 / 归档，各带深色 tooltip，条内含「已选 N 项」。
- 命题全部是中性虚构但口吻真实的说法（咖啡/维C/蓝牙耳机/燃油车禁售/站立办公等），不用真事故真悲剧。
- 产品宪法纪律：界面与正文只讲命题、证据和状态，不出现实现层词汇。

## 键盘路径

| 键 | 做什么 | 细节 |
|---|---|---|
| `j` / `k` | 焦点行下移 / 上移 | 首次按下落在第一行；到头/到尾夹住，不会把焦点丢掉 |
| `x` | 切换焦点行的勾选 | 与鼠标点行走同一条 `toggleItem → refresh`，三态与操作条同步 |
| `esc` | 清空选择 | 焦点描边一并撤掉 |
| 点行 | 切勾选 + 焦点落到该行 | 点在复选框/按钮/链接上不重复触发 |
| 搜索框打字 | 不拦键 | 焦点在输入类元素里时键盘路径让位 |

## 克制的加戏（不碰核心逻辑）

- 点「归档」：被选行先量高，收到 0 并右移淡出后摘节点，侧栏队列计数同步减一。
- 点「派发核查」：被选行状态片变「排查中」+ 1.8s 呼吸脉动。
- 点「标记争议」：状态片变「争议」。
- 点色票：立即亮「已复制」（不等剪贴板 promise），随后按 hex 写系统剪贴板。
- 动作完成后全部取消勾选，回到三态起点。
- reduced-motion：动画/过渡全关，直达终态，交互逻辑不变。

## 可学

- 三态复选框是「先选后操作」列表的地基：十几行 JS，主框永远是条目的投影，不要反向维护两份状态。
- 工具条浮现的入场感来自子项错峰上升（40ms 一档），不是整条飞入。
- tooltip 用「按钮兄弟 + scale+opacity」最省事，pointer-events:none 防抖动。
- 方形框 overflow:hidden 裁掉白卡一角，是原版气质的一部分，不必把所有内容塞进去。
- 键盘路径不是加戏，是「真产品」的门槛：焦点行、勾选、操作条只要共用一组更新函数，键盘和鼠标就不会分叉。
- @font-face 的本地字体在 file:// 下能正常加载（Chrome 实测 status=loaded），不必为了「直开」退回系统字体。

## 不学

- 原版列表卡 450px 宽，在 540 框里只露出一半多——那是收件箱演示的将就，真做产品信息密度会浪费。本页把卡收到 308（侧栏 232）。
- 原版 meta 一行塞 sender + preview + 时间，本页换成了「命题 + 域名/证据 + 可信度或状态」三行式，核查场景更需要证据计数而不是时间戳。
- 原版每行一个星标（important）——核查队列里「标星」语义太弱，换成状态片更有信息量。

## 启示

- 「勾选即上下文」：操作条不占常驻空间，出现的瞬间列表自己变暗（选中行反色），用户视线不用找按钮。
- 队列类产品的侧栏本质是状态分布（队列/争议/尚缺/待补证/已留存/归档），不是功能菜单。
- 批量操作条只需要三个动作：推进（派发核查）、存疑（标记争议）、退出（归档）。
- 展台（黑底 + 方框 + 框下 meta）不是装饰：它把「实验」和「产品」分开，方框里的东西才被当作品看。
