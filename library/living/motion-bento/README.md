# motion-bento

未嵌入原帖截图，数值来自原帖公开的提示词和视频抽帧。

来源：枯白啃设计 @Kubai087，https://x.com/Kubai087/status/2115393082472681875 ，2026-10-28。查看日期 2026-11-05。

## 机制

- 一张 28px 圆角大卡，格子之间用 1px 网格间隙露出底色当细线，不画边框。
- 每格底部内缩 8px 放示意面板，圆角 20px，和外圈同心；面板是 #fafafa、-45° 细斜纹、1px 内环。
- 每个场景只讲一个“动作到结果”：样式写最后一帧，关键帧只写起点，所以减弱动效和中途打断都停在结果上。
- 70% 进入视口后等 200ms 播放，同批按阅读顺序相隔 250ms。
- 悬停（仅鼠标）或键盘聚焦时重播：先 160ms 模糊 6px 淡出，趁看不见时重置动画；一直悬停则播完 600ms 后再播。播放中不打断。

## 可学

场景比文字先讲清功能；一个类名驱动整格动画；所有颜色都是变量，暗色只换值。

## 不学

示意画面不要放真实文字（语言菜单是例外，原版如此）；不适合功能超过 12 个的页面，也不适合需要读细节的说明。

## 和原版的差别

Logo 换成了占位色块。场景的中间过程按视频抽帧和提示词推断，起止帧贴近原版，每步时长不是从原站量的。
