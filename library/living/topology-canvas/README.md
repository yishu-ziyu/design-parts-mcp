# topology-canvas — 架构拓扑画布

来源：[x.com/openshipio/status/2104187404533838043](https://x.com/openshipio/status/2104187404533838043)，帖子两张配图（浅色项目页、深色集群页），读取日期 2026-11-05。代码未公开，本页自写。`?view=cluster` 打开深色页。

原帖只有静态图，文字写了“点击节点可查看、重启、停止”。节点菜单的外观和拖动手感是本页推测，不是原版。

## 机制逐条

- **世界坐标：** 节点和连线放在同一层，缩放只改这一层的 scale，所以 67% 下节点文字约 9px，仍和原图一致。
- **直角路由：** 目标在右走“横竖横”；目标在左先绕到外侧，走中线回到目标左边。转角 9px（深色 13px）圆角。
- **状态：** 重启显示 1.2 秒过渡状态；停止后节点变灰，相关连线变虚线。
- **选中：** 选中节点时相关连线加深，其他不变。

## 可学 / 不学

- **可学：** 节点底色按服务类型分组，一眼能区分入口、应用和数据；连线不加标签，靠走向说明关系。
- **不学：** 节点文字只有 9px，真实产品要留可读性，小屏不能这样放。路由没有避让，拖动后可能压过节点，节点多时要换 ELK、Dagre 这类布局库。
