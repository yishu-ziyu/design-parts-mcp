#lensing
逐像素光线追踪：一个全屏三角形 + 片元着色器，从相机反向发光线，每步 vel += −1.5·h²·r/|r|⁵·dt（史瓦西光线近似，视界半径 Rs = 1），步长 clamp(.06r, .025, 1.5)，最多 130 步。r < 1 吸收；只有 r > 60 且在远离的光线才去星空取色，步数用完的也按吸收（否则视界里冒亮点）。光线穿过 y = 0 且 2.6 < r < 13 时取盘色：开普勒角速度 2.2/r^1.5，两层 fbm 叠出气体丝，朝镜头一侧乘 (1+.45·cos)^2.2，俯看机位由内到外 白 → 橙 → 暗红。收尾 1−exp(−1.15c) 色调映射 + 暗角 .28。星空哈希不用 sin（sin 会出斜条纹）。
#viewpoint
两个场景是同一个 shader 的一个 uniform sc（0 → 1）：相机距离 19 → 34、仰角 .17 → .022 rad、俯仰 .035 → −.01、地平线 −.30 → .012、盘外径 13 → 10，盘色和地面一起 mix。点 ‹ › 只改目标值，cur += (target−cur)·min(1, dt·1.4) 指数逼近（时间常数约 0.7s），看到的是相机连续移动，不是切图。左上场景名淡出 .4s，350ms 时换字再淡入。
#focal
焦距刻度：18–85mm，fov = 2·atan(12/mm)（全画幅 24mm 高），shader 里视平面半高 = tan(fov/2)。滚轮 deltaY × 0.025 mm，拖右侧竖刻度按位置映射，读数 .15s 跟过去。刻度每 3mm 一根，标 24 / 35 / 50 / 70，默认 50mm。
#scale
尺度物：第二块 2D canvas 叠在 WebGL 上，按 devicePixelRatio 满分辨率画（不跟着光追降分辨率）。俯看机位是亮窗农舍 + 皮卡，α = 1 − 1.9·sc；贴盘机位是宇航员背影 + 26 颗散景，α = (sc − .4)/.6。农舍高约画面的 1/6、皮卡 1/20，都压在地平线上，黑洞才显得大。窗光 #ffc06a + 14px 辉光；剪影坐标单位 = 画面高 / 700。
#hud
四角仪表：10px 等宽、字距 .08em、12px 角框、透明度 .55–.7，中间全留给画面。读数和 shader 吃同一组参数：ALT = 距离·sin(仰角)，HORIZON = 距离 − 1，单位 Rs；FPS、渲染比例、运行时钟实时刷新。窄于 600px 收掉说明行和左下读数。
#fps
自适应分辨率：光追画布按 CSS 尺寸的 Q 倍渲染（初值 .7），每 0.6s 量一次帧率：低于 40 且 Q > .4 时 Q − .1，高于 58 且 Q < .9 时 Q + .05。左下 FPS · Q% 就是它；每像素 130 步，普通笔记本会落到 40%–60%。

交互：底部 ‹ › 换机位；滚轮或拖右侧刻度改焦距；右上暂停 / 全屏。WebGL 不可用时只显示一行提示。
