可拆

#trace
整条 agent 轨迹：一行状态头 + 缩进的步骤列表 + 结果卡片 + 最后的回答。头行永远显示「正在做的那一步」，每步开始时把这一步的标签复制上去，旧文字 180 ms 模糊上移淡出、新文字淡入。最后整段折叠成一行灰字摘要「Ran N searches and read M sources」+ 前三个来源图标，左边橙色图标宽度收到 0，摘要左移 25px 和回答左对齐。
#shimmer
进行中的文字扫光：不是给文字上渐变色，而是给整行加 mask-image，一条 16% 宽、透明度 0.28 的带子 1.5 s 从左扫到右（mask 宽 300%）。这样行里的来源胶囊、图标也会一起被扫淡，和原作里胶囊半透明的那几帧一致。reduced-motion 下关掉。
#fold
结果卡片展开 / 收起：外层 display:grid，grid-template-rows 在 0fr 和 1fr 之间过渡 0.5 s，内层 overflow:hidden，不用量高度。最多同时开 2 张（CONFIG.keepOpen），第 3 张打开时最早那张收起，箭头转 -90°。所以列表一直往下长，但高度大致不变。
#card
卡片样式：底 #F6F6F6 放在页面 #EEEEEE 上，只亮 3%；靠三层阴影成形——1px 4.5% 黑描边、下方 2px/5px 5% 黑投影、顶边 1px 内白高光。圆角 12px，行间 1px #ECECEC。行：18px 字母方块或来源图标 + 粗体标题 + 灰色副标 + 右侧时间，下一行正文。
#answer
回答逐块出现：标题、每条要点依次 110 ms 错开，从 5px 下方、2px 模糊淡入。要点里用同一个来源胶囊做引用，和上面轨迹里的胶囊同一个组件。
