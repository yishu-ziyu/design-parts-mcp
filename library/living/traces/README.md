# traces — AI 干活时的轨迹列表：一行状态头跟着当前步骤换字，步骤一条条往下长，结果卡片开两张收一张，最后整段折成一行摘要

来源：https://x.com/dimitroweb/status/2112281659093504201 （Dimitar @dimitroweb，2026-10-20，配文 "Iterating on AI traces, so nice"，视频 1440×1080、11.8 s）。作者简介说自己是做软件细节的工程师。推文没有链接、没有代码、没有 live 页面，回复里只有夸奖和作者的道谢，没有讲做法的话。所以下面的数字全是把视频逐帧画进 canvas 截图后量出来的：位置、颜色、节奏是事实；字号按「1440 宽录屏 = 1 倍像素」换算，字体看字形推断是 Inter，这两条是推断。视频里的示例内容（几个真实 SaaS 的名字和图标、示例消息）没有搬，换成了自己写的书店晨报场景和自己画的来源图标。

## 这一页是什么

- 一个 agent 给书店店主做晨报：先「Working on it…」，然后依次搜聊天、读会议记录、搜邮箱、读退货单、读库存表，每一步出一张结果卡片，最后给出分段回答。
- 整段播放约 11 s，结束后轨迹折成一行灰字「Ran 2 searches and read 3 sources」+ 三个来源图标。点这一行能重新展开；每一步也能单独点开 / 收起卡片。
- 右下角 Replay 重播。往下滚是「可拆」。

## 实测数字（原视频，1 倍像素）

| 项 | 值 |
|----|----|
| 页面底 / 卡片底 | `#EEEEEE` / `#F5F5F5`–`#F6F6F6`（只亮 3%） |
| 卡片边 | 顶边 1px 更亮（251），底边下方 2px 变暗（231–235），左右 1px 略暗：描边 + 投影 + 顶部内高光三层 |
| 行距 | 状态头和每一步都是 30px 一行 |
| 缩进 | 状态头文字距左 25px；步骤图标中心 33px，步骤文字 51px；卡片左边和步骤文字对齐，宽约 491px |
| 竖线 | 1px，约 `#E5E5E5`，在左起约 7.5px（状态头图标正下方） |
| 卡片行 | 约 55px 一条（标题行 + 正文行），行间 1px 细线；左内边距 12px，标题从 37px 起 |
| 节奏 | 0–0.8 s 思考；步骤约 0.8 / 2.3 / 3.8 / 5.3 / 6.8 s 出现（每 1.5 s 一步）；约 8.5 s 回答开始；约 10.5 s 折成摘要 |
| 同时展开 | 最多 2 张卡片，第 3 张打开时最早那张收起 |
| 强调色 | 橙色 ≈ `#EE6A2C`（JPEG 取样，误差几级） |

## 怎么做的

- **状态头永远是当前那一步**：每一步开始时把这一步的标签（动词 + 来源胶囊 + 宾语）复制到头行。换字时旧文字 180 ms 模糊、上移 3px 淡出，再淡入新字。原作 5 s 那帧头行正好是空的，就是换字的中间。
- **扫光用 mask，不用文字渐变**：进行中的整行加 `mask-image`，一条 16% 宽、透明度 0.28 的带子每 1.5 s 从左扫到右。这样来源胶囊和里面的图标也一起被扫淡；原作 1.5 s、3.5 s 两帧里胶囊确实是半透明的，用 `background-clip:text` 做不到这一点。
- **展开 / 收起不量高度**：外层 `display:grid`，`grid-template-rows` 在 `0fr` 和 `1fr` 之间过渡 0.5 s，内层 `overflow:hidden`。
- **开两张收一张**：`keepOpen: 2`。列表一直往下长，但画面高度大致稳定，读的人眼睛不用追。
- **收尾**：所有卡片先收起 → 回答的标题和要点 110 ms 错开从 5px 下方、2px 模糊淡入 → 1 s 后整段轨迹折叠，左侧橙色图标宽度收到 0，摘要左移 25px 和回答左对齐，来源图标排在摘要后面。
- 思考时的橙色图标是 2×2 四个点按相位轮流放大变亮；之后换成当前步骤的类型图标（搜索 / 阅读），保持橙色。

## 关键判断

1. **问题**：第一版字号按 16px 写，并排一看整体大一圈，胶囊也比原作「重」。**改**：正文 15px、胶囊 13px 字 + 12px 图标、胶囊描边从 7% 降到 5%、卡片行 13.5px。**验证**：同一时刻、同一比例裁切并排（`cmp/r3-4.png`），文字基线和卡片左右边对齐到几像素以内。
2. **问题**：第一版节奏慢，1.5 s 时卡片才开始展开，9 s 时还停在第 4 步；原作 9 s 已经全部收起、回答在出现。**改**：思考 0.7 s、每步 1.5 s、卡片延迟 0.4 s、回答前 0.3 s、折叠前 1 s。**验证**：Playwright 在 0.3 / 1.5 / 3.5 / 5 / 7 / 9 / 12 s 截图，和原作同一时刻逐张对照，每一帧所处的阶段一致。
3. **问题**：扫光如果只作用在文字颜色上，胶囊不会变淡，和原作对不上。**改**：用 `mask-image` 整行扫。**验证**：1.5 s 帧里两边的胶囊都被扫到半透明。

## 和原作的差距

- 字体是推断的 Inter，原作的字可能是 SF Pro 一类系统字，小写 `a`、`t` 的细节有出入。
- 原作思考阶段的橙色图标形状在变（点阵、放大镜、像音量条的竖线），具体形状没量清；这里只做了四点呼吸和两种类型图标。
- 原作回答部分出现时可能是逐字流式；视频分辨率下看不清，这里按块淡入。
- 原作的标签换字可能是逐词替换，这里是整句模糊淡出淡入。
- 窄屏（400px）下步骤标签会折行，原作没有窄屏样子可对照。

## API / CONFIG

```js
const t = createTraces(container, {
  thinking: 'Working on it…',  // 思考阶段的头行文字
  thinkMs: 700,                 // 思考多久
  stepMs: 1500,                 // 每一步的间隔
  cardDelayMs: 400,             // 步骤出现后多久展开卡片
  keepOpen: 2,                  // 最多同时展开几张
  answerDelayMs: 300, answerStaggerMs: 110, collapseDelayMs: 1000,
  summary: (searches, reads) => `Ran ${searches} searches and read ${reads} sources`,
  sources: { id: { name, icon /* 内联 SVG */ } },
  steps: [{ kind: 'search' | 'read', verb, src, rest, rows: [{ lead, title, meta, time, text }], more }],
  answer: [{ h }, { li: ['文字', { cite: 'src', label }, { code }, { link }] }],
});
t.replay();   // 从头播
t.destroy();  // 停掉计时器、清空容器
```

`lead` 可以是 `'letter:M'`（灰色字母方块）、`'src'`（来源图标）、`'dot'`（蓝色未读点）、`'glyph:return|swap|check'` 或空。

- `prefers-reduced-motion`：不播动画，计时全部归零，直接停在最终状态（摘要 + 回答），扫光关掉；点摘要仍可展开轨迹。
- file:// 直开，运行时零网络。`fonts/inter-latin-{400,500,600}-normal.woff2` 取自 `@fontsource/inter` 5.3.0（latin 子集，OFL-1.1）。
- 验证：Playwright 拦掉所有非 `file:` 请求，1440×1080、1100×700、400×800 三种视口零请求、零控制台错误、无横向滚动，三个字重都 `loaded`。

## 可拆

- `#trace` 整条轨迹：状态头跟随当前步骤、最后折成摘要。
- `#shimmer` mask 扫光。
- `#fold` grid `0fr ↔ 1fr` 展开收起 + 最多开两张。
- `#card` 卡片三层阴影和行样式。
- `#answer` 回答逐块淡入，引用胶囊和轨迹里同一个组件。
