# thinking-process — 灰底的 AI 思考记录

来源：[@pitus_](https://x.com/pitus_/status/2109282877506777206)，复刻于 2026-11-05。

## 机制

- 一步有两句文案：进行中用现在时（Searching），完成后换成结果（Searched）。
- 整列随高度增长保持垂直居中，新行加入时整列缓慢上移。
- 主线上三种节点：实心灰点是普通步骤，空心圆是并回主线的步骤，蓝色对勾是结束。
- 走不通的路用虚线分出去，以灰字和叉号结束，不接回主线。
- 分出去的两步用实线分叉，在空心圆处并回主线。
- 进行中的文字带一条移动的浅色光带，节点外有一段旋转的圆弧。
- 结束时标题从 Thinking 3s 换成 Thought for 14s，最后一行带一句结论。

## 可学

失败的步骤不删，只调灰并标叉，让用户看到模型试过什么；分支结构让并行步骤一眼可辨。

## 不学

时间表是写死的演示，接真实模型时要由事件驱动。步骤文案和 16 秒节奏来自原视频，属于演示内容。

## 打开方式

`?t=13.2` 定格到某一秒；点标题行可折叠。字体是 Inter 可变字体（OFL），在 `fonts/`。
