# 样本网格音序器（sample-grid-sequencer）

来源：<https://x.com/_nok__/status/2103423380607406090>（@_nok__，2026-09-25）。帖子只有视频，没有外链，工具名在画面里写作 phrz。

## 机制
- 十五格样本，每格四层：文件名和时长、波形、切片轨、64 步时间线。所有格共用一根走带位置。
- 文件名和说明放一行放不下就换行，换行的格子后面整体下移 17px。视频里同一行的格子高低不齐，就是这个原因。
- 切片轨有三种样子：transient 是不等宽色块；divide 是几十上百条细竖线；overlap 是最多几层错开的条块，层数把行高撑开。random 让每格各抽一种。
- 时间线上方的数字指切片序号，挤在一起时错开成两层。走到某步，对应切片瞬间变黑。
- 64 步 = 8 秒（120 BPM 每步 0.125 秒），和视频的 position 与时间读数一致。
- new phrase 按下后不马上换，提示 release to change at loop end，等循环结束才生效。
- 左边图片随触发换切法：裁切、纵向拉丝、三列重复拉伸、分层拉伸、拼贴、三通道错位。

## 可学
数据密度极高但只用一种细等宽字和三档灰，靠黑色只标“现在正在响的”。延迟到循环结束才生效的按钮适合任何有节拍的界面。

## 不学
- 声音是程序合成的短音，首次点击后才响，不是原版采样。视频里能听什么没有核对。
- core、local 和 cc0、phrase map、close 的真实行为视频没有演示，这里只做了简单占位行为。
