# 装饰首字下沉（ornament-drop-caps）

来源：<https://x.com/foodofthegods3/status/2099784849665986731>（@foodofthegods3，2026-09-14）。帖子外链 <https://alembic.space/editor>，原站已打开，顶部工具栏、卡片和底部结构按原站核对；首字面板只在视频里出现，按视频复刻。

## 机制
- 左边写字，右边实时变成两端对齐的书页。首字母取出来单独画，占 N 行，后面整词转大写。
- 面板从上到下：开关、行数、regular 或 ornamental、四组字母、style 折叠区。style 里有 run-in small caps 和字母颜色。
- 切换字母组时，书页先模糊再变清楚，约 300ms。
- 面板压住左栏文字和书页左边，不把内容挤开。
- 选项按钮上的小图就是同一段代码用字母 A 画的。

## 字母从哪来
原站 alembic.space/editor 现在有这个面板。用 ego-browser 打开，四组 × 26 个字母逐个放大到 900px 高截图，再把黑白转成透明蒙版，放在 `source-assets/letters/`。原作者说字母来自 1510 到 1900 年的古籍，这里没有改动。颜色由 CSS 背景色决定，蒙版只管形状。

## 可学
首字下沉是一个可调组件：行数决定尺寸，颜色只改字母。小图与成品同源，不会对不上。

## 不学
- Logo 用 EB Garamond 的 a 代替。视频四周的噪点光带是录屏背景，没有复刻。
