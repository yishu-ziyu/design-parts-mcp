## 机制

- 蓝底世界里散着带白边的抠图贴纸，靠贴纸的位置和大小变化换视角；离画面中心越远越暗越糊，做出纵深。
- 点 Capture：状态栏的黑色岛向下长成取景框，整个世界连同标题被推下去 868（938 宽坐标），胶囊按钮变成快门。
- 拍照后，取景画面缩成一张卡片，出现「You just caught one:」，按钮先是半透明。约一秒后，照片虚化淡出，白边贴纸放大盖上，按钮变实。
- 点名字框键盘升起，贴纸缩小让位；输入名字后点按钮，这一屏下滑，世界从上方回来，新贴纸出现在里面。
- 点贴纸进详情：世界淡出，大字名字加没有白边的大图，下面是地点胶囊和时间。

页面用一条 21.78 秒的时间线驱动，可用 `?t=秒` 定格。默认自动播放；一有操作就改成走到下一步停住。

## 可学

- 拍照到收藏只有一条路径，贴纸在每一步都是主角。
- 取景框从灵动岛长出来，不跳页，没有离开当前世界的感觉。

## 不学

- 抠图和白边在原版里由模型或系统能力生成，这里是视频截图，不能替换成真实拍照。
- 贴纸只靠远近变化区分，没有明确的「收藏了多少」。

## 替换和没做的

- 贴纸、取景画面和照片都是原帖视频截图。标题和按钮文字沿用原帖，没有品牌标志。
- 世界视角的位置按 0.1 到 0.5 秒的抽帧测量，中间用缓动补，不是原版的物理运动。拖动是我加的简化交互。
- 没有真实相机，也没有真正的抠图。键盘只有字母和退格可用。
