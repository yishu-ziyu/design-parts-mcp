花瓣 18 · 签名 1.8s

花落，字干净。

you-find.me。不是模板，是一张灰纸，字自己站稳。

底是 #ededed。栏宽 624。正文 Inter / Noto Sans SC，15 / 24.4。英文词换成 Newsreader 斜体。节标题也是它，18，只斜不加粗到失控。

名字不是 Logo。Dancing Script 44，右边先放一层 8% 的影子，再用 clip-path 从左往右揭开。1.8 秒，cubic-bezier(0.35, 0, 0.15, 1)，晚 0.15 秒。错过了按「再写签名」。

花瓣 18 片。颜色只有那五只粉。落下 10–22 秒，左右晃 28 像素。CSS，不是 WebGL。

下次怎么用

  1. 个人页先定一张灰纸和一条 624 的栏。不要卡片。
  2. 中文用无衬线。夹进来的英文词用斜体衬线。
  3. 手写只写名字。用揭开，不要每帧重绘路径。
  4. 气氛用会落的东西，不要大背景图。
  5. 终端是另一副嗓子。要能再打开。
.page { background: #ededed; color: rgb(8, 9, 10); }
.col { width: 624px; }
.bio { font: 400 15px/24.375px Inter, "Noto Sans SC", sans-serif; }
.bio em { font-family: Newsreader, serif; font-style: italic; }
h2 { font: italic 600 18px/28px Newsreader, serif; }
/* 签名 */
.wipe { transform: scaleX(0); transform-origin: left center; transform-box: fill-box; }
.is-on .wipe { transform: scaleX(1); transition: transform 1.8s cubic-bezier(0.35, 0, 0.15, 1) .15s; }
/* 花瓣 */

  8% { opacity: 1; }
