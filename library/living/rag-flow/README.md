# rag-flow — 五阶段检索问答流程图

来源：[x.com/jeetnirnejak/status/2095507715556831429](https://x.com/jeetnirnejak/status/2095507715556831429)，取原帖 38 秒视频，读取日期 2026-11-05。原帖代码未公开，本页自写。

## 机制逐条

- **占位不跳版：** 未运行时每阶段就有一句说明和空容器（40 格向量条、3 个空圆、空进度条），运行时原位替换为数据。
- **活动阶段：** 图标填阶段色，一颗 11px 同色圆点沿竖线走向下一阶段；底栏状态文字同步换色。
- **耗时是演示值：** 真实播放约 12 秒，胶囊只显示 0 到 945 ms。Query 1400ms、Embed 1800ms、Retrieve 2200ms、Assemble 1600ms、Generate 5400ms（播放时长）。
- **流式正文：** 逐词从 #cfcfd3 淡入到正文色 320ms，块状光标跟随。
- **引用互亮：** 流到 [n] 时来源行序号打一次 900ms 光晕；悬停任一端，两端序号都显示同色光晕。

## 可学 / 不学

- **可学：** 占位和结果等高，长流程里版面不跳；同一个色相贯穿序号、分数、进度条和引用，来源关系不靠连线也能看出。
- **不学：** 不要把演示耗时当真实指标展示；真实系统要接真实计时。正文固定预留 3 行高度，答案长度不定时要改成动态高度。
