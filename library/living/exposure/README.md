# exposure：照片是章节

来源：Exposure 的故事页 https://jillrmeyers.exposure.co/niagara-falls （作者 Jill Meyers，2026-08-14）和货架页 https://travel.exposure.co/ 。2026-11-05 用已登录浏览器打开核对。

`replica.html` 是故事页全页复刻（8 个章节、39 张照片、看图层、评论区、作者卡、更多故事、页尾）；`replica-hub.html` 是货架页全页复刻（271 条故事分批加载、Publications 面板、结尾）；`index.html` 是更早的拆解笔记，保留不动。

## 机制

- 封面铺满首屏，图片从 1.08 倍落回原大，1.2s，`cubic-bezier(.22,1,.36,1)`。这个数值沿用旧笔记。
- 章节：文字 700px 窄栏（EB Garamond 18/27.36），标题大写粗字，照片占页宽 5/6，每行固定宽高比，照片 5px 白边。
- 照片滚入时上浮 10px、从 .99 放大，.5s，`cubic-bezier(.42,0,.2,.99)`。这个数值沿用旧笔记。
- 货架页：天空图 100% 宽铺在顶部并淡出成白，第一张故事压在云下面。
- 悬停：照片上移 5px，.5s `cubic-bezier(.77,.06,.12,.98)`；标题淡到 .5，.2s `cubic-bezier(.42,0,.585,1.23)`。线上计算样式里能读到这两条过渡。

- 封面压一层 50% 黑（线上计算样式）。线上还有一段底部渐变，但在图片下面，看不到，这里没做。
- 看图层：#080808 底，左右键切换，首尾不循环。
- 货架页：一大、两中、之后三列，行高固定；每批 9 条，滚到底才出现 End of Stories。

## 可学

- 文字窄、照片宽，一眼就知道照片是主角。
- 货架顶图淡成白色，让第一张卡片和背景连起来。

## 不学

- 故事页封面压暗后，标题和署名都在图上，遇到亮图要重调。

## 和原版的出入

- 正文和标题字体是商业字体 GT Walsheim、IvyPresto，这里换成 Figtree、Newsreader，大标题、JILL MEYERS 这类粗体和货架标题的字形能看出差别，单行截断的位置也有时差几个字。
- 品牌和作者名换成占位（Atelier、Mika Rivers），货架页其他作者名保留原文。Travel Stories 原站是图，这里用文字重做；Logo 和分享图标是简化图形。
- 评论区原站是第三方嵌入，这里用 HTML 重做静态样子，登录图标是纯色圆，评论者姓名和头像换成占位，不能真的评论。
- 故事页照片行在 1440 以上和原站相同。原站到 1280 宽会重新分行（三列变两列加一张整幅），这里只等比缩小，没有重新分行。
- 素材都用 ego-browser 截取：把图片按原始像素放到空白页再截，从 Display P3 转回 sRGB。照片最宽压到 2000px，货架缩略图压到 920–1100px，JPEG。货架有一条（Picturesque Spain）原站图片打不开，原站显示深色底，这里同样。
- 浏览器记着 travel.exposure.co 的 90% 缩放，截原站货架时用 1440×900、设备比 2.22 换算回 1600 宽布局。

**取材说明：**部分素材把线上图片地址放进空白页后截取，保留透明背景。部分 part.json 数值（#lightbox 留白、#shelf 提前加载距离、每批 9 条）是量出或自定的，不是原站源码。
