# stickman-wrecker — 小人把网页炸开

来源：[x.com/HugoDuprez/status/2104579137575018827](https://x.com/HugoDuprez/status/2104579137575018827)，2026-09-28；原站 [destroy.spritefusion.com](https://destroy.spritefusion.com/)。原视频 25 秒，1674×1080。机制从视频帧和原站的操作说明读出，没有读原站游戏代码。

## 机制逐条

- **字母是独立对象**：整页文字拆成单个字母。爆炸核心内的字母消失，外圈的被推开、旋转，慢慢停在半空，还能继续被炸。
- **洞里是另一个世界**：洞不是挖网页，而是盖一张固定在视口的夜景，用遮罩露出来。滚动时夜景不动，所以有纵深。
- **洞边**：抖动网点的焦边，加持续几秒的小火苗。
- **爆炸层次**：先是火球和红色圆球，再是灰色网点烟，烟停留很久，还有火星。
- **图片碎裂**：第一次被炸时裂成不规则多边形，碎片漂开，露出后面的深蓝色。
- **操作**：A/D 跑，空格跳、按住飞，S 下落，鼠标瞄准点击发射，右键手雷，1/2 换武器。文字行和图片顶边是可站立的平台，被炸穿的地方不能站。

## 可学 / 不学

- **可学**：把页面文字当物理对象，改动很小，冲击力很大。
- **可学**：用固定的背景加遮罩做洞，不用改页面结构。
- **不学**：原站的角色、武器和背景不能公开使用，这一页只留本机。正文和配图来自维基百科“Stick figure”条目（CC BY-SA 等，各图许可见维基）。
- **没做**：输入任意网址、多人联机、皮肤、其他武器和地图。

## 和原版的差距

页面版式、字母脱落、洞和碎裂并排接近，小人、火箭筒、火箭弹和夜景已换成从原站截取的素材，配图换成维基页面截图。还存在的差距：小人只有 10 个瞄准角度（向左靠水平翻转），转动会跳；站立是单帧，跑动没有腿部动画；激光时小人仍拿火箭筒，原片是另一把枪；第一张配图来自现在的维基页面，线条比视频里粗，形状也不同；火球层次和小火苗不如原片丰富；视频播放器封面取自视频帧；每次爆炸随机，帧不会完全相同；没有输入网址、联机、皮肤和其他地图。

## 素材处理

小人是在原站游戏里按住飞行、切到火箭筒后逐个角度截图再抠掉天空色得到的；夜景三层和火箭弹是原站已加载的图片放进页面遮罩层后截图；配图同样从维基页面截取。没有下载视频，也没有另外下载文件。
