# js-drawings — 四幅 JavaScript 笔法插画

来源：[x.com/kevin_t_ngo/status/2108276280286425117](https://x.com/kevin_t_ngo/status/2108276280286425117)，2026-10-08。原帖只有四张成图，配文说是模型写 JavaScript 画的，没有公开代码。页面默认显示原帖截图（`source-assets/`，3840 宽）；按钮切到按成图反推的 Canvas 重画版。

## 机制逐条

- **共同母题**：太阳或月亮、屋顶、烟囱、一扇亮窗，每幅用一种材料的笔法重画。
- **圆珠笔**（`#fans`）：无数短线组成明暗，同心圈上的小扇子离太阳越远越大，颜色从红过渡到蓝。
- **针线放射**（`#rays`）：每条光线一种纹样：排线、交叉、点列、菱形、波浪、人字。
- **黑纸粉笔**（`#moon`）：月面是几万个颗粒，外面是点列、三角团、涡旋笔触同心排列。
- **蜡笔**（`#crayon`）：沿路径撒小方块，疏密随机，模拟蜡笔颗粒；纸片用胶带拼贴。
- **画笔手抖**：所有线条都是二次曲线，中点随机偏移，线宽也随机。

## 可学 / 不学

- **可学**：密度、线宽抖动和纸面颗粒三件事，就能把程序线条变得像手画。
- **可学**：一个母题换材料重画，四幅自然成系列。
- **不学**：不要指望它和原图逐笔一样，这里的随机种子和原作无关。

## 和原版的差距

页面默认显示的就是原帖四张图（从查看大图的画面截取，重新压成 JPEG），所以默认视图和原版只差压缩。真正能学的 Canvas 重画版另有明显差距：扇子和纹样不够细，粉笔月亮的三角团和涡旋最弱，蜡笔线条偏干净；它单独看没有达到 triage 的接近程度。对比图三列依次是原版、复刻页默认视图、代码重画版。
