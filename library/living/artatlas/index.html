#collection
标题区：小号大写眉题 9px、字距 1.8px；大标题 Inter 40/50、500、字距 -1.6px；右侧大数字 44px 400 配两行 9px 小注，数字随搜索和分类实时变。全页只有一个墨色 #22241F 和一个纸色 #F7F6F2，其余灰都是这两色之间的绿灰。
#filters
搜索框 + 分类胶囊：搜索框 40px 高、底色 #EEEFE9、圆角 3px，搜名称、参考作品、描述和标签。胶囊 12px、padding 9/13、圆角 3px，选中态墨底纸字。窄屏胶囊行自己横向滚动，页面不横滚。
#grid
卡片系统：三列，列距 28px，图 16:10，底色 #E8E8E1 先占位。hover 时图 scale(1.035) 0.5s、右侧箭头淡入并从 -6px 滑回；文字三层 9px 分类 / 19px 标题 / 11px 参考作品。缩略图都是 canvas 程序画的，一种风格一个画法函数。
#detail
详情页：同一页内用 hash 路由（#style/<id>）切换，不刷新。左标题右描述，大图占 76% 宽、图注两端对齐；「看哪几点」四栏；一段可复制的美术方向提示词；「这一风格的作品」两列参考卡，复用同一个画法函数换种子。直接打开 #detail 会进第一条。
