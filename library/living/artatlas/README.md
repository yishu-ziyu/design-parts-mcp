# artatlas — 风格图鉴站：16:10 卡片网格 + 搜索和分类胶囊 + 同页详情，缩略图全部用 canvas 程序画

来源：https://x.com/onefifthblue/status/2112372790313799799 （五分之1蓝 @onefifthblue，2026-10-20）。推文原话大意：用 AI 做游戏时要先定美术风格，所以做了一个网站，收集很多游戏的美术风格和参考游戏，可以直接把风格名或风格参考发给 AI。推文链到线上站 gameartstyle.loopyhop.com（标题「Game Art Style — A visual atlas of games」）。站点公开可访问，下面的字号、颜色、圆角、hover 放大倍数和过渡时长都是在 Chrome 里用 `getComputedStyle` 读出来的（视口 1650×992），是事实。没找到源码仓库，也没找到作者讲做法的文字；列距、详情页各段间距是从截图量的，属于推断。原站用真实游戏截图和真实游戏名，这里一张都没用：14 条风格、名称、描述、参考作品（作品名和工作室都是虚构的）、提示词都是自己写的，缩略图是 14 个 canvas 画法函数。

## 这一页是什么

- 首页：顶栏（自画 logo + 两个链接 + 一个描边按钮）→ 眉题 / 大标题 / 一行导语，右侧大数字计数 → 搜索框 + 分类胶囊 → 一行元信息 → 三列卡片网格。
- 卡片：16:10 缩略图，下面三层字（分类 / 标题 / 参考作品）。hover 时图放大 1.035、标题右侧出现箭头。
- 点卡片进同页详情（hash 路由 `#style/<id>`）：返回链接、标题与描述左右分栏、大图（16:9，占 76% 宽）+ 图注、「What to look for」四栏、一段可复制的美术方向提示词、「Titles in this look」两列参考卡。
- 搜索和分类实时过滤，右上角数字和「x of 14 looks」跟着变；搜不到时显示一行空状态。

## 做法

- 内容全在 `CONFIG.styles`：每条有 `id / name / cat / paint / desc / look[3] / games[[作品, 工作室]…]`。`paint` 指向 `PAINTERS` 里的一个画法函数。
- 缩略图：每张卡建一个 640×400 逻辑尺寸的 canvas（按 DPR 最多 2 倍），用 `id + 变体号` 做种子的伪随机数画，所以同一条风格每次画出来一样；详情页的参考卡用同一个函数换变体号（换色相、换太阳位置等），像同一风格下的不同作品。
- 像素类（16 色、1-bit 抖动）先画在 96×60 / 160×100 的小画布上，再关掉平滑放大，像素格是真的。1-bit 用 4×4 Bayer 矩阵。
- 卡片 hover 只动 canvas 的 `transform`，外层 `.thumb` `overflow: hidden` 裁掉放大出来的边。canvas 首次出现从 opacity 0 淡入（对应原站图片加载完淡入）。
- 过滤：每张卡预先拼一个小写的搜索串（名称、分类、描述、看点、作品、工作室），输入时 `includes` 匹配，再和当前分类取交集。
- 详情：同页 hash 路由，不刷新；`#detail` 直接打开第一条，方便从「可拆」跳过去。
- `prefers-reduced-motion`：关掉 hover 放大、箭头滑入和胶囊过渡。
- 窄屏：≤980px 两列、工具行竖排；≤640px 一列，胶囊行自己横向滚动，页面不横滚。

## 几个关键判断

1. 计数块的对齐。问题：第一版右侧大数字贴着标题区底边，比原站低了约 20px，一眼看上去头部是歪的。改：`.head` 从 `align-items: flex-end` 改成 `center`，数字和大标题同一条水平线。验证：同为 1650 宽的左右对比图，数字中心和标题中心对齐，和原站一致。
2. 详情大图不是 16:10。问题：首页卡片是 16:10，第一版详情大图沿用了它，对比时明显比原站高一截。量原站截图：661×371，约 1.78，即 16:9。改：详情图单独设 `aspect-ratio: 16/9`。验证：重出对比图，图底和图注位置与原站对齐。
3. 提示词框的字。问题：原站提示词正文是衬线体（看上去是回退到 Times），眉题是无衬线小号大写；第一版选择器写成 `.prompt p`，把眉题也变成了衬线。改：正文单独一个类 `.prompt-text`（Georgia 14px / 1.85），眉题保持 Inter 9px。验证：对比图里两者字形分开了，正文行距和原站接近。

## 和原作的差距

- 最大的差距是图本身：原站是真实游戏截图，信息密度高；这里是程序画的示意图，能说明风格特征，但远没有截图丰富。
- 原站有多语言切换、「Share on X」、关于页，这里都没做，只保留顶栏的位置和样式。
- 详情页「What to look for」以下各段的间距是从一张 0.6 倍截图量的，误差可能有 ±6px。
- 400px 宽时原站的样子没截到（共享浏览器不能改窗口大小），窄屏布局是按同类站点的常见做法推断的。
- 复制按钮用 `navigator.clipboard`，在 file:// 下部分浏览器会拒绝，此时静默不提示。

## 接入（file:// 直开，运行时零网络）

- 字体：`fonts/inter-latin-{400,500,600}-normal.woff2`，取自 `@fontsource/inter@5.3.0`（latin 子集，OFL-1.1），与库里其他条目同一份文件。
- 没有外部脚本、没有构建。
- 验证：Playwright 拦掉所有非 `file:` 请求打开，零外部请求、零控制台错误；1650 / 1100 / 400 三个宽度 `scrollWidth == innerWidth`；搜索「grid」剩 4 张卡；`#detail` 能直接进详情。

```js
const atlas = createArtAtlas(containerEl, {
  title: "…", styles: [ /* 同 CONFIG.styles 结构 */ ], categories: [ … ]
});
atlas.filter("ink");   // 切分类
atlas.search("pixel"); // 搜索
atlas.open("noir");    // 打开详情（写 hash）
atlas.close();
atlas.destroy();
```

新增风格：在 `CONFIG.styles` 里加一条，`paint` 选已有画法或在 `PAINTERS` 里加一个 `(ctx, w, h, rnd, variant) => {}`。

## 可拆

- `#collection` 标题区：眉题、40px 大标题、右侧实时计数。
- `#filters` 搜索框 + 分类胶囊，窄屏胶囊行内滚动。
- `#grid` 16:10 卡片、hover 1.035 放大 + 箭头、三层字。
- `#detail` 同页详情：左右分栏头、16:9 大图、四栏看点、提示词框、两列参考卡。

## 启示

图鉴类站点的骨架很少：一种卡片、一种比例、两级灰字、一个选中态。把这几样定死，内容换成什么（游戏风格、字体、配色）都能直接套。
