# flagring — 一圈旗子慢慢转

来源：[x.com/60fpsdesign/status/2109604725880762373](https://x.com/60fpsdesign/status/2109604725880762373)，2026-10-12，Plasma 的界面。原帖 8.9s，2160×2160。旗帜和代码自绘自写。

## 机制逐条

- **轨道**：七枚圆徽章放在扁椭圆上，水平半径 88px，垂直半径 22px，徽章直径 78px，匀速。
- **深度**：前大后小（0.62→1.08），后面模糊（2.6px→0），层级跟深度。
- **自转**：徽章随角度倾斜 ±18°，所以不像在平移。
- **节奏**：转一格约 1.27s，原帖 7 枚转一圈约 8.9s。
- **质感**：徽章上有高光和底部暗角，细描边，软阴影。

## 可学 / 不学

- **可学**：用缩放、模糊和层级三个数做空间感，不用 3D。
- **不学**：Plasma 的品牌和文案。
