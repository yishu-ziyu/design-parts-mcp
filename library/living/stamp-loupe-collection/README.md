# stamp-loupe-collection — 笔记本上的邮票和放大镜

来源：[x.com/Heylaosan/status/2094334090657046996](https://x.com/Heylaosan/status/2094334090657046996)，2026-08-31；原站 [marijanapav.com/stamps](https://marijanapav.com/stamps)（Marijana Pavlinić）。公开仓库 buka-studio/www-marijanapav 没有许可证，只读了数值和做法，代码自写。邮票图、手写字和空状态图从原站截取，放在 `source-assets/`。

## 机制逐条

- **版面**：1495×962 舞台。左页 680px 放标题和说明，右页 32px 网格，中间 7 个打孔，右侧四个索引页签。
- **邮票**：30 张从原站截取，带透明通道（同一张图分别在黑底和白底上截，算出透明度）。列表和选中态用原站图集那一版（3 倍），放大镜取样用原站的大图（约 5 倍）。落位用 900ms 弹簧曲线，打乱时角度 ±35°。位置、角度和资料表来自原站的一次真实排布。
- **拖动**：取最近 8 个位置算速度，乘 260ms 得到惯性距离。
- **选中**：其余邮票模糊 12px、透明度 0.6，选中那张回正并放大到 1.5 倍（原站实测），左页换成资料表。
- **放大镜**：外圈 400px、镜片 300px。179 根刻度，每 5 根一根长的。拖外圈改倍率，拖镜片移动。
- **镜片**：WebGL 取样，中心放大 1.62 倍，往边缘按半径的 2 次和 8 次方向外压缩，红蓝通道在边缘分开形成色散。这组系数是对着原站截图调的，不是原站的公式。

## 可学 / 不学

- **可学**：选中时让背景失焦，只留一件东西；工具贴着对象出现；用真实折射而不是缩放图片做放大。
- **不学**：原作者的邮票图案和文案里的个人信息不能公开使用，这一页只留本机。

## 和原版的差距

邮票、手写字、空状态图都是原站截取，版面和一次真实排布并排基本重合。还存在的差距：镜片折射是按截图拟合的公式，边缘的线条形状和色散与原站不完全一样；空状态的手写字是定格图，没有原站的逐笔写出动画；品牌和署名是占位（archive、NOTEBOOK、放大镜铭文）；抖动组与原站一样锁定；每次排布原站是随机的，这里默认固定成截取那一次。大图是把原站已加载的图片放进页面遮罩层后截图取得，没有另外下载文件。

**取材说明：**部分素材是把页面图片按地址重新载入后截取的。
