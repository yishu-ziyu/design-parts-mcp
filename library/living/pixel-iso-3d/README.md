# pixel-iso-3d

来源：https://x.com/WrongNebula/status/2020704646474703235（@WrongNebula，2026-02-09，同串上一条的三张图），复刻于 2026-11-05。

原帖只有三张静图，没有视频也没有可打开的页面。默认视图对应第一张，`?view=map` 对应第二张，`?view=terrain` 对应第三张。

## 机制
- 场景渲染到小尺寸目标后最近邻放大。
- 用深度和法线差画边缘，来自 three.js 的 webgl_postprocessing_pixel 示例。
- 等距正交相机，模型贴合网格。
- 地形：map 和 terrain 视图的格子类型、丘陵台阶带和树的位置，是脚本从原图取色得到的；REGENERATE 后才切换为噪声生成，这时没有 V 形台阶。
- 丘陵台阶：比较原图每条格边的亮度，偏暗的边在朝向镜头的一侧画深色带；terrain 的树按原图深褐色树影定位，没有明显树影的树会漏掉。
- 这些滑块和按钮都连着真实参数；`prefers-reduced-motion` 时不推进年份。

## 可学
- 只靠后处理和低分辨率，就把简单模型变成统一的像素风。
- 把着色器参数做成面板放在界面里。

## 不学
- 工具条的 emoji 在不同系统上外观不同，正式产品要换成自己的图标。
- 模拟逻辑（人口、资源）这里只是占位，原帖没有可以核对的玩法。

原作名 KEMET 换成占位 OASIS。默认视图的树影是手放的色块，不是实时阴影。
