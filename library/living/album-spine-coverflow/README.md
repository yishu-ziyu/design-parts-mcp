# 立体书脊墙

来源：Marvix @nanshanjukr https://x.com/nanshanjukr/status/2070509256625795153
复刻日期：2026-11-05

## 机制
- 只有一个数字 X 决定所有书的位置，环形取模。
- 相机到封面的距离等于封面边长（864px），封面转 88.2 度。这组数是从静止帧反算的：封面上边缘都收向灭点 (712.5, 540)，中间那本的远端缩到一半。
- 书脊在 z=0，不受透视缩放，所以书距在屏幕上严格等距（133.4px）。
- 过了中线，同一张封面换到书脊另一侧：左半边看到封面左边，右半边看到封面右边。
- 折点跟着滚动速度滞后，停下回到中线。
- 流程：书墙 → 封面转正飞到青色专辑页 → 黑底页滑入并逐步显影 → 蓝色专辑页和翻页条。

## 可学
用很近的相机和接近 90 度的转角表达“墙”；只用一个数字驱动整个列表。

## 不学
不要把封面、人物照和曲目图用到公开页面，它们是原作和原帖的内容。

## 素材说明
source-assets/ 全部来自原帖视频暂停帧：
- 封面是按上述几何把画面反投影成正面图得到的。视频里没露出来的部分用最近一列像素横向拉伸填充，所以拖到别的位置时，部分封面会出现拉丝。
- 书脊、状态栏、迷你条、青色页、蓝色页、四块面板和缩略图是直接裁切的，所以曲目文字不能选中或修改。
- 帖子里只演示了 Mission 这一张专辑，点任何一本书都会进这张专辑。

字体：页面文字几乎都在截图里，迷你条滚动标题用系统字体。

演示入口：`?demo=teal`、`?demo=album`、`?demo=turn&sx=-180`、`?demo=turn2`、`?demo=load&i=2`。

**取材说明：**封面由透视画面反推，拖动后两侧部分内容是镜像填充；专辑名保留视频里的 MANGO JUMP。
