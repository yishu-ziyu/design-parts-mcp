#gallery
无尽画布：每 3×3 格是一块，9 个产品按「起点 = (bx·s₁ + by·s₂) mod N」轮着取，s₁、s₂ 取和 N 互质的步长（9 和 0.618·N 附近），相邻两块不会出现同一排列。格子是正方形：桌面 4×136/300 = 1.813 倍放大后 544×544，产品框 417×334，标题 17px 斜体在格顶 395px，下面 13px 一句话、15px 300 字重的「品牌 / 价格」。窄屏（< 700px）314×377，只留标题和一句话。所有产品按「可见轮廓框面积 = 产品框面积 × 64%」统一缩放，长条的东西不会显得更大。拖动 / 滚轮 / 方向键平移，松手按 0.95 每帧衰减滑行。
#lens
整页先画到一张离屏 2D canvas，再交给一个 WebGL 片元着色器只弯四条边：左右各 min(7%, 110px)、上下各 min(10%, 90px)。带内坐标 t − 0.5·c·t² 压缩（静止 c = 0.6，拖得越快越接近 0.97），越靠边越被拉高 / 拉宽 20%；RGB 三通道错开 0.09 做色散，7 次采样做拖尾，有内容的地方叠一层随位置和时间变的彩虹油膜。最外沿一条 4.5px 的彩虹细线 + 34px 光晕，颜色 20 s 绕边一圈；鼠标进到离边 150px 内，边线朝光标鼓出一个 46px 的软包，跟随系数 0.14。悬停产品时，用产品透明通道往外扩三层（2/36、4/18、2/6px 模糊）做一圈光，颜色是锥形渐变，24 s 转一圈，260ms 淡入。
#dock
四角浮着的玻璃药丸：rgba(255,255,255,.52) + blur(20px) saturate(180%) + 顶部 1px 白内描边 + 极淡阴影。左下「Filter」展开 340px 宽的面板（罗马数字编号的功能多选、类型、排序），中间「Search」展开成搜索框，匹配项一条条玻璃条叠在上方（最多露 4 条，按条吸附滚动，每过一条一声短促的咔哒），右下音效开关。一旦有筛选，画布从无尽平铺变成居中的有限网格，平移有边界，切换时整页 520ms 从下方 10px 淡入。
#focus
点产品：画布 380ms 淡成白，产品图从格子里的位置 FLIP 放大到页中（680ms，cubic-bezier(.2,.75,.15,1)），标题 32px、价格 28px、正文 17px/1.85 从下方 10px 升起（300ms 后），相关设备列表每行再晚 45ms；相关度是标签的 Jaccard 系数，当前行下面一条 1px 彩虹线。关闭时反向 520ms 飞回原格子。
#index
「All Devices」：同一套数据的列表视图，70×62 缩略图 + 20px 标题 + 一句说明 + 品牌 + 价格，行高 16px 上下留白、1px 分隔线。顶部同样漏进一片彩虹光，不画整条色带。
#intro
原推视频的开场（现网站上没有这一段）：先只有一台设备在中间，其余设备按 n(t) = 2·e^(1.95(t−1)) 越来越快地从屏幕外减速飞进来（每台 0.32 s），排成一个实心球（体积内均匀分布、由内向外），镜头同时拉远：缩放 = (0.2 + 0.84·e^(−0.689(t−1)))·视口高，用视频 1.0 / 2.4 / 3.6 s 三帧拟合。3.7 s 后球越转越快、压扁；4.2 s 镜头穿进去，1 s 里每个可见格位认领一台同款设备飞过去，网格从 0.45 倍长到 1，其余设备从身边掠过、淡出，后半段透镜和边线才出现；5.25 s 四角浮层淡入。点按、滚轮、任意键跳过；减少动态时不播。
#sound
光标靠近边缘时弹一小段竖琴：C 大调五声音阶（C4–C6），沿边位置决定音高（左边、下边低），左右声道跟着光标；第一次靠近弹 3 个音的短句（间隔 0.17 s），沿边滑动超过 7% 再弹单音。原作用竖琴采样，这里用 Karplus–Strong 合成同样的拨弦，加一个 3.2 s 的合成混响，不加载任何音频文件。
#config
内容全在页内一段 JSON：每个设备 name / brand / category / line / price / tags / about / links / repos / visual。visual.draw 指向页内的 SVG 绘制函数（16 台虚构设备都是代码画的）；换成真照片只要写 visual.src（透明 PNG / WebP），可选 visual.bounds 给出主体框，不给就按透明通道自动裁。
