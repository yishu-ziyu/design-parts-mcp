# devicegallery — 一张拖不到头的产品画布，四条边像透镜一样弯，悬停时产品外面亮一圈会转的彩虹光

来源：

- 原帖 https://x.com/openmys/status/2112965771412521039 （JosephZhou @openmys，深圳的 AI 硬件创业者，2026-10-22，视频 25.8 s，1280×720）。他在帖下回复里给了站点，又补了一条：给 Agent 用的精简数据版 https://josephzhou.me/ai/agent （他说从 89,000 token 压到 5,800）。
- 站点 https://josephzhou.me/ai/ （标题 AI HardWare，129 台设备）。没有公开仓库：他的 GitHub（JosssphZhou）里有 3DS、cinetty、groki-bot 等项目，没有这个站。
- 下面的版式、透镜、动效数值是**从站点公开的 `styles.css` 和 `assets/perf-20261022/app-*.js` 里读出来的**（事实），再在 Chrome 里用站点自带的只读调试对象 `window.__gadgetsDebug` 核对了 1100×700、1650×992、400×820 三种宽度下每格的实际坐标。
- 设备数据本身不是他原创的：`projects.json` 里写着 `catalog.source = buildinpublic.com/gadgets`（2026-08-21 抓取），产品名、图片、顺序、价格都来自 Build in Public 的 Gadgets 页；他加的是画布界面、中英文、淘宝链接、仓库链接和语音能力标签（事实，来自数据文件）。
- 画布界面也有更早的底子：CSS 注释写着「Porto Rocha-shaped」的玻璃药丸，JS 注释说「Match the upstream nine products per square block」，并保留了一整套给作品集用的程序化封面（乐谱、字形、像素、波浪……）。所以它是从一个作品集画布模板改过来的（推断，上游是谁没找到）。
- 视频开头 0–5 s 那段「设备一台台飞进来聚成一个球、镜头穿过去落到网格上」**在现在的网站上没有**，站点代码里也没有对应逻辑；这一段是按视频逐帧量的，属于推断复原。

调性一句话：白底、细斜体衬线、玻璃药丸都退到角落，只让产品照片浮在格子里；动的东西只有三样——四条边的透镜、悬停的彩虹光、贴边时边线朝鼠标鼓出来的一包，全都是「光」，不是 UI。

打开 [index.html](index.html)。第一次打开先播约 5.3 s 的开场（点一下、滚一下或按任意键跳过）；拖、滚轮、方向键都能移动；鼠标贴近四边听竖琴；点任何设备进详情。

## 这一页是什么

- 一张无尽画布：16 台**虚构**设备（Lumo Dial、Cubit、Quill Badge……全部用 SVG 在页内画出来），按 3×3 一块重复铺满，往哪拖都拖不到头。
- 左下 Filter（功能多选 + 类型 + 排序）、中间 Search（输入时匹配项一条条浮在搜索框上面）、右下 Sound；右上 All Devices 列表和中文 / EN。
- 点设备：画布淡成白，产品从格子里放大到页中，下面是价格、介绍、品牌、芯片、链接、代码仓库、相关设备。
- 产品名、品牌、文案、站点名 Gadget Atlas、链接（都指向 example.com）都是自己写的；没有用原作的任何品牌、图标、文案、设备清单和照片。

## 字体

- 原站把字体登记成 `"Cormorant UI"`，文件是 Google Fonts 的 `co3bmX5slCNuHLi8bLeY9MK7whWMhyjYqXtK…`（正体可变 300–400）和 `co3smX5slC…`（斜体 400）。用 canvas `measureText` 在 100px 对比：原站 300 / 400 / 斜体 = 1873.10 / 1877.30 / 1756.50，本页用 Cormorant Garamond 得 1873.10 / 1877.20 / 1756.50，`g` 宽 44.54 对 44.50，而 Cormorant（非 Garamond）的 `g` 是 43.30——所以是 **Cormorant Garamond**。
- 数字是 `lnum` + `tnum`：写在 `@font-face` 的 `font-feature-settings` 里，canvas 画字也生效（原站数字 0 宽 49.1，等宽齐线；不开时是 47.7 的旧式数字）。
- 中文落到 Songti SC / Noto Serif SC；语言切换单独用 Georgia 14px。

## 怎么做的 + 三个判断

1. **透镜放在画布之后，不放在 DOM 上。** 问题：要弯的是一整片可无限拖动的内容，CSS 的 `backdrop-filter` 只能模糊不能扭曲，每格一个 DOM 也扛不住每帧重排。做法：照原作，每次变化把可见格子画进一张离屏 2D canvas，上传成纹理，一个片元着色器只改四条边；点选时用同一个公式把鼠标坐标换回画布坐标。验证：1100×700 下每格坐标、产品框、标题位置和原站调试对象给出的数字完全一致；悬停光、贴边鼓包和原站截图并排对过。
2. **产品按「可见面积」统一，不按框统一。** 问题：代码画的设备和照片的留白不一样，直接塞进 417×334 的框，圆的显得小、长条的显得大。做法：先按透明通道裁出主体框，再让主体框面积 = 产品框 × 64%；同一张透明通道还给悬停光和命中判断用。验证：并排图里每格的视觉分量和原作接近；换成任意带留白的 PNG 也会自动居中。
3. **开场的球是实心的，镜头是先拉远后穿入。** 问题：第一版按球面均匀分布 + 指数拉远，视频 2.4 s 时原作还是一小团，本页已经散成一圈，3.6 s 球边比中间密。做法：改成体积内均匀分布、由内向外飞入，缩放曲线用三帧重新拟合；穿入时网格从 0.45 倍长到 1，和 4.85 s 那帧的 0.68 倍对上。验证：在和录屏同比例的 1940×1091 视口里逐帧并排对了 6 轮（`cmp/` 里 r1–r6）。

## 和原作的差距

- **最大的差距是产品图**：原作是 129 张高清产品照，光影、材质、反光都是真的；这里是 16 台 SVG 设备，层次少、偏卡通，开场里同一款重复约 7 次。换成真照片（`visual.src`）后这一条就不成立。
- 开场是从视频帧反推的，网站上没有这段代码；飞入方向、旋转、穿入的节奏都是近似值。
- 竖琴是合成的，音色比采样干。
- 没有社区计数、淘宝价、多图切换、Agent 用的数据端点。
- 用 file:// 打开并换成本地真照片时，Chrome 会把画布标成跨域，WebGL 上传失败，页面自动退回不弯边的 2D 画布；要透镜效果请用 http(s) 打开。
- 语言切换用 Georgia，Linux 上没有这个字体会退成别的衬线。

## API 与 CONFIG

```js
const g = createDeviceGallery(container, {
  title: 'Gadget Atlas',          // 开场小字、详情左上角
  items: [...],                   // 见下
  vocab: { wifi: { en: 'Wi-Fi', zh: 'Wi-Fi' }, ... }, // 功能标签，顺序 = 筛选面板顺序
  lang: 'en',                     // 'en' | 'zh'
  intro: true,                    // 开场；减少动态时自动跳过
  sound: true,                    // 竖琴默认开（第一次点按后才发声）
  hash: true,                     // 打开设备时写 #device=<id>，可直接分享
  navLinks: [{ icon: 'notes', label: '可拆', href: '#notes' }],
  lens: { strength: 0.6, rim: 0.5 }, // 可覆盖任意透镜参数
  heroMaxPx: 900                  // 矢量图在详情里的最大边长
});
g.setItems(items);  // 换数据
g.open('lumo-dial'); g.close(); g.skipIntro(); g.destroy();
```

每个设备：

```json
{ "id": "lumo-dial", "name": "Lumo Dial", "brand": "Pinecone Works", "category": "Dial",
  "line": "Round touch knob", "price": 32, "chip": "ESP32-S3",
  "tags": ["wifi", "touchscreen", "recommended"],
  "about": "…", "zh": { "name": "…", "line": "…", "about": "…" },
  "links": [{ "label": "Website", "url": "https://…" }],
  "repos": [{ "name": "org/repo", "url": "https://…", "note": "…" }],
  "visual": { "draw": "dial", "color": "#f08a24" } }
```

`visual` 二选一：`{ "draw": "<页内绘制函数名>" }`（dial / robot / badge / keys / pager / puck / cam / board / panel / clock / watch / glasses / stick / arcade / rover / pebble），或 `{ "src": "photos/x.png", "bounds": [x, y, w, h] }`（`bounds` 是主体框占图片的比例，可省）。`recommended` 标签会在详情标题旁显示「Recommended」。

测试钩子：`window.__dg.debug`（`layout`、`canvas`、`lens`、`hover(x,y)`、`pull(x,y)`、`holdEnergy(v)`、`seekIntro(秒, 冻结)`、`home()`）。

## 接入（file:// 直开，运行时零网络）

- `fonts/cormorant-garamond-latin-wght-normal.woff2`、`fonts/cormorant-garamond-latin-wght-italic.woff2` 取自 `@fontsource-variable/cormorant-garamond` 5.3.0（latin 子集，OFL-1.1），`@font-face` 相对路径 + `unicode-range` + `font-feature-settings: "lnum" 1, "tnum" 1`。

## 启示

一个目录站要让人愿意多看几眼，靠的不是更多卡片，而是让「看」这个动作本身有手感：内容只占画面中间，边缘留给一层会对速度和鼠标起反应的光。UI 退到四角，产品就是界面。
