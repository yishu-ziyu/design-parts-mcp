PageFlow for macOS

PageFlow is a lightweight, minimalistic native macOS PDF viewer built with Swift and PDFKit. PageFlow launches instantly, and ships only the essentials: highlight, underline, bookmark, and comment. All tools stay invisible until you need them. Everything stays on your Mac locally, no telemetry, no network calls.

工具栏藏着 · 150ms

工具藏在纸上。

pageflow.pinchen.me。落地页就是阅读器。工具栏先不在。

底是 #fefefe。下面那扇窗 max-width: 64rem，高 420，圆角 24，边 #e5e7eb。纸比窗略大，scale(1.06)。字是 #1f3a5a，16 / 1.625。要强调的词自己下划线。荧光笔是 #ffe600a6，书签 #e6e9ee，批注 #d3d7de。外扩 2 像素，圆角 6。

鼠标放上去，灰带 150ms 褪掉。玻璃条长出来：红绿灯 #f85b5b / #f4c542 / #4cc44c，标签，放大镜，下划线，荧光笔。条子本身是 rgba(244,246,250,.66)，blur(24px) saturate(150%)。内沿一条白，底下一条软影子。不是另开一层 App 截图。

下次怎么用

  1. 阅读器、批注工具，落地页先放一张纸，不要先放工具栏。
  2. 顶上留一条会消失的提示。真正的窗框用玻璃条，高度 28，不要厚。
  3. 功能词就在正文里画出来。荧光笔、下划线、书签用不同底，不要另开图例。
  4. 显隐 150ms 就够。再快会闪，再慢就不像系统。
  5. 要能再藏、再长出。只写在说明书里不算。
.win { height: 420px; border: 1px solid #e5e7eb; border-radius: 24px; }
.hint { transition: opacity 150ms ease-in-out; }
.chrome { opacity: 0; transition: opacity 150ms ease-in-out; }
.win.is-on .hint { opacity: 0; }
.win.is-on .chrome { opacity: 1; }
.pill {
  height: 28px;
  background: rgba(244,246,250,.66);
  backdrop-filter: blur(24px) saturate(150%);
}
.hi { background: #ffe600a6; box-shadow: 0 0 0 2px #ffe600a6; border-radius: 6px; }
