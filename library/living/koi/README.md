# koi — 粒子动物海报：几千个水彩色点从一张底图取色，三张同一版式

来源：Oriku（[@Oriku175](https://x.com/Oriku175/status/2113603374470013133)，交互和界面设计师，Behance：orikustudio），帖子原文 “playing around with particles and colors.”。原帖只有三张图，没有代码、没有过程说明，也没找到教程。复刻程度：点形、疏密、纸纹、版式照原作实测；三只动物的底图按原作姿势自己画；文案自己写。

调性一句话：一张暖白纸上，动物由一千多个半透明色点拼成，颜色跟着动物本身的花纹走，每张只有一个主色。

## 这一页是什么

- 三张 4:5 海报并排：锦鲤（蓝 + 橙）、海龟（青 + 橙）、蜥蜴（绿 + 桃色），同一套版式。
- 每只动物是几千个花瓣形水彩色点：脊背大而密，鳍尖小而稀，边缘往外晕开。锦鲤约 1700 个点，标题里的「一千多个点」是实时点数。
- 动物外面是主色细线连起来的标注框，每个标注点带两行标签；四角有很虚的主色色块。
- 鼠标在画上划过，点被推开再弹回；「重新聚拢」把点撒开再飞回；可以把第一张换成自己的图。
- 页尾「可拆」6 条：`#series` `#sample` `#dot` `#callouts` `#scatter` `#upload`。

## 原作

三张海报（原图 1639 × 2048）：

| | 主色 | 标题 |
|---|---|---|
| 锦鲤 | 蓝 + 橙 | “Nature Informs Better **Solutions**” |
| 海龟 | 青 + 橙 | “A Deeper View of Individual **Health**” |
| 蜥蜴 | 绿 + 桃色 | “Biology Builds a Brighter **Tomorrow**” |

- 版式：左上两行大标题，细的无衬线字体，只有一个词用主色。动物外面有四个标注点，用主色细线连成四边形；每个点旁边是一行等宽字体的编号（例如 NEXUS-03 / RESEARCH PROTOCOL）和一行灰色小字。底部左右各一行小字。四角各有一块很虚的主色色块。
- 点：放大到原图分辨率（3277 × 4096）看，每个点是一朵五六个圆瓣的小花形色块，形状各不相同；半透明，边缘比中间略深，像水彩干了以后的边；重叠的地方颜色变深。脊背上的点又大又密，鳍尖的点小而稀。
- 纸：不是纯色，有一层很淡的白色斑驳纹理。
- 锦鲤背上那条深蓝和鳍上的橙色，位置和真实锦鲤的花纹对得上。

## 作者与方法

事实：

- Oriku 的个人介绍写的是「让产品感觉是活的：动效、质感、大多数人会跳过的细节」。
- 他之前发过一个小实验：粒子被鼠标推散，松开后聚回原位。
- 原帖只有三张图，没有代码、没有过程说明。

推断：三张海报是同一套粒子系统导出的静帧；点的颜色是从一张带花纹的动物图上采样的，证据是花纹位置和真实动物一致。

未知：底图是照片还是手绘、点的形状是贴图还是程序生成，都没有公开。

## 参数

取点（海报坐标 800 × 1000）：

| 海报 | D0（满尺寸所需离边距离） | 点半径 rMin–rMax | 间距系数 gap | 点形 | 主色（标题词） | 标注色 |
|------|------|------|------|------|------|------|
| 锦鲤 | 38 | 3–12 | 0.45 | blob | `#2b9cf0` | `#0a6cf5` |
| 海龟 | 40 | 3–11 | 0.50 | blob | `#ec7a2c` | `#ec7a2c`，小点 `#2f6fe0` |
| 蜥蜴 | 18 | 3.4–12 | 0.42 | leaf | `#5cbf3a` | `#69c247` |

| 机制 | 值 |
|------|------|
| 距离场 | 双遍 chamfer，直边 1、斜边 1.414；alpha > 40 算身体 |
| 候选点 | 3px 六角网格 + 抖动；优先级 `0.65·rand + 0.35·(1−s)`，大点先放 |
| 半径 / 间距 | `s = (d/D0)^0.75`，`r = (rMin + (rMax−rMin)·s)·(0.5 + 0.75u)`；最小间距 `(gap + 0.14s)·(r1 + r2)`，8px 网格查邻居 |
| 边缘 | 离边 < 3px 的候选丢 35%；< 7px 的点向白混至多 30% |
| 颜料吸附 | 像素数 > max(30, 0.2%) 的纯色算颜料，≥ 3 种才启用 |
| 点形 blob | 核心圆 0.66–0.74R + 6–8 瓣（偏移 0.32–0.52R、半径 0.36–0.52R），压扁 0.86–1，边缘 ±0.08R 噪声 |
| 点形 leaf | 2–3 瓣，压扁 0.46–0.62 |
| 加深 | 边缘 `exp(−距边/0.08R)`，2–5 粒小斑；深色 `c·(c/255)^0.3`；不透明度上限 0.97 |
| 图集 | k-means 32 色 × 12 形，另一张半尺寸图集给小点；`multiply` 叠加 |
| 白光晕 | 每个点下垫半径 1.8r、不透明度 0.4 的白色径向渐变 |
| 标注 | 实心圆 r 4.8，连线 1.1px；标签 JetBrains Mono 500 15px + Noto Sans SC 300 14px（45% 灰） |
| 推散 | 半径约 105（`d² < 11000`），力 `(1 − d²/11000)·3.2` |
| 回弹 | `v += (target − p)·0.045`，`v *= 0.8`；悬停晃动振幅 1.1，0.9 / 0.8 rad/s |
| 散开 | 载入从 1.6 倍画幅飞入；「重新聚拢」撒到 1.8 倍 |

## 实现要点

- **先有底图，再有粒子**：第一版随机撒点再随机上色，颜色成了噪声，看不出锦鲤。改成先画一张带花纹的锦鲤，粒子只从它取色；和原作并排，背上深蓝条和鳍上橙色的位置对得上。颜色问题在图里解决，不在粒子代码里解决。
- **边缘按距离变化**：点一样大时轮廓一圈很硬。按到轮廓的距离同时调大小、透明度和保留概率，边缘出现原作那种往外晕开的效果。
- **点换成花瓣形水彩块**：原图放到 1:1 才看清每个点是五六瓣的小花、边缘深中间浅。预画 12 种花瓣形；边缘一开始直接颜色自乘，蓝色发紫、橙色发棕，改成同色相加深。按原作近景同一取景截图上下并排验证。
- **接缝不出灰点**：画好的底图两种颜色交界有抗锯齿过渡色，会变成灰扑扑的点。每个点的颜色吸附到最近的纯色颜料；上传的照片没有主色，就不吸附。
- **鳍是一条条鳍条**：鳍条之间留细缝（透明），取点时小点会沿鳍条排开，像原作那样有羽毛感。
- **只画要画的**：三张共用一个 requestAnimationFrame；点停稳、鼠标不在画上时那张不重画。无 GPU 的无头浏览器里静止 60fps，悬停一张 50–60fps；强制三张同时重画每张约 10–15ms。
- **canvas 字不会等字体**：标签画在 canvas 上，页面显式 `document.fonts.load` 两个标签字体，加载完重画一次。
- 标注点位存成动物外框的比例坐标，所以换图后标注框跟着新图走。

可学之处（原笔记的要点）：

1. 点的颜色来自一张颜色正确的底图，粒子只负责把它拆开。
2. 中间密、边缘稀。边缘的点更小更淡，轮廓清楚但不硬。
3. 一套版式出一个系列：标题、标注、页脚位置都不动，只换动物和主色。
4. 主色只出现在三个地方：标题里的一个词、动物本身、四角的模糊色块。

## 和原作的差距

| | |
|------|------|
| 颜色 | 原作的点更鲜亮、几乎不透明，重叠处只略深；这里用 `multiply`，重叠多的地方偏深偏饱和，蓝橙交界偶尔有暗绿灰的点 |
| 轮廓 | 原作鱼身更圆润、头更大；这里的锦鲤略细长，鳍条感太强；轮廓重叠度约 0.75 |
| 花纹 | 原作是手绘般的自然过渡；这里是按区域摆的色斑，近看分区比较整齐 |
| 海龟、蜥蜴 | 海龟比原作深、密；蜥蜴比原作细、稀，叶片点偏少。这两张只做到同一种手法、姿势对上 |
| 角落色块 | 用径向渐变近似；原作更像一条被虚化的鱼鳍，形状更具体 |

## 接入

- **file:// 直开，运行时零网络**：`grep http index.html` 为空；纯 Canvas 2D，没有外部脚本。
- `fonts/` 全部取自 npm 的 fontsource 包 `files/`，`@font-face` 相对路径引用：
  - `@fontsource/inter-tight@5.3.0`：latin 300 / 400（标题与页脚的西文）；
  - `@fontsource/jetbrains-mono@5.3.0`：latin 400 / 500（canvas 标签编号、页尾代码）；
  - `@fontsource/noto-sans-sc@5.3.1`：只带海报和控件用到的约 90 个中文字符所在的 14 个切片 × 300 / 400 字重（28 个 woff2，约 850KB），每个 `@font-face` 保留原切片的 `unicode-range`。原包 300 + 400 全量约 7.3MB，不搬。
  - 改了海报或控件里的中文后，新字可能落在没带的切片里而回退系统字体：按 fontsource `300.css` / `400.css` 的 `unicode-range` 找出新字所在切片补进来。
  - 许可证：三款都是 OFL，见 `fonts/OFL-*.txt`。
- 页尾「可拆」正文走系统字体，不依赖这些切片。
- 打包进库时的改动：三张海报改成静态标记（带 id，脚本按顺序填）；页脚左边原来的「粒子与颜色」是原帖文案的直译，换成 01 / 03 编号；「重新聚拢」按钮 id 改为 `scatter`；加 canvas 字体加载后重画；去掉笔记宿主的 meta 和 Google Fonts 链接；页尾加「可拆」。
