# progressive-blur

来源：@rit3zh 的 Progressive blur，https://x.com/rit3zh/status/2102423249909146040 ，项目 github.com/rit3zh/expo-backdrop。取样日期 2026-11-05（看视频，未读原项目代码）。

## 机制

- 六层（顶）或五层（底）`backdrop-filter` 叠放，半径逐层翻倍，遮罩让高半径的层只留在靠屏幕边的部分。
- 模糊层上再盖一层同底色的渐变，把最外侧压淡。
- 页头和按钮在模糊层上面，自己不被糊。
- 进入页面慢速自动滚动，一拖动或滚轮就停；减弱动效时不滚。

## 可学

- 模糊强度沿方向连续变化，比一条硬边的毛玻璃更不抢眼。
- 顶和底用不同强度：顶部要藏内容，底部还要让内容隐约可见。

## 不学

- 原视频开头的相机推拉和整机模糊是录屏后期，不是界面。
- 模拟器的触点圆只在拖动时显示，产品里删掉。

## 和原版的差距

照片是自绘色块（原帖照片不收），所以没有照片细节；外壳比原版略亮。

测试参数：`?y=<滚动位置>`、`?touch=<x>,<y>`、`?still`。
