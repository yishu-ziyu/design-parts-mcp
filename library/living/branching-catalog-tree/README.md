## 机制
- 入场：每张图从节点旁的小团（scale .2）飞到位，延迟 = min(380, 距离*.3) + 随机 0-60ms，时长 620ms。
- 连线：pathLength=1，dashoffset 从 1 到 0。
- 切分类：旧图 240ms 收回节点，新图再展开。
- 连线用横向线性渐变，离源头越远越淡。
- 打开：主卡片从缩略图矩形 FLIP 放大 560ms，同时树 blur(16px)、opacity .42。

## 可学
把“分类”画成真实的树，切换时先收再放；用连线的深浅表达层级。

## 不学
不学原帖的客户 Logo 和作品图；上百张图时也别照搬逐张 SVG。

## 和原版的差距
页头、节点、Logo 和 Physical 的缩略图位置尺寸、细曲线树和弹层基本重合（位置是从视频帧量的）。差距：缩略图全是代码画的占位，Digital 这组差距最明显，原版是真实网页截图，我的是几种重复的模板，看上去更规整；Physical 的摄影感没有。Digital 只画了 57 张（原版标 60）。曲线整体比原版略深。原版的工作室名和客户 Logo 都换成虚构词。

## 素材说明
图片、封面、Logo 全部用代码重绘，品牌名换成虚构词。字体在 fonts/（inter-latin-var.woff2），均为开源字体，不是原版字体。

演示入口写在页面脚本末尾的 URL 参数里。
