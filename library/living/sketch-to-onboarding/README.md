# sketch-to-onboarding — 手绘分镜变成手机引导页

来源：[@jhao941 的帖子](https://x.com/jhao941/status/2091518401915277479)，2026-08-23。作者先手绘分镜和提示，再让智能体实现，说两三轮就能调到满意。

## 机制

- **箭头钉住：** 箭头入场后全程不动，静止位置 x=105.5。图标在它下面穿过，所以视线一直有落点。
- **图标轮换：** 每 3.5 秒换一次。旧图标左移 270px 退场，新图标从右边同速入场，时长 950ms，曲线 `cubic-bezier(.16,.84,.24,1)`，起步快、收尾慢。
- **步骤同步：** 图标开始移动时，步骤高亮同时切换。顺序是网格日历配第 1 步、红色日历配第 2 步、吉祥物配第 3 步，然后循环。首轮是吉祥物配第 1 步，这个顺序来自原视频。
- **入场：** 引导页从底部升起 500ms；箭头和图标同时从屏幕左右两侧进入，1500ms 汇合。
- **玻璃菜单：** 日程页的弹出菜单半透明并模糊背后内容，紫色横条透过来变成一条淡紫光带。

## 可学

- 先把动效写成 Phase 分镜，再让智能体实现，能把沟通轮次压到两三轮。
- 一个不动的元素加一个轮换的元素，比整组一起动更容易看懂「从哪里迁到哪里」。

## 不学

- 原版的吉祥物和其他产品图标不收，这里是自绘占位。
- 这种循环只适合等待用户点击的说明页；用户正在操作时不要循环。

## 和原版的差别

吉祥物、三枚图标都是自绘。中文用系统 PingFang，本目录不带字体，所以换到非苹果系统会变样。手绘分镜是 SVG 加扰动滤镜和楷体画的，笔迹比原图规整。
