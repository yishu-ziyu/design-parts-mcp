# list-peek

来源：@ZaynHao 的 UI 设计小技巧，https://x.com/ZaynHao/status/2114557290724683976 。取样日期 2026-11-05（看视频）。

## 机制

- 定高列表的高度算到下一行的上半截，用半行提示还有内容。
- 方向键移动时，让选中项的下一项也完整可见，提前露出。
- 面板打开没有动画，原视频里相邻两帧（60ms）就已经完整出现。
- ⌘K 开关，点搜索按钮也能打开，Esc 或点外面关闭；打字过滤。

## 可学

- 提示还有内容，不一定要滚动条或渐隐，算准高度就够。
- 滚动边距给下一项留位置，键盘用户不会撞到边才发现。

## 不学

- 红色讲解条、箭头和按键提示是原视频的讲解内容，留在页面上方便对照，接入产品时删掉。
- 发件人标识是原视频的品牌图标，这里全部换成自绘占位。

## 和原版的差距

发件人头像和品牌图标换成了占位；中文字用系统苹方，不在本目录。

测试参数：`?open=<向下按几次>`、`&key=<按键提示>`、`&held=1`。
