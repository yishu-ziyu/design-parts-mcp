# SVG 分批作画（svg-draw-process）

来源：<https://x.com/leo114119/status/2109602441356583178>（@leo114119，帖子里的动图）。复刻日期：2026-11-05。
画面主体是初音未来同人插画，角色和画面都有版权，这个目录不公开、不推送。

## 机制

- 画面是原帖动图的逐帧截图：13.2 秒、264 帧、每秒 20 帧，在 ego-browser 里暂停后逐帧截取，存在 `source-assets/frames/`。这里不是在实时画 SVG。
- 顶部信息栏是真实 HTML：阶段标题、批次说明、元素计数、百分比和进度条都由时间线算出。时间线和全部文案逐条读自视频。
- 节奏不是匀速：两次「观察与修改」阶段计数几乎不动（1.1–1.9 秒、5.05–5.85 秒），之后每秒约 200 个元素。
- 四个阶段的顺序：草稿线、大色块、细节、收尾，中间穿插观察修正。

## 可学

把生成过程分成有名字的阶段并显示计数，观众能看懂进度；暂停修正的片段让过程看起来像在思考。

## 不学

不要把这些帧或这个角色放到公开页面。要做自己的版本，把 `#board` 换成自己的分批绘制内容，保留时间线和信息栏。
