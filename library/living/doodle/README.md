# doodle：一笔一笔画出来、画完继续抖的图标

来源：nicoletangnan/doodle-icons（MIT），https://github.com/nicoletangnan/doodle-icons ，演示站 https://doodle.oreoui.com 。2026-11-05 用 ego 打开线上版本核对。

`replica.html` 是演示站首页复刻；`index.html` 是更早的拆解笔记，保留不动。

## 机制（常量读自线上打包代码，只读取未改动）

- 抖动：`feTurbulence` 的 seed 在 1 到 6 之间跳变，`calcMode="discrete"`，每轮 .86s，再用 `feDisplacementMap` 位移 4。文字和图标共用。
- 笔画：单笔时长 = 线长/130，夹在 .15 到 .7 秒；下一笔在上一笔 70% 处起；同行错开 .06s。放进句子的图标用 线长/160，夹在 .12 到 .5。
- 句子：词之间都有空槽。点托盘放进随机空位，拖动吸附到最近槽位。
- 回收站：外扩 14px 判定，靠近时变红、放大、掀盖。
- 改色：七个圆点错开 .045s 弹出。
- 进场动画默认 .8s，缓动 cubic-bezier(.625,.05,0,1)，标题按行升起，卡片错开浮入。
- 音效是 WebAudio 现合成，用户点过页面才响，总音量 .5。

## 可学

- 手绘感大半来自持续抖动，线条本身不需要画得很歪。
- 一个滤镜同时管文字、图标、按钮文字。
- 拖拽的反馈分层：虚线槽位、托盘淡出、回收站变红掀盖。

## 不学

- 整页大量元素一直跑滤镜有性能开销。
