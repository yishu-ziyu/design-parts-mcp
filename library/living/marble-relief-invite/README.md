# marble-relief-invite — 石膏浮雕邀请页

含原作素材，只留本机。

来源：Viviennn（@whereisvivien）用 Codex 做的 Wild Week Athens 2026 邀请页，https://x.com/whereisvivien/status/2050987880399704382 ，2026-05-03。复刻于 2026-11-05，依据是帖子视频（15.8 秒）。没有看过原站，视频也只滚到第三行露头，往下的内容未知。

## 机制

- 首屏是一行巨大的蓝色窄字母，中间压着一只白边贴纸外形的陶瓶。
- 鼠标移上陶瓶：瓶子转 127° 倒下并右移，用弹性缓动，压住两边的字母。0.3 秒后瓶口淌出一条同色液体，带同样的白边，约 1 秒流到首屏底部被裁掉，1.5 秒开始变细，2.4 秒断掉。鼠标移开，瓶子立回去。
- 鼠标划过石膏浮雕：人物沿划过的范围变成深灰，背景不变。停止后等 2.6 秒再用约 4 秒淡回去。
- 页面只有两个颜色方向：米灰的「石膏」和饱和的蓝。

## 可学

- 所有东西都像一张纸或一块石膏，没有阴影堆叠。蓝色只给字。
- 悬停效果用的是真实的明暗层，不是统一的灰度滤镜：背景不变，只有人物变色，所以像在给石膏上色。
- 「April 31 – 32」这种不存在的日期，把正式格式变成玩笑。

## 不学

- 整页依赖悬停，触屏上看不到液体和上色。
- 按窄条字母撑满首屏，手机上字会很小。

## 素材

`source-assets/` 全部从帖子视频的暂停帧裁出。`relief-dark.jpg` 把 50 帧逐像素取第三暗的值，去掉鼠标后得到；视频里鼠标没有走到最右边的人物，那一块按已压暗区域的亮度关系合成。第一个 W 的左臂被瓶子挡住，是照可见部分补画的。
