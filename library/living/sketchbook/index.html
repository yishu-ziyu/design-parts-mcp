#curl
翻页曲面：每页一条 28 列的平面网格，顶点着色器里按到书脊的距离 x 弯成一段圆柱：x' = sin(xk)/k，z' = (1 − cos xk)/k，再绕书脊转 −π·r。曲率 k = 1.15·sin(πt)，翻到一半最弯、两头摊平；r = tᵂ/(tᵂ+(1−t)ᵂ)，W = 1.6。页面抬离纸面 0.004 + 0.02·sin(πt)。正反面用弯曲后的法线判断，不用 gl_FrontFacing。
#stage
手势：在右半页按下拖向左是往后翻，左半页拖向右是往前翻；进度 = 拖动距离 / 书宽。松手时进度过半或甩动速度超过 1.4 书宽/秒就翻过去，否则弹回。弹簧 stiffness 55、damping 18、mass 1.2，略过阻尼，约 1 秒停稳。只点不拖就直接翻一页；方向键也行。
#viewer
版式：纯白底，书居中，宽 = min(920, 48vw)（手机 = 屏宽 − 32），单页宽高比 1 : 1.01。只有外侧两角是圆角（页宽 5%），书脊一侧直角。书下面一层很淡的大阴影，右边一根紫色橡皮筋从书背绕出来，高度约书高 46%。
#dial
左侧刻度：每个跨页一根 13×2 的浅灰紫刻度 #d2cfda，间距 11px；当前页变成 19px 黑色。点刻度会一页一页连续翻过去，而不是直接跳。手机上改成底部横排。
#caption
说明文字跟着书的左右边缘对齐，书下 48px：左边地点大写 14px、字距 0.04em，下面一行灰色日期；右边一句灰色备注 15px。翻页一开始就换成目标页的文字。
