来源：[x.com/raul_dronca/status/2096951042558595245](https://x.com/raul_dronca/status/2096951042558595245)，2026-09-07。原帖 Rearrange Grid，34.1s、1918×1080、60fps。五张图、三种排法、拖动让位。原帖照片有版权，本页五张为原件。

打开 [index.html](index.html)。

## 机制逐条

- **拼贴**：三列。第一张占两列。行高 268 / 196。
- **主图**：第一张跨两行。右侧 2×2。
- **横排**：五列等宽，行高 228。
- **FLIP**：换排法和让位都是 550ms `power3.inOut`。
- **拖起**：位移超过 7px。128×168，−8°。虚线框 `#ghost` 留在格子里。

## 可学 / 收窄 / 启示

- **可学**：同一组节点换格子。拖起来缩小，落点用虚线。邻居滑过去。周围留白。
- **收窄**：标本只收三种排法和拖动。镜头走 [lasso](../lasso/index.html)。
- **启示**：手在抓的时候，格子要先让开。虚线框比半透明残影更清楚。
