#hero
版式和色板：整页只有一个黑 #0A0A0A 和两个近白——页面 #F1F1EF、画布 #F5F5F2（亮 4 级，所以画布上沿是一条看得出的硬边）。画布从视口宽 41.4% 处开始、顶在导航下沿、铺到右下角，左缘 4.5 格渐变进页面色。导航高 clamp(56px, 6.41vw, 112px)，正文 clamp(13px, 1.23vw, 21px)、每行约 33 字，按钮纯黑直角、高 3.37em。≤720px 改成标题 / 画布 / 正文上下排。
#scan
四态格子着色器：格高 = 视口宽 × 8/1684（约 0.475%，取整到设备像素），格宽 = 1.5 × 格高。每格只在中心采一次源亮度：< 0.24 整格、< 0.44 粗线（格高 6/8）、< 0.805 细线（3/8，落在第 2–4 行），其余留空。淡影 = 同一源图模糊半格后最多混入 30% 墨色，垫在线缝里给体积。每帧每格加 ±0.025 噪声让线头轻闪；左缘约 7 格内按格随机把亮度推白，线头参差断开。
#stage
源和规则分开，12 fps 步进：源是离屏 canvas 上逐帧画的灰度程序猫（椭圆 + 三角 + 贝塞尔尾巴，径向渐变做体积，右上一块噪声边灰墙），所有周期都整除 9.6 s，无缝循环；源像素是正方形、边长半格。rAF 里只在 floor(t × 12) 变了才重画；滚出视口暂停；reduced-motion 停在第 6 帧。没有 WebGL 时 Canvas 2D 画同一套格子。
#headline
点阵标题和格子是同一种语言：5 行高大写，竖笔 2 格、横笔 1 格、字距 2 格、词距 5.6 格，两行顶边差 7.4 格。内联 SVG rect + crispEdges，单位 = round(0.81vw) 取整到整像素（5–14px），笔画不会忽粗忽细。
#swap
换成自己的视频 / 图片：点选或直接拖到画布上，object URL 本地读，不上传；视频静音、循环、playsinline，按 cover 铺满。自动色阶：每秒把可见画面缩到 64px 宽算亮度直方图，第 3 / 7 / 45 / 92 百分位对齐整格 / 粗线 / 细线 / 近白四个切点，着色器里分段线性映射，每帧向目标靠 25%。一大片平坦背景（±8 级内超过 25% 像素）压在细线切点上就把切点推开：亮背景留白，暗背景变成一片细线。
