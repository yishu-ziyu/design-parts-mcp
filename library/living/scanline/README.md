# scanline — 一条渲染规则画整页：循环素材变成 12×8 的四态扫描线格子，12 fps 步进

来源：https://x.com/amananimates/status/2113508952524910707 （Aman Singh @amananimates，2026-10-23，视频 9.6 s）；推文指向的模板页 https://www.scrolltide.co/templates/mitten （Scrolltide，分类 Hero Section，Premium，预览视频 1280×756、9.6 s 循环）。完整 prompt 要付费，没读到，也没有代码和 live demo。模板页公开的做法只有一句：一个 WebGL shader 把一段循环视频转成细线（rules）、色块（blocks）和一层发光淡影（ghost），画面按 12 fps 步进，像采样信号。下面的格子、线宽、颜色、帧率都是把推文视频（X 给到的最高 1684×994）逐帧画进 canvas 读像素量出来的，不是从源码读的。

调性一句话：整页只有一个黑和两个近白，明暗全靠「这格画不画线、画多粗」；降到 12 fps 再量化到格子，一段视频就成了屏幕里的信号。

## 这一页是什么

- 首屏 hero：左边点阵大标题、三行等宽正文、一个黑色直角按钮；右边画布里一只由扫描线实时画出的程序化小猫，9.6 s 无缝循环，右上角一片整齐的长细线（灰墙）压住构图。
- 产品是虚构的 **Noodle**（一个小 AI agent）。标题、正文、导航、按钮文案和 logo 都是自己写的。
- 画布右下角「换成你自己的视频 / 图片」：点选或直接拖到画布上，用同一套规则画你的素材；换过之后变成「换一个」和「恢复默认」。
- 往下滚是「可拆」。

## 格子规则

| 项 | 值 |
|----|----|
| 格子 | 原作 1684 宽时 12×8 px。本页格高 = 视口宽 × 8/1684（≈ 0.475%，取整到设备像素），格宽 = 1.5 × 格高 |
| 空 | 源亮度 ≥ 0.805 |
| 细线 | 0.44–0.805：格高 3/8，落在格内第 2–4 行 |
| 粗线 | 0.24–0.44：格高 6/8，第 1–6 行 |
| 整格 | < 0.24；上下相邻连成实心块 |
| 采样 | 每格只在中心采一次源亮度；源像素是正方形，边长半格 |
| 淡影 | 同一源图模糊 5 个源像素（半格），按亮度最多混入 30% 墨色，垫在线缝里 |
| 噪声 | 每帧每格 ±0.025，边缘线头轻闪 |
| 左缘 | 画布底色 4.5 格渐变进页面色；亮度在约 7 格内按格随机推白，线头参差断开 |
| 帧率 | 12 fps：rAF 里只在 `floor(t × 12)` 变化时重画 |
| 循环 | 9.6 s，所有周期函数都整除 9.6 |

## 色板（只有三个基色）

| 角色 | 值 | 用在哪 |
|------|----|--------|
| 页面 | `#F1F1EF` | 整页底色 |
| 画布 | `#F5F5F2` | 比页面亮 4 级，所以画布上沿是一条看得出的硬边 |
| 墨 | `#0A0A0A` | 标题、按钮、线条、logo，全页只有这一个黑 |

正文字色 `#111110`、按钮字 `#F4F4F1`、按钮悬停 `#262624` 都是这三个的近邻。淡影是墨色按比例混进画布色，不是第四种颜色。

## 实现要点

- **内容和规则分开**：源（程序猫或你的素材）画在离屏 2D canvas 上，着色器只管怎么画；换主角只换源。
- **一个全屏片元着色器**：`cell = floor(p / uCell)`，在格心采源亮度 → 分段映射 → 四态；格内纵向位置 `fy` 决定细线（0.25–0.625）、粗线（0.125–0.875）还是整格。淡影另采一张模糊过的源。
- **12 fps**：rAF 每帧都跑，但只在 `floor(now / 1000 × 12)` 变了才重画；滚出视口暂停（IntersectionObserver，视频同时暂停）；`prefers-reduced-motion` 停在第 6 帧。
- **换源**：文件只在本地用 object URL 读，不上传、不用摄像头；视频 `muted` + `loop` + `playsinline`，按 cover 铺满画布；着色器按 rgb 算亮度，彩色素材也能用。浏览器解不了的视频提示换 mp4 (H.264) 或 webm。拖到画布以外的文件被拦住，浏览器不会跳走。
- **自动色阶**：每秒把可见画面缩到 64px 宽，算亮度直方图，第 3 / 7 / 45 / 92 百分位分别对齐整格 / 粗线 / 细线 / 近白四个切点，着色器里分段线性映射；切点每帧向目标靠 25%，切换不跳。
- **防闪烁**：一大片平坦背景（±8 级内超过 25% 的像素）正好压在细线切点上时把切点推开——浅背景移到它下面，背景留白；深背景移到它上面，背景变成一片细线，和原作右上那片灰墙一样。
- **兜底**：没有 WebGL 时 Canvas 2D 画同一套格子（没有每帧噪声）。
- **标题**：一个小脚本把字形表按字距 / 词距排成内联 SVG `rect` + `crispEdges`；单位取整到整像素，笔画粗细才不会忽粗忽细。
- 测试钩子：`window.__scan`（`render` / `pose` / `levels` / `cells`）。

## 和原作的差距

- 最大的差距是猫本身：原作来自真实视频，轮廓、毛发、动作都是有机的，扑和转身时整个身体在三维里转；这里是 2D 程序化卡通猫，动作是摆动式的，回头只是五官平移，仔细看是「木偶」。换成真实视频后这一条就不成立了。
- 原作线头的破碎来自视频噪点和真实毛发，分布自然；这里来自一张固定噪声图加每帧随机噪声，背上那片碎点比原作规整。
- 原作右上的灰墙随镜头轻微移动，这里静止。
- 等宽字体是推断的，原作的字看起来略细一点。
- 阈值和淡影算法是从截帧统计反推的，prompt 付费，无法核对原作的具体写法。
- 1100 宽时导航字号下限设为 12px，比按比例缩放的 11.6px 稍大。

## 接入（file:// 直开，运行时零网络）

- `fonts/jetbrains-mono-latin-400-normal.woff2`、`fonts/jetbrains-mono-latin-500-normal.woff2` 取自 `@fontsource/jetbrains-mono` 5.3.0（latin 子集，OFL-1.1）。`@font-face` 相对路径 + `unicode-range`，中文落到系统字体。
- 没有外部脚本、没有构建。`grep http index.html` 为空。
- 换源用 object URL，file:// 下可用。
- 验证：Playwright（swiftshader）拦掉所有非 `file:` 请求打开，零失败请求、零控制台错误，两个字重 `loaded`；默认程序猫帧在变；换成本地生成的测试图片后色阶切点变成 `[0.427, 0.58, 0.807, 0.89]`，再换一段 webm 帧在变，「恢复默认」回到 `[0.24, 0.44, 0.805, 0.97]`；1280 宽和 400 宽两种版式都看过。

## 可拆

- `#hero` 版式与三色板：画布 41.4% 起、亮 4 级的硬上沿、左缘渐变，导航 / 正文 / 按钮尺寸。
- `#scan` 四态格子着色器：格心采样、三档阈值、淡影、每帧噪声、左缘参差。
- `#stage` 源和规则分开 + 12 fps 步进 + 离屏暂停 + Canvas 2D 兜底。
- `#headline` 点阵标题：竖 2 横 1、字距 2、词距 5.6，整像素单位。
- `#swap` 换源 + 自动色阶 + 平坦背景防闪烁。

## 启示

给一个作品定一条只属于它的渲染规则（这里是 12×8 的格子、三档线宽、12 fps），让头图、标题字、按钮都服从它，一屏就有辨识度，不靠颜色和渐变。实现上把「内容」和「渲染规则」分开，换一个作品只换内容，整站的样子不变。
