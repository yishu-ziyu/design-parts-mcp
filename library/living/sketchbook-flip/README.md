# 素描本转盘、书架和翻页

含原作素材，只留本机。

来源：@jeanxcrj https://x.com/jeanxcrj/status/2111508243096969596 ，站点 https://jeanxcrj.com/play.html（查看于 2026-11-05）。转盘公式、书架样式和刻度位置取自公开页面的 CSS 和渲染结果；翻页代码是自己写的，没有用原站的 sketchbook.js。

## 机制
- 转盘：书走在圆心位于屏幕右外的大圆上，半径 106vh。中间那本放平，上一本和下一本分别倾斜，右侧书名跟着上下移动。
- 书的大小：屏幕面积按真实纸张面积的平方根缩放，大本显大但不压过小本。
- 书架：封面底部对齐，悬停时封面翻开 34 度，露出内页。
- 翻页：把一页切成 12 条嵌套的竖条，每条相对上一条再转一点，所以纸是弯的。阴影按每条的角度变化。
- 刻度：每个跨页一格，按住上下拖动就逐页翻过去。

## 可学
竖条嵌套只用 CSS 3D 就能做出弯曲纸张，不需要 WebGL。

## 不学
竖条接缝在高分屏上可能隐约可见。需要真实纸张光影时，还是原站的 WebGL 更好。

## 素材和差距
页面、封面和书带都是在原站用 ego-browser 2 倍截的，放在 `source-assets/`，每个跨页切成左右两张；说明文字是原站的。原站翻页是 WebGL，这里仍是 CSS 竖条，纸面光影较弱，所以截图里已带的装订阴影没有再叠。

书名去掉了 CMU；手册封面的品牌标签已盖掉，但内页和封面其余部分没有改。First Year 原有 32 个跨页，只截了前 14 个，所以它的刻度比原站短。原站标题字体 Milling 是商业字体，换成系统 Helvetica Neue 600，未打包字体文件。原站首页的入口没有做，页面直接打开在转盘。
