# svg-launch-film — 每帧都用 JS 画的 SVG 发布短片

来源：[x.com/dwhitedesign/status/2102014506192851303](https://x.com/dwhitedesign/status/2102014506192851303)，原站 [cube-motion.dev](https://www.cube-motion.dev)，复刻日期 2026-11-05。原帖 35 秒。全部用 JS 现画，没有用原帖图片。

## 机制逐条

- `render(t)` 是 t 的纯函数，所以可以任意跳转；`?t=秒` 能定住某一帧。
- 全片是一张分组表 `TRACKS`：每一组点各有自己的入场和离场时间，从一团尘凝聚成形，再散成另一团。组之间不要求同一批点，看起来连贯靠的是尘团的位置接得上。
- 球面炸开：点按方向分给四个小球，每个点沿二次贝塞尔曲线穿过中间一个汇合点飞向目标，目标本身也先飞过头再退回来，所以 5.3 秒会拉出 Y 形。
- 卡片是透视的：每张卡在几个时刻记下四个角，中间线性插值，内部的点用单应矩阵映射，点距跟着透视变。
- 球变立方体：每个立方体上的点配给离它最近的球面点，直接插值。
- 上千个点不建上千个节点：按颜色、透明度、大小分组，每组一条 `M x y h0` 路径，靠圆头描边画成点。
- 标题逐字从裁切线下升起（每字 50ms），离场逐字落回同一条裁切线下（每字 36ms）。
- 片尾一个圆盘从立方体中心放大盖满画面，变成亮底；立方体同时由白转蓝，缩小上移，品牌字、网址、安装命令依次出现。

## 可学 / 不学

- 可学：用一个时间函数驱动整部片子；用少量路径画大量点；四角加单应矩阵做透视。
- 不学：品牌名（换成 form）和四个框架的名字与图标（换成占位）。

## 和原版的差距

四角、球和小球的位置是从 4K 暂停帧上量的，到位后的画面基本重合。过渡中的点云只是形状和走向接近，每个点的位置不同：5.3 秒的 Y 形比原版稀，23.2 秒左边的尘团没有原版的斜向，27.2 秒原版是三团，这里更像横着的一条。
