可拆

#stack
首页：作品不带卡片框，竖向一列居中，滚动容器上下各 120px 渐隐遮罩。
#dock
进入作品后顶部出现的胶囊 Dock：关闭圆钮 + 每个作品一个 42px 格子 + 竖向省略点。半透明白底 + 14px 背景模糊。
#tray
神灯变形：每件作品取中心点，跑原站的 d() 吸入函数，换算成 translate / scaleX / scaleY / skewY / opacity / blur 六个量，0.68 s、ease [.2,.8,.2,1]，相邻件错开 40 ms。
#case
作品页：底色换成暖灰，大号衬线标题压在主图上，一句话说明。点 Dock 里别的格子直接切换，点圆钮反向吐回首页。
