# genie — 点开一件作品，首页上的作品像 macOS 最小化那样被吸进顶部 Dock

来源：https://x.com/DanBatten/status/2110793325360058378 （Dan Batten 转引并评论"这个交互和设计很好"）。被引的原帖是 David McGillivray @dmcgco 2026-10-16 的作品集重新上线帖，附视频，指向 https://dmcg.co 。原站是公开的 Next.js 站，打包后的 JS 里能直接读到这段动画的模块：导出 `DockGenieArtwork` 和 `DOCK_MOTION_DURATION = 0.68`，变形函数、透明度、模糊、错开时间都是从这段压缩代码里抄的数（事实）。没找到作者讲做法的文字、仓库或 CodePen。原站还有一个按同一变形函数生成的圆角矩形 `clip-path: path()`，以及点击音效（`emitSiteSound("dock.open")`），这两样本页没做。Dock 的尺寸、底色、页面底色是在 1650 px 宽视口截图里量的（推断精度约 ±2 px）。

## 量到的数

| 项 | 值 | 来源 |
|----|----|------|
| 动画时长 | 0.68 s | 代码 `DOCK_MOTION_DURATION` |
| 缓动 | cubic-bezier(.2, .8, .2, 1) | 代码 `g=[.2,.8,.2,1]` |
| 错开 | 每件 +0.04 s（入场 0.1 + 0.04·i） | 代码 |
| 吸入起点 | 右缘先动，左缘晚 38% 时间轴 | 代码 `(p − .38(1−t)) / (.62 − .1t)` |
| 厚度 | 1 − 0.97·吸入量（最薄 3%） | 代码 |
| 弧线下沉 | sin(πt)·sin(πp)·高 × 0.1 | 代码 |
| scaleX / skewY 限幅 | 0.035–1.16 / ±8° | 代码 |
| 淡出 / 模糊 | 吸入量 38% 以后才开始，最多 5 px | 代码 |
| 首页底 / 作品页底 | #FFFFFF / #F0EFEB | 截图取色 |
| Dock | 高约 52 px、顶 10 px、半透明白、关闭钮在胶囊左外侧 | 截图量 |

## 怎么做的

1. 首页每件作品是不带框的插画，竖着一列居中，滚动容器上下 120 px 用 mask 渐隐。
2. 点一件作品：先把所有作品的变换清零，量出每件的矩形和它在 Dock 里对应格子的中心，作为 `targetX / targetY`。
3. 每帧对每件作品算三次变形函数：中心点一次，左右各偏 0.5% 宽度各一次。两侧点的水平距离给出 scaleX，连线斜率给出 skewY，中心点的位移给出 translate，厚度给出 scaleY。
4. 吸入量过 38% 才开始淡出加模糊，所以前半段形状在变、后半段才消失；格子里的小图标在本件进度过 72% 时亮起。
5. 反向（点圆钮、点"作品"、按 Esc）就是同一条曲线把进度从 1 跑回 0。

## 关键判断

- **变形是逐点函数，不是 SVG 网格。** 问题：最直觉的做法是把图切成很多条再各自移动，成本高。改法：原站只对作品中心算一次，再用左右两个近邻点的差分换成 scaleX 和 skewY，一个元素一个 CSS transform 就够。验证：把进度固定在 0.2/0.4/0.6/0.8 截图，形状先斜着变薄、再缩成一条、再淡出，和原站落地帧的走向一致。
- **滚动容器的渐隐遮罩会吃掉飞进 Dock 的作品。** 问题：Dock 在顶部 10–62 px，正好落在 mask 的透明区里，作品飞到一半就看不见了。改法：动画期间给容器加 `.anim`，去掉 mask 并抬高层级，结束再还原。验证：p=0.4 截图里作品在 Dock 下方仍完整可见。
- **400 px 宽时标题被主图盖住。** 问题：桌面上主图压住标题下半是原站的做法，窄屏上 Dock 下移后标题几乎全被挡。改法：窄屏把作品页上边距加到 136 px，主图上移量从 64 减到 30。验证：400 px 截图里标题完整露出上 2/3。

## 没做到的

- 原站 9 个项目全部进 Dock，而且落地时图标有轻微的上下错落；本页只让视口内可见的作品做变形，其余图标直接淡入。
- 原站过渡中途整页会短暂变成灰底（约 #DCDCDC），本页直接从白过渡到暖灰。
- 没做原站基于同一函数的 `clip-path` 卡片轮廓、点击音效、作品页往下的长案例内容、"目录"视图。
- 没拿到原站动画中段的清晰帧，只有落地前最后一帧，所以中段形状是靠代码推出来的，没有逐帧对照。

## API 和 CONFIG

```js
const g = createGenieDock(document.getElementById("site"), { duration: 0.68 });
g.open(0);          // 打开第 0 件，作品吸入 Dock
g.close();          // 反向吐回首页
g.setProgress(0.5); // 把可见作品定格在某个进度（调试/截图用）
g.destroy();
```

`CONFIG`（页面顶部）：`wordmark` 三行字标、`footer` 左右角注、`duration`、`stagger`、`ease`、`maxBlur`、`bulge`（弧线下沉比例）、`projects[]`（`id / title / line / meta / svg`）。系统字体，无外部请求，`prefers-reduced-motion` 时跳过变形直接切换。
