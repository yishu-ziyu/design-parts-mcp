# hoop — 一块漂在白纸上的等距小球场：低分辨率渲染再整数倍放大，三个像素小人自己打半场

来源：https://x.com/zzzzshawn/status/2111546123546661289 （shawn. @zzzzshawn，“Small plays - Basketball”，视频 18.8 s，1450×1346），它引用了同一作者 10 月 18 日的 “Small plays - Juggler”（9.0 s，同尺寸：一块圆形石板地上一个人在抛球）。作者主页简介是 design engineer，挂了 directoryyy.com、orbkit、dotmatrix 三个站，但这两条帖子都没有链接、源码或 live demo，回复里也没有作者讲做法，只看到别人跟风做了羽毛球版。所以下面的做法是推断：画面像是 3D 场景先渲染到很小的分辨率再用最近邻放大（块边缘整齐、草地外缘是散点），人物像 3D 模型带骨骼动画，有统一方向的长投影。数字是把视频逐帧画进 canvas 截图后量的，不是读源码。

## 量到的数

| 项 | 原作 | 这里 |
|---|---|---|
| 投影 | 2:1 等距（菱形宽高比 ≈ 0.49） | 2:1，`ky = kx / 2` |
| 球场颗粒数 | 菱形约 132 块宽（含草边） | `courtPixels = 160`（只算地面，草边另算） |
| 屏上块大小 | 约 4.8 CSS px（视频是 2x 录屏，≈ 9.6 视频像素） | 桌面 4 px，400 px 宽时 2 px |
| 画面占比 | 球场约占画面宽 57% | `fill = 0.6`，窄屏 `0.84` |
| 篮架高 / 人高 | 约 27 块 / 13–16 块 | 篮架 0.84 kz ≈ 33 块 / 人 18 块 |
| 颜色 | 沥青 #373636、禁区 #2d526c、禁区上阴影 #223650、篮架 #15171d、篮板框 #ca5455、包 #2e4995 | 同色板，阴影 = 地面 × 0.5 并偏蓝 |
| 背景 | 纯白 #ffffff | 纯白 |

## 怎么做的

1. 一张低分辨率 canvas（宽 = 容器宽 ÷ 块大小），画完后 `imageSmoothingEnabled = false` 画到可见 canvas 上，CSS 再加 `image-rendering: pixelated`。
2. 地面不画多边形，而是逐像素逆投影：屏幕 (x, y) → 地面 (u, v)，用圆角方形范数 `(|u|^7 + |v|^7)^(1/7)` 分出沥青、土边、草边；场地线和禁区用直角距离判断，宽度 = 0.6 个像素。颜色按像素哈希从小色板挑；沥青再叠两层低频值噪声，噪声高的地方亮点多，像磨旧的路面。这一层只在尺寸变化时算一次。
3. 草地外缘：超过草线后，离边越远的像素越容易被哈希阈值丢掉，边缘变成散点，不用描边也不用透明度。
4. 阴影每帧重算：从物体脚下沿光向 (0.62, −0.38) 拉一条带子，长度 = 高度 × 1.6，把带子下的地面像素乘 0.5、蓝通道略抬。人、篮架、长椅、包、球共用一套，所以光的方向统一。
5. 人物是 18 像素高的程序化小人（鞋、腿、短裤、上衣、手臂、头），跑动时腿和手臂按相位错开，身体每半步上下 1 像素。按 `u + v` 排序画，越靠近观者越后画。
6. 小剧本：持球人运球 1–3 s，离篮近就 55% 概率出手（起跳、抛物线、62% 进），否则传给另一人；没进或进了之后球落地弹几下，最近的人去捡，循环不停。第二个人始终贴在持球人和篮筐之间防守。

## 关键判断

- **问题**：第一版线条 2 像素粗、颗粒比原作粗。**改**：球场颗粒数从 132 提到 160，线宽阈值改成跟 `kx` 走（0.6 个像素）。**验证**：同宽对比图（cmp/03 → cmp/04）里线变成 1 块宽，和原作一致。
- **问题**：沥青是均匀噪点，看着像电视雪花，原作是有大片亮斑的旧路面。**改**：叠两层低频值噪声控制亮点出现概率。**验证**：对比图里出现了成片的浅灰区。
- **问题**：原作场地四角是圆的、草边厚，第一版是尖菱形加 1 像素草边。**改**：外层用 p=7 的圆角范数，草带加宽并让阈值随噪声起伏。**验证**：对比图外轮廓接近原作的圆角软边。

## 没做到的

- 原作人物是 3D 模型加骨骼动画再像素化，有明暗体积和真实的投篮动作；这里是 18 像素的平面小人，动作只有跑、跳、举手。
- 原作是透视/正交 3D 相机渲染，篮板和长椅有真实厚度与光照；这里是手写的等距多边形，篮板偏粗糙。
- 原作人物相对球场更大（约 1/9 菱形宽），这里约 1/9，但体块是平的。
- 没做抛球人那条（Juggler）的圆形石板地面。

## API / CONFIG

```js
const hoop = createHoop(container, {
  courtPixels: 160,   // 球场菱形的低分辨率像素宽，决定颗粒粗细
  fill: 0.6,          // 球场宽 / 容器宽；窄于 600 px 用 fillNarrow
  fillNarrow: 0.84,
  seed: 7,            // 剧本随机种子
  speed: 0.32,        // 跑速，地面单位/秒
  light: [0.62, -0.38],
  shadowLength: 1.6,
  colors: { /* 覆盖任意色板，见 hoop.js DEFAULTS */ },
  players: [ /* { skin, hair, shirt, shirtDark, shorts, shoes } × N */ ]
});
hoop.play(); hoop.pause(); hoop.isPlaying(); hoop.reseed(3); hoop.destroy();
hoop.canvas; // 可见的 canvas 元素
```

`prefers-reduced-motion: reduce` 时只画一帧，不自动播放；滚出视口时不推进剧本。
