# mosby 档案柜复刻

来源：https://www.mosbyfiles.com/ 和 https://www.mosbyfiles.com/cases/mary-colter ，2026-11-05 用 ego-browser 打开，读样式表和元素尺寸，在 1600×1000 视口核对。页面：`replica.html`（旧的 `index.html` 保留未动）。

## 机制
- 档案柜：四组错开 60px，悬停倾斜 -3°，右侧三分之一悬停时下面的组让位。
- 点开：同一块文件夹飞到卷宗位置，封面绕 Y 轴翻开。
- 卷宗：A4 比例的纸加九个穿孔，右侧竖排页签，剪贴按公式落点并可拖动。
- 滚过底部累计 2000px 翻到下一案。

## 可学
- 进入详情时不换场景，始终是同一个物件在动。
- 页签形状只用一段曲线，翻转后可做两端。

## 不学
- 进入动画 1.5 秒偏长，常用工具不适合。

## 差距
- 标题字原版是商业字体 Founders Grotesk，换成 Sofia Sans Extra Condensed 900；衬线原版是 Signifier，换成 Newsreader。字形和局部换行有差别。
- 便签和纸张上的原站纹理（便签的 note 纹理）没有拿到，便签是纯色。
- 视频卡只是外观，不能播放。
- Robie House 的平面图原版是撕纸边，这里用多边形裁切近似；回形针形状和粗细有差别。
- Mary Colter 里 `frame-1171277247.avif` 本地没有，原站当时也没量到尺寸，页面会尝试从原站加载，离线时缺这一张。
- 只对照过 Frank Lloyd Wright 这一案的首屏、剪贴和翻页，其余七案只看过是否能打开和翻页。
