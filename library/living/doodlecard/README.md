调性一句话：同一个动作（照片闪一下白光，变成一张卡）连做五次讲清产品是干什么的，然后靠三次速度变化撑满 19 秒，最后把卡印出来撒在地板上。

打开 [index.html](index.html)。加 `?still=1` 不自动播放，停在 f90。

## 这一页是什么

- **宣传片播放器**：1080×720 画布，按 24 fps 停帧播放整段 456 帧。下面是播放键、可拖的帧条、时间码，七个段落按钮跳到对应帧。「换成我的照片/视频」把你的素材放进开场、第一张闪光卡和桌上的一张卡。
- **涂鸦层实验区**：宣传片里每张卡用的同一个工厂函数单独拿出来。可调颜色数、蜡笔颗粒、边缘抖动、重画帧率、主体来源、日期和一句话；拖照片或视频进来，视频每秒重画 6 次。图片只在本机处理。
- 产品是虚构的 **LOOP**，工作室是 nearby studio。字标、标语、18 张卡的日期和一句话、全部替身场景都是自己的，不用原作的品牌、logo、文案和照片。
- 往下滚是「可拆」。

## 实现要点

- **数字都在 CONFIG 里**：`timeline`（每段的帧号和参数）、`pop`、`card`、`type`、`doodle`、`cards[]`、`table[]`。换品牌只改 `brand`，换内容改 `cards[]`。
- **按帧号画**：`createPromoPlayer` 每帧算出当前帧号，交给开场 / 闪卡 / 拼贴 / App / 落卡 / 结尾 / 工作室七个绘制函数之一。`quantize` 打开时按 24 fps 停帧，和原片一样。
- **涂鸦分两遍读图**：第一版在整张照片上缩到 150 px 分析，孩子在分析图里只有约 40 px 高，手臂 2–3 px 宽，分色后糊成色块。改成先在 120 px 的整图上找主体范围，再只把主体外框重读成 170 px 分色。卡上的画按实际涂色面积定大小，不按外框，三个气球加一个小孩这种稀疏的画不会被缩得太小。
- **落卡段拆成两个镜头**：f288–292 是空中镜头（4 张大卡贴着镜头往下掉，统一模糊 9 px，背景罩 84% 白）；f293 起切俯拍，17 张卡在 f301–310 依次落地，每张从 2.35 倍大用 5 帧落到桌面。之前做成一张满地卡片加白雾，或者让卡放大 3.4 倍，两种都和原片对不上。
- **俯拍段增量缓存**：地板和已落地的卡画进一张缓存位图，按落地顺序往上叠，一张卡只画一次（后落地的压在上面，也符合实物）；空中的卡和窗光每帧单独画，模糊很重的卡不加阴影，地板虚化图只生成一次。Playwright 软件渲染下整段平均帧率从 15 升到 33 fps，俯拍稳定段没有超过 60 ms 的帧。
- **启动**：18 个场景和涂鸦分批生成，每张之间让出主线程，第一张好了就先显示；之后预先生成地板和窗光，并把所有位图在可见画布上各画一次，播放时第一次用到不卡。
- **reduced-motion**：不自动播放，白光降到 60%，去掉手持晃动和所有运动模糊、缩放模糊。
- 测试钩子：`window.__promo`（`frame(f)`、`seek`、`ready`、`getCard`）、`window.__lab`。

## 用法

涂鸦层：

```js
const layer = createDoodleLayer(containerEl, {
  source: imgOrVideoOrCanvas,      // 必填才会出画
  mask: 'auto',                    // 'auto' 自动找主体 | 'full' 整幅 | 一张白色遮罩 canvas
  colors: 7, grain: 0.5, wobble: 0.5,
  boilFps: 0,                      // 原片是 0；>0 时用 3 套噪声循环重画
  liveFps: 6,                      // source 是视频时每秒重新分析几次
  date: 'Thu, Aug 20', caption: '…',
  background: 'photo',             // 'photo' 把原图垫在后面 | 'none'
  pop: true, seed: 3
});
layer.play(); layer.pause(); layer.seek(sec); layer.repop();
layer.setSource(src, { mask: 'auto' }); layer.update({ colors: 9 });
layer.getCard(); layer.getDoodle(); layer.destroy();
```

不依赖 DOM 容器的纯函数：

- `doodlify(source, opts) → { prep, canvas }`：一步得到透明底涂鸦。
- `prepareDoodle(source, opts) → prep`：分析一次，结果可缓存。
- `renderCrayon(prep, seed, overrides) → canvas`：只重画质感，换 seed 就是一帧 boil。返回的 canvas 带 `inkFrac`（涂色面积占比）。
- `renderCard({ doodle, date, caption }, 'white' | 'paper', scale) → canvas`：出一张卡。
- `makeWordmark(text, capPx, color, rough)`：粗糙边缘的字标。

宣传片：

```js
const promo = createPromoPlayer(stageEl, { config: CONFIG });
await promo.ready;            // 场景和涂鸦生成完
promo.play(); promo.pause(); promo.toggle(); promo.seek(3.75); promo.frame(90);
promo.setUserMedia(imgOrVideo, { date, caption });   // 换开场、第一张卡和桌上一张卡
promo.on((event, t) => {});   // 'play' | 'pause' | 'time' | 'ready'
promo.getCard(i, 'white' | 'paper'); promo.getPhoto(i); promo.destroy();
```

`cards[]` 每项是场景名、宽高比、随机种子、日期、一句话、遮罩方式。换成自己的内容时，把 `scene` 换成自己的绘制函数，或者在 `SCENES` 里加一个。`table[]` 是俯拍段每张卡的位置、角度、落地帧。

适合用在：「照片进去、结果出来」的功能演示（滤镜、风格化、抠图、证件照、OCR），闪白 + 卡片弹出可以单独当揭晓动画；日记、相册、手账类产品的分享卡和宣传片；1 秒一拍的重复段 + 加速拼贴 + 静止产品画面 + 实物收尾这套短视频节奏。

## 性能

Playwright 无 GPU 软件渲染、双核且有其他任务在跑时测的，真机 Chrome 会更快：

- 启动生成 18 张场景和涂鸦约 4–7 s。
- 播放平均 33 fps；最重的是拼贴缩放模糊和落地瞬间，单帧 80–150 ms。
- 一张 1100 px 照片 `doodlify` 约 100–230 ms；`renderCrayon` 重画一次 30–150 ms，所以 boil 建议不超过 8 fps，视频实时重画默认 6 fps。
- JS 堆约 10 MB。画布尺寸跟容器宽度和 devicePixelRatio（上限 2）。

## 和原作的差距

| 项 | 差距 |
|----|------|
| 涂鸦怎么来 | 最大的差距。原作（推断）由图像模型重新画，会简化人物、补全被挡住的身体、画出五官。这里只做分色和蜡笔质感，保留主体的轮廓和颜色，不会重画。真实照片上自动抠主体也不稳：把原片开场的一帧拖进涂鸦层，只抠到两个风车叶片、孩子的上衣和几块碎片，裤子和另外两个风车漏了 |
| 照片 | 原作是真实照片和手持实拍，有浅景深和真实光线；这里的替身场景是代码画的平面插图，手和手机是简化插画。换成自己的照片或视频可以补一部分 |
| 实物镜头 | 落卡和俯拍是 2D 近似：卡片没有透视倾斜和纸张弯曲，地板纹理比真实橡木规整；f283 卡堆特写的排列比原片整齐 |
| App 画面 | 卡片翻面、日历页没做；时间、日期、文案都是自己的占位 |
| 徽章 | 间距 8 px，原片量到约 10 px |
| 字体 | 手写字和字标的字体是从字形推断的，没有官方确认 |

## 可学之处

- 一个动作讲完产品：闪白、卡片弹出、照片变涂鸦，连做 5 次。每次间隔约 1 秒，看到第三次观众已经知道这个 App 干什么，开始等下一张。
- 节奏先慢后快再停：闪卡段 1 秒一张，拼贴段切点间隔从 11 帧压到 1 帧，到 App 画面突然安静，落卡段又慢下来。19 秒里有三次明显的速度变化，所以不显得长。
- 实物收尾：最后把卡片印出来撒在地板上，把数字日记变成能摸到的东西，比再放一张 App 截图更能说明「收集小时刻」。

## 启示

先用逐帧亮度和帧差把剪辑量出来：闪光是亮度 255 的尖峰，切点是帧差的尖峰，弹出用一行像素里卡片的宽度量。帧号写进配置以后再做画面。这一页的替身画面和原片差得多，并排截同一帧时，闪卡、拼贴、落卡的时间点是对齐的。
