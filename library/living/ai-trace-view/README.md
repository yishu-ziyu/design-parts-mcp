# ai-trace-view — 灰底极简的 AI 执行轨迹

来源：[@dimitroweb](https://x.com/dimitroweb/status/2112281659093504201)，复刻于 2026-11-05。

## 机制

- 最上面一行永远显示正在做的那一步，换步时旧文字模糊淡出，新文字淡入。
- 下面的列表逐条追加来源，每条展开一张结果卡片。
- 新卡片展开时最早的卡片收起，通常只露两张左右，高度变化用过渡衔接。
- 还在跑最后一步时，答案就从底部开始按字符流式显示，复制和反馈按钮被文字往下推。
- 全部结束后，列表收进一句 Ran 2 searches and read 3 sources 加来源小图标，只留答案。

## 可学

过程占地随任务推进而缩小，结束后退到一行：过程可查，但不和答案抢位置。

## 不学

用字符级 span 做流式效果只适合短文本；真实回答要按 token 或词追加。

## 替换过的内容

Slack、Granola、Gmail、GitHub、Linear 的 Logo 不收，换成自绘的彩色小图形；文字标签保留以对照原版。原视频里的录屏鼠标指针没有复刻。

## 打开方式

`?t=7.2` 定格；演示结束后点第一行展开列表，点某一步展开卡片。
