# GPS 仪器（复刻）

来源：https://x.com/dimuuu/status/2091803670794866711（Dmytro Kondakov，2026-08-24），页面 https://gps-01.dmytro.fyi ，开源仓库 https://github.com/dimuuu/gps-01 ，2026-11-05 查看。

海岸线数据从原站页面的 SVG 路径反投影得到，只留本机。

## 机制
- 整个场景是一张 SVG，每帧重算正射投影。
- 点地球时把屏幕坐标反投影成经纬度，镜头缓动到接收机并放大。
- 五步讲解：第 2 步画可见卫星连线，第 3 步信号球扩散，第 4 步加钟差后三球解偏离，第 5 步四球解回到原位。
- 遥测面板显示实时数表。
- 时间冻结且镜头停下后不再重写路径。整张放大时每帧重写会让浏览器来不及绘制，出现缺块。

## 可学
讲解卡固定在底部，数字从真实解算来；提示框出现在卡片正上方，不挡图。

## 不学
逐帧重写长路径只适合小尺寸，长期运行要做裁剪或 canvas。

## 和原版的差距
版式、面板、字体、配色和五步文字并排几乎相同，解算是真算的（投影、仰角、GDOP、三球和四球）。差距：星座和地球时相不同，选中的四颗星和 FIX/3 的偏差数都跟原版那一刻不一样，所以圆的位置不会一模一样；海岸线是从原站页面的路径反投影出来的，南极大陆缺失，放大后有约 0.1 度抖动；第 3 步球面里的淡线是两个椭圆近似；波速是按原版一帧估的；窄屏布局只简单隐藏了遥测面板，没按原版做；定位失败时固定用纽约坐标。作者和项目名换成了占位。
