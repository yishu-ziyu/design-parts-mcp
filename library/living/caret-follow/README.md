# 光标跟着书写位置

从一次本地产品站研究里拆出的机制。能打开的是 `index.html`。`origin/` 是那一页上的原始实现，依赖该页的文案和样式，不能单独跑。

## 机制

- 研究页里的浏览器演示。指针量的是当前目标的盒子，字按 150ms 一个补上。
- 文案、色块和句子都是样本，用的时候换成自己的。
- 尊重 `prefers-reduced-motion`。

## 可学

- 先看 `index.html` 正在动的样子，再决定要不要这一块。
- 参数写在页尾「可拆」里。

## 不学

- 不带走原页面的品牌、整页排版和作品图片。
- `origin/` 里的模块导入是研究页内部路径，不是这个库的公共 API。
