# answer-length-drag — 拖动手柄缩短 AI 回答

来源：[@dominikmartn](https://x.com/dominikmartn/status/2108179881926574321)，复刻于 2026-11-05。

## 机制

- 回答卡片底边有一个小把手，向上拖切到更短的版本，向下拖放回完整内容。
- 长度是四个固定档位，不是连续裁切；每档内容都写好了（20、10、4、1 秒阅读）。
- 被删的词原地缩小淡出，留下的词挤拢重排；再次变长时新词从小长大。
- 卡片高度单独用带轻微回弹的过渡，比文字重排慢一点。
- 右下角的阅读时间跟档位一起变。

## 可学

删词时不整段替换，用户能看到哪些内容被留下；长度变化直接绑在手上，不需要再发一次请求或点菜单。

## 不学

每档文字和词级对应都是手写的。接真实模型时要让模型输出带层级的结果，否则词对不上，缩放效果就没有依据。字号动画每帧都会重新排版，大段文字不适合。

## 打开方式

打开后自动演示循环，碰把手后停止演示。`?level=0..3` 定格到某一档，`?frame=N` 定格到演示第 N 步。把手支持上下方向键，`role=slider`。
