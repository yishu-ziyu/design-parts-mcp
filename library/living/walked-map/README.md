# walked-map — 在城市里度过的时间变成个人地图

来源：[x.com/sakinotomiura/status/2093308370119967192](https://x.com/sakinotomiura/status/2093308370119967192)，2026-08-28。原帖四段竖屏视频（720×960，7–11 秒）。产品名换成占位词 Holes，角色名换成 Crumb。

## 机制逐条

- **画幅**：每段按 689×916 显示，蓝底 #3c60c0，手机描边 8px #2b4aa6。点击重播，循环。
- **立体字**：文字外扩、模糊、截断得到圆形状，再算光照。
- **地图卡**：11 秒走三个地点。地图移动，卡片弹起，贴纸压照片左下，标签压右上；切换时照片模糊过渡。
- **开场**：11.3 秒，前 6 秒从夜到白天。先亮天空和地面，角色在 44%–52% 从剪影亮起，50% 后才出标题和按钮。
- **聊天**：7.3 秒六步，第 5 步是输入中，每条进来时整列移动，让它底边停在 y=853。
- **城市卡**：地图先空，贴纸依次弹出（每个错开 144ms），62% 才出总结和角色。
- **减少动效**：直接显示最终状态。

## 可学 / 不学

- **可学**：贴纸当地图标记；空地图逐渐被填满，直接说明"你走过的地方"；开场先给氛围再给标题。
- **不学**：把逐帧截图当实现。真要做这个产品，结构看 mechanism.html。

## 两个页面

- `index.html`：贴近原版的页面。地图、开场、城市卡是视频暂停帧逐帧播放（`source-assets/map|meet|city/`），聊天段是真实元素，照片和头像裁自原帖。
- `mechanism.html`：上一版的可拆结构，贴纸、地图、角色都是自绘，时长是旧的估计值。

## 和原版的差距

地图、开场、城市卡三段是原帖视频的逐帧截图，10 帧每秒播放，画面与视频几乎相同，但动作不如原视频顺滑，也不是可改的结构（可改结构在 mechanism.html，那里仍是自绘素材）。产品名 Hellos 换成占位词 Holes，由原作字母剪拼，接缝处略不自然，比原词短一个字母；标题角色名换成 Crumb，字形和粗细与原版略有不同；地图卡片里的小字 Toasty 没有换。聊天段是真实元素，文字比原视频锐利，气泡位置差约 2px。
