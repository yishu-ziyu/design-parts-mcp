# applecut — 一格一事：黑底 2×2 对照 Apple 产品片

来源：[x.com/leomeethewoo/status/2098033411000828007](https://x.com/leomeethewoo/status/2098033411000828007)，2026-09-10。原帖是 9.33s、3840×2160、60fps 的四分格剪辑，用来说明 Apple 产品片为何看起来贵。引用文章列出构图、字体、颜色、转场、声音五条。本页只收录第一屏：四段片子同时播，每格一件事。

打开 [index.html](index.html)。

## 机制逐条

- **原件**：视频，不是网页组件，也不是 WebGL。黑底 2×2，16:9。
- **本页播放 `#stage`**：`grid.mp4` 为 1920×1080 转码，循环、默认可自动播放（静音）。「重播」将 `currentTime` 置 0。
- **单格 `#solo`**：点一格 `transform-origin` 落到该角，`scale(2)`，0.45s `cubic-bezier(.2, .7, .2, 1)`。容器 `overflow: hidden`。
- **声音**：原片有配乐。自动播放必须静音；「声音」打开后取消 mute。
- **时长**：9.33s。时钟显示 `currentTime`。

## 可学 / 不学 / 启示

- **可学**：一镜一事；颜色只给产品或 UI；对照时用四分格同时播，比列五条原则更有效。
- **不学**：不要把四件事叠进同一镜再加发光背景。不要做抢戏的转场。不要用生成图代替原片。
- **启示**：空不是没做完。留白和对比在分配视觉权重。剪辑的工作是让人先看见产品。
