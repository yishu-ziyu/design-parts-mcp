# paperwave — 一张纸在点阵地面上起伏，纯 SVG 逐帧把 3D 点投影到屏幕，能拖起来、松手看波传开

来源：https://x.com/gabriell_lab/status/2112910045688279358 （Gabriel @gabriell_lab，2026-10-21，视频 25.5 s）。作者简介写的是「designer ex. Porsche & Audi」，个人站 ravalabs.com 是他的设计工作室 Rava Labs（站上写着 2024–2025 在 Weissach、2023 在 Ingolstadt 实习），没有代码或实验页。帖子原文只说了一句做法：纯 SVG，每个点投影进 3D 空间、逐帧重画，不用 3D 库。回复里有人问代码是否公开，他答「No sorry not public」；有人夸纸下的影子，他回「very important」；有人问每帧是不是按深度排序路径，他没回。引用帖里有人照这个思路做了莫比乌斯带，也没有原作代码。GitHub、CodePen 上搜不到他的相关仓库。所以下面所有数值都是把视频（X 给到的最高 1920×1440、60 fps）逐帧画进 canvas、在浏览器里读像素量出来的，不是读源码。哪些是量的、哪些是推断，表里分开写。

调性一句话：白底、黑细线、一张近白的纸，所有空间感都来自投影本身和几样辅助线：点阵地面、随高度变深的落地虚线、跟着高度变淡的影子。

打开 [index.html](index.html)。纸在动；把指针放到纸上会出现手柄和高度读数，按住往上拖再松手；底下五个药丸左右拖可以改参数。

## 这一页是什么

- 一屏的舞台：点阵地面、纸、纸下的影子、竖直虚线，底部居中一排五个数值药丸（Amplitude / Wavelength / Speed / Rotate / Tilt），没有别的文字。
- 拖纸：悬停显示灰色手柄和 `height` 读数，按下变黑，上下拖把那一块纸拉起来；松手后形变沿纸传开，到端点翘起再弹回，几秒后回到原位。
- 往下滚是「可拆」。
- 默认值：Amplitude 20、Wavelength 200、Speed 0.20、Rotate 145°、Tilt 20°。视频开头 Amplitude 是 0（先演示拖纸），之后大部分时间是 20，这里取 20 让纸一打开就在动。

### 拖纸的物理

把 0.3–3.0 s 的 41 帧前缘逐列读出高度（33 列），用一根带回复力、带阻尼、两端自由的弦去拟合：

| 项 | 拟合值 | 本页 |
|----|--------|------|
| 波速 c | 461–476 单位/s | 465 |
| 回复 k | 6.5–6.8 /s² | 6.6 |
| 阻尼 γ | 1.9–2.05 /s | 1.95 |
| 抓取范围 | 高斯 σ 32–38 单位 | 35，弹簧 6000、阻尼 150 |
| 松手 | 0.64 s | — |
| 误差 | 均方根 3.1 单位 | — |

## 怎么做的

- **一帧的流程**：先推进弦的模拟（固定步长 1/240 s），再算每个节点的总高度 = 模拟高度 + 正弦，然后投影 129 × 4 个点（纸的两条边、地面的两条边），写回 SVG 路径。
- **画家算法**：纸切成 128 条细带，每条是一个 `<g>`：填色路径 + 两段黑边。每帧按细带中心到相机的深度排序，顺序变了才重新 append。远处的边被近处的带子盖住，不需要另做消隐。横线挂在它两边细带里较近的那一条上，免得被盖掉半根。
- **接缝**：每条细带用和填色同色的 0.6px 描边盖住抗锯齿缝。
- **地面**：点阵只在 Rotate / Tilt / 尺寸变化时重算位置和淡出；影子是 128 个不透明灰块，颜色随各自的高度变。
- **辅助线**：34 根竖线和地面轮廓画在纸上面，每根单独设不透明度。
- **拖纸**：从最近的细带往后做点在四边形内的测试，命中后解 2×2 方程得到纸面上的 (x, z)。拖动时把以 x 为中心的高斯范围拉向「目标高度 − 抓点处的正弦值」，所以波照样从手里穿过。
- **显示值和画面分开**：药丸上的数字立刻变，画面上的 Rotate / Tilt / Amplitude / Wavelength 按 0.15 s 时间常数追。
- **省电**：振幅为 0 或速度为 0、弦已静止、没在追参数时停掉 rAF；滚出视口或标签页隐藏时也停。
- **减少动态**：`prefers-reduced-motion` 下波不走（静止的波形）、参数直接跳，拖纸照常，松手后 0.25 s 指数回落，不传波、不回弹。

## 三个判断

1. **消隐靠排序，不靠算遮挡。** 问题：21 s 那帧纸拱起来以后，远侧那条黑边在鼓包后面断开了，但竖直虚线又是穿过纸的。改法：黑边跟着各自的细带一起排序画，虚线单独一层盖在最上面。验证：21 s 对比图里远边断开的位置一致；7 s 平稳段黑线平均偏差 1.21 px（1920 宽视频像素）。
2. **画面在追数字。** 问题：11.4 s 那帧按显示的 69° 重画，波的相位从 0 试到 0.95 都对不上，最好也差 27.9 px。改法：把角度也放进搜索，80° 时只差 2.1 px；结合当时的拖动速度，推出画面以 0.15 s 的时间常数追显示值，就加了这一层追随。验证：11.4 s 从 27.9 px 降到 2.12 px，其他静态帧不受影响。
3. **读数显示的是纸的高度，不是指针的高度。** 问题：按「拖到读数停止才松手（0.9 s）」去拟合物理，均方误差 24–57；而且读数从 0.66 s 起涨得越来越慢，像惯性。改法：把松手时刻当未知数一起拟合，得到 0.64 s，误差降到 9.7；读数改成那一点的实际高度。同一组参数直接套到 18–21 s 的慢拖，纸整体被带起的形状也对上了；再把抓取改成整块共用一个偏移（让波从手里穿过），21 s 的偏差从 14.0 降到 7.8 px。

## 用法

```html
<section id="stage">
  <svg data-pw="scene"><g data-pw="floor"></g><g data-pw="sheet"></g><g data-pw="guides"></g><g data-pw="probe"></g></svg>
  <div data-pw="controls"></div>
</section>
<script>
  const wave = createPaperWave(document.getElementById('stage'), {
    params: { amplitude: 12, rotate: 120 },   // 覆盖 CONFIG.params
    controls: true,                           // false 时不出药丸
    config: { shadow: { alpha: 0.1 } },       // 深合并进 CONFIG
  });
  wave.set({ tilt: 35 });                     // 画面追过去；加 { instant: true } 直接跳
  wave.pause(); wave.play(); wave.destroy();
</script>
```

- `createPaperWave(container, options) → { play, pause, set(params, opts), params, destroy }`。容器里有 `data-pw` 骨架就复用（本页就是这样，`#scene` 等锚点都在静态 HTML 里），没有就自己建。容器要有确定的宽高。
- `set` 只认 `amplitude / wavelength / speed / rotate / tilt`，超范围会被夹住，Rotate 会绕回 0–360。
- `destroy` 解绑所有监听、清空它画的东西。
- `_debug` 是测试钩子（重置、按秒推进物理、脚本化抓取、投影函数），对比渲染全靠它。

## 接入（file:// 直开，运行时零网络）

- 没有外部脚本、没有构建，一个文件。`grep http index.html` 只剩 SVG 命名空间字符串。
- 字体取自 `npm pack --registry=https://registry.npmjs.org`，latin 子集，OFL-1.1，`@font-face` 相对路径 + `unicode-range`：

## 可拆

页尾「可拆」写了五块：`#scene`（正交投影 + 细带画家算法 + 法线明暗）、`#floor`（屏幕空间淡出的点阵 + 按高度变淡的影子）、`#guides`（按高度变深的落地虚线）、`#probe`（拾取纸面点 + 高斯抓取 + 阻尼弦）、`#controls`（左右拖的数值药丸）。

## 可学之处

- 「3D」只需要一个投影函数加上排序。纸只有一个方向在弯，所以每条细带整宽一样高，按带排序就是对的，不用逐面比较。
- 空间感靠辅助信息叠出来：地面点阵给方向和尺度，落地虚线和影子给高度，而且这两样都随高度变化，一眼就能读出纸离地多远。
- 控件显示的数字和画面分开：数字跟手，画面平滑追，拖得再快也不跳。
