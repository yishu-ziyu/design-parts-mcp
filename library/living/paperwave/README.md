# paperwave — 一张纸的波，全是 SVG

来源：[x.com/gabriell_lab/status/2112910045688279358](https://x.com/gabriell_lab/status/2112910045688279358)，2026-10-21。原帖 25.5s：一条纸带在五个数值下起伏。原帖代码未公开，算法和代码为本页自写。

## 机制逐条

- **高度**：`z = 振幅 × sin(2π x / 波长 + 相位)`，相位随时间走。
- **投影**：每点绕竖轴旋转，再按俯角压到 2D，每帧重写 SVG 路径。
- **深度**：条带从后往前画；亮度取坡度，不用光照模型。
- **胶囊**：按住左右拖改值；方向键也能改。默认 Amplitude 20、Wavelength 200、Speed 0.20、Rotate 145°、Tilt 20°。

## 可学 / 不学

- **可学**：简单的三维感不需要 3D 库。把几何算法和 SVG 分开，便于调参。
- **不学**：点数太多时逐帧重写路径会掉帧，不适合大面积或多实例。
