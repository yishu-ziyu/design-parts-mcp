可拆

#scene
纯 SVG 的 3D：每个点用正交投影手算到屏幕，sx = ox + s(x·cosθ − z·sinθ)，sy = oy − s(sinT(x·sinθ + z·cosθ) + cosT·y)，θ = Rotate，T = Tilt，没有透视，平行线始终平行。纸是 660 × 176 的长条，沿长度切成 128 条细带；每帧按细带中心到相机的深度从远到近重排再画（画家算法），每条带自己带着两段黑边，所以纸拱起来时远处的边被近处的带子挡住，不用另做消隐。带子颜色由法线和视线的点积 f 决定：f ≥ 0 时从 rgb(228,228,235) 线性亮到白（f = 0.565 时到顶），f < 0（看到纸背）换成淡紫灰 rgb(235,234,242)。Rotate / Tilt / Amplitude / Wavelength 的显示值立刻变，画面按 0.15 s 时间常数追上去。
#floor
地面：30 单位一格的点阵，x ±660、z ±330，点半径 0.85px、黑 33%，按屏幕上离投影中心的距离淡出（158 → 471 个单位乘缩放，线性）；纸下的影子也按细带画，每条的深浅跟它自己的高度走，α = 0.13·e^(−y/150)，纸抬得越高影子越淡。
#guides
透视线：两条长边每 1/16 长度一根竖直虚线落到地面，加上地面轮廓虚线，画在纸的上面，像 X 光一样穿过纸。虚线 3.5 4、1px 黑，不透明度跟那一点的高度成正比 min(0.6, y/120)，远侧那条边再乘 0.57：纸贴地时几乎看不见，抬起来线就变深，高度和前后都读得出来。
#probe
拖纸：从最近的细带往远处找指针落在哪条带里，反解出纸面上的点 (x, z)，显示手柄（半径 2.9）、落到地面的虚线、地面小点和 height 读数（11px 等宽，前灰后黑）。按住上下拖，以抓点为中心、σ = 35 的高斯范围被弹簧拉到指针高度，波照常从手里穿过；松手后按带回复力的阻尼弦传开：波速 465、回复 6.6、阻尼 1.95，两端自由，脉冲到端点会翘起来再弹回。
#controls
五个可左右拖的数值药丸（Amplitude / Wavelength / Speed / Rotate / Tilt），底边离容器 48px、间距 8px、居中：药丸高 32、圆角 16、左右内边距 14、底 #f1f1f3，悬停和拖动时 #e7e6eb；名字 12px 无衬线灰，数值 12px 等宽黑、右对齐、最小宽 25px，名字和数值隔 10px。指针变成左右箭头，键盘方向键也能调，Shift 一次 10 步。
