# Desk Objects

含原作素材，只留本机。

来源：Hal（@hal__lee）https://x.com/hal__lee/status/2083196877714112560 （2026-11-05 查看；原帖是本地开发录屏，没有公开页面）。

## 机制
- 个人主页做成书桌：小票、履历卡、两本书、贴纸和留言机，全都能拖。
- 绿色底上 20px 网格，容器宽高用 round() 取整到 20 的倍数，不会露半格（作者在被引用的帖子里讲的做法）。
- 点物体：物体居中放大，其他东西模糊 14px，Esc 或再点一下回去。
- 点书：先放大到 1.28 倍，再绕书脊翻开封面（.75s）；点右半翻下一页，点左半翻上一页。
- 贴纸：从边缘按住拖，沿中垂线折起，背面翻出来带阴影；松手 .45s 贴回。
- Organize 把所有物体送回原位。

## 和原版的区别
- DM Sans 本机没有，用 Figtree；书名、贴纸、头像是原帖截图。
- 公司名和 Logo 换成占位（水印是简单形状）；浏览器外框没有复刻。
- 折叠和翻页的曲面感比原版平：原版纸页有轻微弯曲，这里是刚性旋转。
- 留言发送只做了一个简单反馈，原帖没有演示这一步。

## 可学
- 把个人信息放进有物理感的物体里，操作本身就有趣。
- 焦点模式用模糊而不是遮罩，上下文还在。

## 不学
- 主要信息藏在物体里，手机上和读屏工具都要另做一份。
