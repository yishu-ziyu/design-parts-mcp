# quiet-blocks — 十块页面，一次只看一块

来源：自己整理的页面组块。十块分别是顶栏、首句、说明、字标、数字、作品、引言、报价、信、收束。视觉规则来自同一套笔记里已经写过的三条：少做、组内比组外近、颜色只用明度分层。不是任何公开网站的复刻，不含第三方字体、图片或品牌。

## 机制逐条

- **一次一块**：左侧点名，其余 `hidden`。要看整页，就把这十块按原顺序叠回去。
- **三种字号**：14 / 16 / 20。1rem = 16px。标题 1.25rem，行高 1.2。
- **间距**：组内 0.5rem，组间 2rem。按钮左右留白 1rem，按钮之间也是 1rem，上下留白 0.5rem。
- **明度**：页面 0%，卡片 5%，可点表面 10%。文字 92% 和 60%。
- **强调色**：`hsl(211 90% 56%)` 只出现在主按钮上。

## 可学 / 不学

- **可学**：组块可以单独打开；同一套字号、间距、明度换内容还能用。
- **不学**：不要把某一站的句子、字标、荧光点缀一起搬过来。这块只保留结构和规则。
