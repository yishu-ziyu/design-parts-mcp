# icon-toggles — 带自定义图标组的开关和选择控件

来源：[x.com/shivraj_roy10/status/2091847990424047634](https://x.com/shivraj_roy10/status/2091847990424047634)，读取日期 2026-11-05。帖内 20 秒视频，以及帖子外链的公开站 https://bloom-color-picker.shivrajroy.in （页面标明 MIT）。图标路径、CSS 数值、四组调色板取自该站页面；控件的弹簧常数在它按需加载的脚本里，我没读到。

## 机制逐条

- **图标组开关：** 46px 高的灰底条，右侧白色小托盘放 30px 图标按钮，选中项变深色，14×2px 粉色短线滑到它下方。
- **图标同一语言：** Motion 三枚用同一个小球和不同曲线表示无、微弹、强弹；Theme 三枚都是灯泡；Disabled 用花加一条斜线。
- **就地展开：** Palette 收起时只留当前项，点箭头后其余项 max-width 从 0 展开、模糊散去，标题淡出，箭头变粉框确认钮。
- **翻页色块：** 30px 高的窗口里两排色块上下错动，箭头上下两段分开弹动。
- **整条滑块：** 按下才显示刻度和手柄，拖过两端时整条被拉长，松手弹回。实测基准宽 329.5px，过拉到 343.5px，松手恢复 329.5px。
- **滚动渐隐：** 列表顶底按滚动进度各自渐隐，渐隐高度为可视高度 20%。
- **开花：** 色块放大成圆盘，12 + 6 + 1 片花瓣按原站延迟错峰入场，旁边弧形滑杆调明度。

## 可学 / 不学

- **可学：** 图标比文字更快说明差别时，给每个选项画一枚同语言的图标；选择器就地展开，不弹层，版面不跳。
- **不学：** 图标含义靠猜的场景不要照搬，要配 aria-label 和提示。开花取色器占位大，不适合密集表单。

## 和原版的差距

控件版式、尺寸、字体、配色和图标路径与原版并排几乎重合。差距：控件的弹簧常数和滑块过拉曲线是估计值；手写体标注 The Crafter 和页面其余面板没做；代码面板的展开是简化过渡。
