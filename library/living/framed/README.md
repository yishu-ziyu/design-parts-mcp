# framed — 一段素材 + 一层点阵纹理 + 高清输出 + 一个克制的画框，四步各有开关

来源：https://x.com/davidhaz/status/2111174599002198309 （David Haz @davidhaz，React Bits 作者，2026-10-17，视频 1280×720、28.3 s）。推文原话是一个四步清单：挑一段合情绪的素材 → 过一遍 Texture Lab 选个风格 → 4K 导出 → 围着它搭界面，做框、从简。视频是同一段湖景素材配九个界面（订房页、播放器、手机三连、404、活动报名页、风格选择器、天气卡、居中 hero、登录页）。他在回复里给了 Texture Lab 的链接 https://reactbits.dev/tools/texture-lab （160 种风格，每种有 Strength / Size / Density / Glow 等滑杆，可以叠 Blur、Adjust、Grain 图层）。**事实**：清单四步、九个界面的版式、素材是一段湖上划船的镜头（回复里有人提到 pixabay）。**没找到**：他用的是 Texture Lab 里哪一个风格、具体参数、九个界面的源码。**推断**：视频里的纹理是格点上的稀疏亮点 + 暗点（类似有序抖动），我按截帧反推参数，不是读的源码；Texture Lab 里的「Dot matrix」是满格点阵，和视频不一样。

## 这一页是什么

- 复刻视频 t=15 s 那一屏（活动报名页）的版式：浅米色面板、两行衬线大标题、右侧一小段说明、圆角画框里的点阵湖景、底部三栏信息 + 一个深色按钮。
- 产品是虚构的 **Coldwater**（湖边的写作周），文案、品牌全部自己写；湖景是程序画的（山、树线、水面碎光、慢慢漂的小船），没有用原视频素材。
- 底部一条开关栏，四个开关一一对应清单四步，外加「全部」。键盘 1–4、0 同样能切。

## 怎么做的

- **素材和纹理分开**：素材画在离屏 2D canvas（开 4K 时 960 px 宽，关时 320 px），每帧作为纹理传给一个全屏 WebGL 片元着色器。
- **纹理**：`cell = floor(px / 6)`，在格心采一次色；底图是平滑原图混 30% 的 5 级色阶；亮度乘 4 取小数部分，和 4×4 Bayer 阈值比，高出 0.22 在格心画提亮方点（混向 `hi`），低出 0.5 画压暗方点（混向 `lo`），其余格不画。
- **第 1 步关**：素材换成一段快速移动的霓虹色块 + 斜条纹，文案不变。
- **第 3 步关**：画布缓冲区降到 0.32 倍再由 CSS 拉伸，点会糊；角标显示当前缓冲区尺寸。
- **第 4 步关**：同一套内容换成常见做法：满屏素材、黑色渐变遮罩、居中大写无衬线标题、毛玻璃胶囊、渐变按钮。切换时整块先淡出 180 ms 再淡入。
- 30 fps 节流；画面滚出视口暂停；`prefers-reduced-motion` 时停在固定一帧，开关仍然生效；没有 WebGL 或着色器链接失败时用 2D 直接画素材（没有纹理）。

## 三个判断

1. **点太密 → 改成稀疏阈值**。第一版每格都画点（不是亮就是暗），放大对比看像一张均匀网格。原作水面大约三成格子有亮点、少量暗点，其余格露出底图。改成只在超出阈值一段时才画点，再对比同一位置的 2× 截图，密度接近。
2. **色阶在格心取值 → 改成对平滑图取值**。第一版把格心颜色做 5 级色阶当底图，山和树变成一块块马赛克；原作底图是连续的。改成对平滑原图取色阶、只混 30%，同一处放大对比马赛克消失。
3. **画布被清空 → 尺寸不变就不重设**。Playwright 截图偶尔是空画框：ResizeObserver 回调里重设了同样的 `canvas.width`，WebGL 缓冲区被清空而这一帧还没画。改成尺寸真变了才赋值，连续三轮截图都正常。

## 和原作的差距

- 最大的差距是素材本身：原作是真实湖景视频，树、水波、阳光反射都有细节，点阵落在这些细节上才显得「贵」；这里是程序画的卡通湖景，纹理只能落在比较平的色块上。换成真实视频（素材画进离屏 canvas 即可）这一条就不成立。
- Texture Lab 具体用的是哪个风格没有确认，阈值和点大小是从截帧反推的。
- 只复刻了九个界面中的一个（活动报名页）；视频里界面之间的转场没有做。
- 原作亮点偏圆，本页是方点。

## API / CONFIG

- `createFramedHero(container, options)` → `{ set(step, on?), get(), destroy() }`。`step` 是 `clip` / `texture` / `hires` / `frame` / `all`，`on` 省略时取反。
- `CONFIG`（页顶）：品牌、标题两行、说明、三栏信息、按钮文案、四个开关的中文标签；`texture.cell`（格大小 CSS px）、`dot`（方点半宽，单位格）、`levels`、`poster`、`posterMix`、`hi` / `lo`（提亮 / 压暗目标色）；`hiresSource` / `loresSource` / `loresScale` / `maxDpr`。
- 测试钩子：`window.__framed`。
- 字体：`fonts/` 下 Newsreader 400/500、Inter 400/500，取自 `@fontsource/newsreader` 5.3.0、`@fontsource/inter` 5.3.0（latin 子集，OFL-1.1）。file:// 直开，运行时零网络。

## 可拆

- `#clip` 素材要和文案同一个情绪。
- `#texture` 稀疏点阵纹理着色器。
- `#export` 高分辨率输出，缓冲区尺寸角标。
- `#hero` 画框版式 vs 满屏遮罩版式。
- `#steps` 四步开关栏。
