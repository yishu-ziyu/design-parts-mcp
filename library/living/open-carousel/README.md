# open-carousel — 粘稠的作品轮播

来源：[x.com/YousufSoomroDev/status/2088657289410687111](https://x.com/YousufSoomroDev/status/2088657289410687111)，读取日期 2026-11-05。帖内 44 秒视频，以及作者在回复里给出的开源仓库 https://github.com/Yousuf-developer/Viscose-carousel （MIT，许可证见 LICENSE-viscose.txt）。着色器和参数从仓库移植，去掉 Three.js 和 GSAP，改成原生 WebGL2。18 张卡片图从帖内视频暂停帧裁切摆正（`source-assets/cards/`），不再自绘。仓库现版已改成深色和大标题，这里按帖子视频的浅色版做。

## 机制逐条

- **一个全屏着色器：** 没有卡片元素，每个像素算到最近卡片的距离，smin 让相邻形状融合。
- **拉丝：** 相邻卡片之间有一条桥形距离场，随分离度变细、中段收窄、下垂，半径被推到负值后断开。
- **入场：** 种子卡生长并飞到半径上，其余卡分代剥离合成整圈，转一圈后放大 4.46 倍并左移，只留一段弧。
- **玻璃边：** 顶底各 8% 高度折射内容，邻卡在这里被拉成扫掠形状。
- **悬停：** 指针周围软化距离场，近处卡片靠过来并膨胀，其余退让变暗；靠近的速率 0.14，放开的速率 0.06。
- **文字融化：** 新旧文字各自模糊后过对比度阈值。
- **转动：** 滚轮和拖动带惯性，低于 1 rad/s 吸附到最近一格。实测滚轮后停在 Nightshift，goTo(10) 停在 Iris。

## 可学 / 不学

- **可学：** 把“融合”交给距离场，一个数 k 控制整体粘度；接近快、离开慢的不对称速率让动作显得粘稠。
- **不学：** 着色器开销不低，内容型列表不要用；索引列和键盘才让它可用，不能只留滚轮。

## 和原版的差距

环的位置、卡片尺寸、拉丝、玻璃边、索引列、两侧文字和 18 张图都接近视频；图是从视频暂停帧裁切摆正的，原始分辨率低，放大后比原版略软，图内原作品牌字样（favor、PRESTIGE 等）没有抹掉。标题字体 PP Neue Montreal 是商业字体，换成 Satoshi；点开卡片的项目页、视频播放、窄屏专用构图没做；入场时长按视频估算；Volt、Keycard 等 14 张的类别和年份未能从视频确认。
