# 对话里生成地图

来源：https://x.com/pitus_/status/2110421626873643338（@pitus_，2026-10-14）

复刻页：`index.html`。并排核对图：`原料/x-收藏/originals/2110421626873643338/compare.jpg`。

## 机制

- 正文逐词淡入，到冒号处地图接着出现：先公园，再街区，再标签、路线、卡片，最后才出下一段。
- 点标签或卡片左右箭头都换选中项；路线用 stroke-dashoffset 重画 700ms，地图同时微调位置。
- 右上角圆点悬停展开成主题条，悬停时左侧文字先显示主题名，点击才应用。
- 换主题时复制一层地图，用模糊边缘的圆形遮罩从中心展开，结束后替换底层并删掉复制层。
- 主题全部走 CSS 变量，含路线色和发送按钮色。
- 发送按钮三态：发送、发送中、已发送。

## 可学

生成式界面可以分步出现，并和正文节奏对齐；圆形展开让主题切换有明确的“换了”的感觉。

## 不学

地图是静态 SVG，不能缩放平移，不能当真实地图用；复制整层做切换，内容很重时开销大。

## 和原版的差距

版式、字号、颜色、标签和卡片并排几乎重合，主题也都有。差距：地图是我手绘的，树林形状和街道线只是近似，不是逐点相同；三张缩略图是自绘色块，不是原帖照片（规则不收）；Earth 主题在视频里只悬停没应用，配色是我按色块猜的；路线和入场节奏按视频估计。

## 素材处理

地图和缩略图全部自绘；“Send to iPhone”只是原帖文案，没有用任何标志。
