# month-memories

含原作素材，只留本机。卡片照片、贴纸和海报底图都是从原帖视频截的，不公开、不推送。

来源：kua（@kuuuuuuuuuua）2026-11-01 发帖 https://x.com/kuuuuuuuuuua/status/2116766785173364781 ，日本应用 Pimorio 的“月度回顾”，8.2 秒手机录屏。时间点和尺寸逐帧量出（步长 0.05 到 0.1 秒），源码未公开。

## 机制

1. 黑屏上先有 2026、OCTOBER，大号橙色渐变的 10 上浮淡入（0.08 到 0.42 秒）。
2. 1.2 秒起照片一张张从屏幕上方落下，每张有自己的倾斜（-7.5° 到 8.5°）。前一张压到 42% 亮度，再前一张 16%，更早的消失。
3. 节奏加快：前 7 张每张约 0.4 秒，第 8 张起每张约 0.1 秒。
4. 进度条按已落下的张数走，不按时间走，所以后半段走得快。
5. 最后一张停 1.4 秒。6.5 秒起海报淡入，同时放大到 1.037 倍过冲，7 秒回到原位；底部控件换成“閉じる”。
6. 7 到 8 秒 10 张白边贴纸逐张落下，每张先发白放大（1.16 倍，亮度 1.9，饱和度 .1），0.1 秒内回到正常。
7. 8.02 秒海报缩到 .954 倍上移，下方出现活动横幅和分享按钮。

本页按住屏幕 3 倍速（原版提示文字“長押しで早送り”），右下按钮跳到结尾，“閉じる”重播。`?t=秒` 定格。

## 可学

- 用加速的节奏把一个月压进 5 秒，前慢后快，前面看得清，后面只留感觉。
- 上一张不移走、只压暗，画面始终有层次。
- 贴纸发白再回色，比单纯缩放更像“贴上去”。

## 不学

- 19 张照片的切换太快，没法停下来看某一张（原版也只能重放）。

## 和原版的取舍

- Pimorio 的 Logo 和名字换成圆点加 Moments；分享按钮的 Instagram、LINE、X 换成几何占位，标签改成“ストーリー、チャット、ポスト”；横幅里的应用名改成“アプリ”。
- 标题用 Poppins ExtraBold（只有 800 一个字重），字形和原版接近但不相同。
- 贴纸是用相邻帧相减抠出来的，白边外缘偶有毛刺；标题压住的地方是透明的。
- 海报底图在标题区用同一张照片的小图放大补（放大 1.8 倍），被标题挡住，基本看不到。
