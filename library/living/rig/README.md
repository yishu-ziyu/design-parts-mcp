# rig — 镜头摇动 · 只剩相机的编辑视图

来源：判断记在 [../../km-camera-rig.md](../../km-camera-rig.md)（2026-09-13 记录 KM 的镜头摇动演示，已溯源到编辑器 mo1 / three.js WebGPU / Three.js Conf Paris）；页面整块从 [../nightflight/index.html](../nightflight/index.html) 的左窗格提取，不引入它的纸/黄铜卡片色。

调性一句话：打开只有镜头在摇——一台相机的编辑视图（视锥、虚线航线、路径点点火），没有渲染窗格。

## 这一页是什么

整页 = 原左窗格 rig，占满窗口（角标 `RIG · 编辑视图`），底部一条时间轴横贯：

- 斜投影线框视锥：apex + 四角 + 正面交叉线 + 朝向三角 + 六边形机身，沿虚线航线在夜摄照片墙上方滑行；
- 5 枚编号路径点（01–05）：相机到达时刻 `t ≥ TI[i]` 由空心变实心；起点只作航线端点，不占点；
- 段内 smoothstep，段间节奏不等长 `[0.20, 0.16, 0.24, 0.20, 0.20]`；
- 时间轴双向绑定：菱形刻度点跳、拖拽 scrub、`?demo=progress=X` 定帧、播完停末帧 + 重播按钮；
- 右上角一行 mono 仪表：`T 0.42 · HDG 126° · SEG 3/5`；朝向由视锥行进方向在世界坐标里算（0° = 朝航线深处，即 -z）；
- reduced-motion：不自动播、视锥直达末位、路径点全实、时间轴仍可拖。

## 色板（只有四个 hex）

| 角色 | 值 | 用在哪 |
|------|-----|--------|
| 夜底（暗） | `#0C121E` | 整页底盘、点阵、站号描边 |
| 夜底 | `#101827` | 底部时间轴 |
| 仪器黄 | `#FFD84D` | 视锥 / 航线 / 路径点 / 进度条 / 仪表 |
| 月色 | `#F7F3EA` | 文字、刻度、播放头 |

照片墙的灰白只用上面两色的 alpha 变体（`rgba(247,243,234,…)` / `rgba(12,18,30,…)`），没有第五个基色。nightflight 的纸 `#F2E9D8` / `#E7DCC6`、黄铜 `#C99A3C`、红 `#C84B3B` 一个都没进来。

## 与 flycam / nightflight 的关系：本体 vs 投影

[../../km-camera-rig.md](../../km-camera-rig.md) 的判断：**左边比右边重要**。rig 视图是设计本体；右窗格只是它的投影，内容可以整体替换（旅行板、证据墙、观星台都成立且都次要）。

- [flycam](../flycam/index.html)：两窗格版本 1（物件拼贴墙 + 求职内容）；
- [nightflight](../nightflight/index.html)：两窗格版本 2（深夜观测台 + 暖纸黄铜）；
- 本页：**本体单独成页**——相机、航线、点火、时间轴一行未改，右窗格与 5 张卡片整体删掉。

## 单窗格取舍

- 删：`#flight`（真透视窗格）、`#scene` 与手记卡/月相卡/星图卡/星轨片/终卡、红绳、星尘、银河、逐字打字、星点脉动，以及只服务右窗格的 `rproj` / `PERSP` / 每帧取尺寸对齐。
- 留：世界坐标与站点表、`eproj` 斜投影、视锥与朝向三角、虚线航线、照片墙 9 张、路径点点火、时间轴与防跳变手法（纯函数 `render(t)`、拖拽 pointer capture、demo 定帧、reduced-motion）。
- 新写三处：
  - 取景：内容安全框（照片墙四角 + 视锥全程扫过的范围 + 站号占位）按窗格比例缩放到整页，窗口再扁再窄也不裁掉任何照片/路径点；点阵网格跟着世界缩放；
  - 窗口 resize 时立刻重画：暂停或停末帧时不会停在旧尺度上（reduced-motion 首帧就靠这条对齐）；
  - 站号落位：斜投影里 01 与 03 只差 24 单位，固定右上会被 03 的六边形盖掉一半——站号自动躲开别的站点与航线，并描一圈夜底描边，被视锥线穿过时仍可读。
- 没有右窗格，「每帧重取尺寸」不再是对齐投影，而是窗格比例变化时取景不跳。

## 可学之处

- 一个机制拆成「本体 + 投影」两页更干净：观众看的其实是导航（相机在哪、去过哪、要去哪），不是渲染结果。
- 站号（01–05）是隐藏功臣：它把一根黄线变成可读的行程。
- 时间轴与相机同吃 `render(t)`：scrub 的每一帧都是纯函数，没有「碰巧对上」的双动画。
- 取景可以写成对内容安全框的缩放，而不是固定 viewBox：整页只装这一块时，任何窗口比例都不裁内容。

## 不学之处

- 不为了撑场面把右窗格内容搬回来——内容再多也救不了走位难看。
- 不留纯装饰黄线：没有点火次序、没有编号，rig 就死了。
- 不引入纸/黄铜色：本页只有夜底 + 仪器黄 + 照片墙灰白 + 一点月色。

## 启示

一句话：**它是相机的仪表盘，不是相机的照片。**

## 可拆

本页与 flycam / nightflight 同机制（可见相机 rig + 虚线航线 + 路径点点火 + 双向时间轴），这里只剩本体；页尾「可拆」芯片写明同一件事。要换世界改 `WPTS / SEGS / PHOTOS` 三个数组即可。
