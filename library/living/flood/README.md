# flood — 进度铺满整张卡

来源：[x.com/itschatto/status/2096962716036472894](https://x.com/itschatto/status/2096962716036472894)，2026-09-07。原帖 16.1s、1600×1200、60fps。Create UI 的 File Upload：淡紫色从左边灌进整张文件卡。本页收文件卡。商标和六个框架圆点不收。

打开 [index.html](index.html)。

## 机制逐条

- **房间**：底 `#e4e4e6`。卡白，圆角 24px。完成后浅灰托盘 `#f2f2f4`，圆角 28px。
- **灌色 `#flood`**：从左变宽。`#e6eaff` 到 `#dcd6ff`。0% 最小宽 16px。暂停和完成时透明度收到 0。
- **细条 `#bar`**：高 5px。上传 `#7064f6`，暂停 `#3a3a40`。完成前收到右边。
- **时序**：0→65% 5s，暂停 1.1s，65→100% 4.5s。完成后再 600ms 长出 Change / Download。
- **文案**：`Uploading 27% · 0.5 MB of 2.3 MB`。暂停改 Paused。完成改 Completed，绿勾，暂停和关闭换成垃圾桶。

## 可学 / 收窄 / 启示

- **可学**：进度铺在物件上。暂停先拿掉灌色。状态用最短的词，不要另写标签。
- **收窄**：标本只收这一张文件卡。投放区走 [minifolio](../minifolio/index.html)。
- **启示**：细条只是回声。拿掉灌色，暂停才站到第一层。
