# folder-open

来源：@AdityaSur11 的 Document folder animation，https://x.com/AdityaSur11/status/2114001465207669220 。取样日期 2026-11-05（看视频，开合段每 0.1 秒取一帧）。

## 机制

- 悬停开门：两片门转 98°，邮票从口袋里升起，下半截被口袋挡住。
- 点击取出：邮票升到最高点后换层，边放大边落到合上的文件夹前面。
- 悬停邮票：后一张滑出来；点空白或文件夹放回，顺序相反。
- 关着时门缝留约 1px，里面的邮票露出一条白边。
- 减弱动效时，所有状态直接切换。

## 可学

- 门缝的白边用真实层叠得到，不是画出来的线。
- 动画中途换层时选一个位置不重叠的时刻，就看不出换层。

## 不学

- 原视频的邮票插画不收，这里是自绘：麻雀、波纹和日文排版都是重画。
- 系统鼠标指针是录屏带的，不复刻。

## 和原版的差距

邮票插画是自绘，麻雀和波纹明显比原版简单；日文依赖系统明朝和黑体，不在本目录；缓动是看帧调的。

测试参数：`?s=shut|peek|out`、`&fan=1`、`&tilt=<度>`。
