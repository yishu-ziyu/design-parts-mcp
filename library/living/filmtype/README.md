# filmtype — 电影字体档案站：暗色开场轮播撑满上推，进到浅色列表，悬停弹帧，点开横向走帧带时间码尺

来源：https://x.com/VibeEverything/status/2111438994500375009 （LOOPY @VibeEverything，2026-10-17，韩文推文，介绍一个收集电影里字体的档案站，附站点录屏）。站点链接在作者自己的回复卡片里：https://fontsinmovies.com 。站点是公开的 Nuxt 应用，下面的数字是在 Chrome 里打开它、读 DOM 计算样式和 `:root` CSS 变量量出来的（事实）。没有找到作者讲做法的文字，也没有仓库。作者只是转介绍，不是站点作者；站点作者没查到（未知）。开场「滚一下就撑满再上推」的分段时序是看截图和 CSS 变量名（`--tp-im-*`、`--tp-im-fake-scroll-*`）推的，没读到 JS 里的具体编排（推断）。

这一页只复刻版式、浏览交互和转场。片名、帧、文案、站名都是自己编的：14 部虚构电影，每部 2–4 帧，每帧用 CSS 背景加一种免费字体画出来，没有任何真实剧照或海报。

## 怎么做的

1. **开场**（`#intro`）：固定全屏暗色层。主帧放在 6 列网格的中间三列，背后全屏铺**下一部**的帧，亮度压到 42%（原站 DOM 里就是 `intro-featured-poster--active` 在格子里、`--next` 铺满全屏）。每 4.5 s 换一部：前后两层都 1 s 交叉淡入，标题先下沉淡出再换字。第一次向下滚轮、下键或点底部 ↓，背景层用 `clip-path: inset(6% 8% 8% 7%)` 收成带深色边框的画面并提亮，主帧缩到 0.88，然后整块往上推走，露出下面的浅色页。
2. **刊头**（`#masthead`）：三个词用 `space-between` 铺满一行，字号 12.1vw。
3. **列表**（`#list`）：5 等分网格，片名跨中间三列。悬停时片名两边的「+」向外滑出，第 4 列从中线上下展开一帧预览。行进入视口才淡入。
4. **工具条**（`#toolbar`）：列表和图片视图切换，按年份、片名、帧数排序，再点同一项反向。切换时整块淡出 0.167 s 再重画。
5. **单片页**（`#film`）：帧横排成一条，当前帧钉在 44.7vw。滚轮、方向键、点帧、左右滑都走一帧，1 s 平移。底部时间码尺上每帧在片长里的位置有一个点，当前点变红，时间码标签跟着滑过去。
6. **帧**（`.still`）：`container-type: inline-size`，字号用 `cqw`，所以同一帧在 20% 宽的预览和全屏开场里排版比例一样。

## 关键判断

1. **开场离场方向做反了** → 第一版让主帧撑满全屏，对照原站滚动瞬间的截图（cmp6）才看出来：主帧几乎不动，是背后那张全屏的「下一帧」收进一个带边框的画面。DOM 也对得上：`--next` 那层是 1650×1001 全屏。改成背景层 `clip-path` 收边 + 提亮，主帧缩 0.88。验证：cmp6 两边同一时刻的层次和边框位置一致（原站边框约 左 7% 右 8% 上 6% 下 8%）。
2. **假帧怎么在任意尺寸下都像同一张图** → 用 px 写字号，预览缩到 300px 宽时字会溢出。改成容器查询单位 `cqw`，帧是多大字就按比例多大。验证：同一帧在列表预览、图片视图、单片页里三种尺寸截图排版一致。
3. **单片页走过的帧压在左侧标题上** → 原站当前帧左边是空的；我第一版让走过的帧留 18% 透明，盖住了左边的片名。改成完全透明。验证：cmp5 左侧干净。

## 和原站的差距

- 开场的「假滚动」只能按截图和变量名推时序，原站里撑满和上推是否同时进行、上推是不是 2 s，没读到 JS 确认。
- 原站开场背后是真实剧照，四周有画面内容；本页的假帧是居中的一组字，铺满全屏后大半被主帧挡住，背景显得空。
- 原站单片页的时间码尺带较密的长短刻度和每帧的小灰点簇，本页只有等距刻度和每帧一个点。
- 原站单片页左侧没有片名信息，本页加了片名、年份和这一帧用的字体，属于自己的改动。
- 正文用 Inter Tight 代替 Overused Grotesk，字形更窄一点。
- 没做原站的路由（每部片独立 URL）和返回时的页面转场。

## API / CONFIG

页面顶部 `CONFIG`：

- `brand.pre`：开场标题上方的小字；`brand.blurb`：刊头下的说明。
- `featured`：开场轮播用的片 id 列表；`introInterval`：换片间隔（ms）。
- `films[]`：`{ id, title, year, runtime(分钟), frames[] }`；每帧 `{ tc(秒), cap, bg(CSS 背景), font, style, weight, text, size(cqw), ink, fx: 'neon'|'glow'|'shadow'|'block', rot, x, y, sub }`。

```js
const api = createFilmArchive(document.body, { featured: ['orbit-diner'] });
api.openFilm('copper-moth'); api.go(1); api.closeFilm();
api.setView('grid'); api.leaveIntro(); api.destroy();
```

`prefers-reduced-motion: reduce` 时所有过渡压到 0.01ms，开场直接切走。字体全部从 @fontsource 取 latin 子集放在 `fonts/`，file:// 直开，运行时零网络。
