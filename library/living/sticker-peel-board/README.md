# 贴纸揭起板

来源：@workcinprogress https://x.com/workcinprogress/status/2112800799361221074（查看于 2026-11-05）。原帖是一段 9 秒视频，作者说明用 Claude Code 和 GSAP 做。

## 机制
- 折叠：抓点 G 固定在贴纸边缘，指针 P 移动。折线是 G 与 P 连线的中垂线。线这一侧的贴纸不动，另一侧按该线做镜像，并画成灰白背面。
- 底纸：格子贴纸揭开时，下面露出同形状的灰色底。贴纸整张离开后，这块底还留在格子里，松手才弹回新贴纸。
- 离开：指针离贴纸中心超过半对角线加 58px，贴纸整张跟手，带投影和轻微摆动。
- 回弹：没拉够就松手，P 用弹簧回到 G。
- 声音：用 WebAudio 合成带通噪声，没有音频文件。原版的音效未核对。

## 可学
折叠只用一次反射矩阵和两次裁剪，不需要网格变形，也不依赖动画库。像素风靠小画布加阈值和色阶，再放大时关掉平滑。

## 不学
贴纸只有单层硬折，没有原版那种纸面起皱的高光。

## 替换和差距
原版的 Hello Kitty 换成自绘白猫。其余贴纸也都是自绘。视频顶部露出的外部工具栏不是这个部件，没有复刻。字体是 Playfair Display Italic，属目测选定，不确认与原版同款。
