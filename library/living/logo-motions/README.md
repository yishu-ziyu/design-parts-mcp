# 四个标志动效

来源：@yui540，https://x.com/yui540/status/2089212378982584648 ，2026-08-17。视频 13.38 秒，2:1，四格同时播放。  
复刻日期：2026-11-05。

## 机制

- 四格两种循环：左列 8 秒，右列 4.5 秒，所以两边错开，不会同时结束。
- 左上：角色从一条看不见的基线后面冒出，只露耳朵时压扁回弹三次，再整只升起；字母从右边转着进来，把它挤到左边；i 的点先出现，再换成爱心。
- 左下：角色先从一条竖线后面斜着探头，缩回去，再从左边淡入；第二只闭眼的把它推到字上，用背景色盖住被挡的字母，最后两只合成一只，副标题淡入。
- 右上：四个小图标抛起再落向中心，消失的同时一本书弹出来；书飞出右边，再从右边回到左侧，文字跟着它的右边缘露出；颜色逐个字母从浅橙扫到红再到深棕，书同时换成对话框。
- 右下：一条线里掉出三枚硬币堆起来，线飞到右边变胶囊；硬币再弹起，砸进移回中间的胶囊，胶囊鼓起来变成徽章；徽章先退到左边，字母从下方跳出，把徽章推回右边。

页面全部用 Web Animations API 写成，可用 `?t=秒` 定格；点击画面从头播放。

## 可学

- 硬切比补间更有节奏：很多地方用 `steps(1)` 瞬间换形状，下一拍才用弹性缓动。
- 用背景色填充的形状当遮挡，不需要真正的蒙版。
- 让一个形状接力变成下一个形状（线、胶囊、徽章），观众的视线不会断。

## 不学

- 单个标志动效要 4 到 8 秒，放在产品里太长，只适合开屏或宣传片。

## 替换和没做的

- comimi、comilio、React 换成 nomimi、nomilio、Web；角色和字母按原版比例自己用线条重画。没有用原帖素材。
- 时间点来自 0.1 秒抽帧，每段中间的缓动是估计的。
