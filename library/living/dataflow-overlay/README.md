# dataflow-overlay — 在组件树上画出数据流向

来源：[x.com/aidenybai/status/2097174528267092360](https://x.com/aidenybai/status/2097174528267092360)，2026-11-05 看原帖视频（15s，1596×1080）。原视频按 2 倍录制，这里 1 CSS px 对应视频 2px。没有原站或代码，机制按视频反推。

## 机制逐条

- **树**：等宽字，行高 28px，缩进 21.5px。节点形状区分类型：实心函数组件，空心元素，方框错误边界，菱形第二种组件。属性行没有节点，贴着父亲的竖线。
- **悬停**：鼠标停在一行上，这条流上的相关曲线全部出现，相关组件变白，当前行变色。
- **三种线**：蓝实线是数据，紫虚线是回调，绿点线是外部 store 订阅。曲线画在树左侧，不挡文字；短线两端水平出入并向左鼓，长线贴树走到目标才横向进入。
- **标签**：鼠标所在位置附近的那段曲线写变量名（query、item、render、call、action、snapshot.count）。
- **Context**：悬停 Provider 或消费者，子树整块罩上青绿框，横线直连消费者。
- **提示**：停留 800ms（估计）后鼠标下方出现完整字段名。
- **折叠**：有子节点的行悬停时左侧出现箭头，可折叠子树。视频里只出现箭头，没有演示点击。

## 可学

- 只在悬停时画关系：平时树很干净，要看才出现。
- 线型编码类型，不靠图例也能分清数据和回调。

## 不学

- 这里的树和流是写死的演示数据，不是真正分析 React 应用得到的。
