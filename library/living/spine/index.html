可拆

#accordion
手风琴不对称时序：点「任务」toggle aria-expanded，子容器联动 inert。展开 300ms ease-spring（linear() 弹簧曲线），收起 200ms ease-in-out；子导航高度 0 → auto 过渡靠 interpolate-size:allow-keywords。收合箭头 rotate:-90deg，展开转正。
#spine
脊柱条：子导航左缘 10px 宽条，--bar-height 是注册过 @property 的长度，才能被 transition。悬停第 i 个子项长到三档 10/47/84px，升高走 0.3s spring、缩没走 0.1s ease-in-out；pointerleave 时先 commitStyles() 再 cancel() 取消进行中的过渡，防跳变。
#dot
滑动光点：6px primary 圆 + box-shadow:0 0 10px 辉光，translate 三档 0/37/74px 对应当前子项。初次出现或无当前项 = instant（data-instant 属性 + offsetHeight 强制 reflow）；已显示才 0.2s ease-in-out 平滑滑动。点叶子项 data-current 迁移，光点滑到新位。
#sfx
合成音：Web Audio 正弦超短包络，pop（400→200Hz 扫频，gain 0.1）= 父项开合、tap（1200Hz，gain 0.08）= 叶子选中、swoosh（600→1400Hz，gain 0.05）= 新建会话。AudioContext 首次手势惰性创建。右下角可关。
