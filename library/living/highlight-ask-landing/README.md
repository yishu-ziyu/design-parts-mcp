# highlight-ask-landing：选中一行就问的阅读工具

来源：[@nutlope 2026-10-09](https://x.com/nutlope/status/2108754717912244472)，产品名 Gloss，1 分 48 秒演示录屏。

打开：`index.html`，粘贴任意链接后按 Read。`?view=` 可直达 `landing-typed`、`loading`、`select`、`explain`、`notebook`、`look`、`text`，`?theme=paper` 换主题。

这个页面没有接模型：回答是写死的两段文字，粘贴任何链接都进入同一篇示例文章。文章段落取自录屏里能看到的部分，只用来核对排版，真正使用时要换掉。

## 机制

1. 标语一个词铺底色，划线从左向右画入。
2. 输入框三态：空、可读、读取中。读取中文字换成 Reading 加域名，按钮下方走进度线。
3. 松开鼠标时读真实选区，工具条放在选区上方，箭头对准选区中心。
4. 回答卡片和选中的行同高，引线连回原文。结论句高亮，再逐词流出其余内容，新回答出现时旧卡片收成一行。
5. 左侧竖条是全文缩略、当前视口和回答位置。
6. 主题切换整组颜色变量，笔色和荧光色按明暗主题各有一套值。
7. 笔记本打开时正文左移让位，问答和高亮按时间汇总。

## 可学

- 回答不离开原文的位置，读者不用切换视线和上下文。
- 结论句单独高亮，先给答案，再给依据和段落编号。
- 落地页的标语本身就在演示产品动作。

## 不学

- 合作方 Logo 已换成占位，文章和产品名只用于对照。
- 左侧刻度这里是随机生成的；真实实现要从段落长度计算。
- 笔记本只存在内存里，刷新就没了。
