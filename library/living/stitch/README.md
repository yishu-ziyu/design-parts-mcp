# stitch — 一个能拖着转的三维小模型，实时降采样成十字绣图样，右边是线色表和成品尺寸

来源：https://x.com/LottieCoxon/status/2110764430229225942 （Lottie @LottieCoxon，PostHog 平面设计负责人，2026-10-16，视频 43.8 s，1480×1080）。推文说她第一次用 Claude 做了一个把扁平矢量图转成十字绣图样的设计工具。她在回复里补了三句：一开始只是想把矢量图转成十字绣，能用，但针脚不够有立体感、文字渲染不好；所以让 Claude 专门做了一套字体，现在用在工具标题 cross purposes 上；最后让模型动起来，「Claude make this move」就做到了。没有找到 live 站、仓库或代码。下面的面板结构、数值、颜色都是从视频 2 s / 8 s / 16 s 三帧读出来的（事实）；「先按子采样渲染再每格统计覆盖率」「底针加深做立体感」是从界面上的 Sampling「Lines win」和 Line coverage needed 15% 反推的实现（推断）。

## 怎么做的

1. 离屏 canvas 按 `格数 × 6` 的分辨率画三维模型：面只用 4 个色调（白、浅、中、线/影），每个面描一圈深色轮廓。模型是自己做的小木屋（盒子 + 人字顶 + 烟囱 + 门窗），地面上投一块向左的影子。旋转是两层矩阵（yaw 绕竖轴、pitch 倾斜），面按深度从远到近画，背面剔除。
2. 每格 6×6 个子像素统计四个色调的占比。「Lines win」：深色占比 ≥ `Line coverage needed` 就整格绣深色，否则取多数色；「Majority」只取多数色。细线在降采样时不会断。
3. Thread colours 2 / 3 / 4 把四个色调合并到可用线色上。
4. 底下两行字在单独的低分辨率画布上按格写，阈值化后落到整格。
5. 每格画一个 X：先画左下到右上的底针（线色加深 22%），再画左上到右下的面针，格子够大时加一条浅色高光。白色区域默认不绣。
6. 右栏按实际针数出线色表：hex、RGB 距离最近的 DMC 编号、针数、束数；再出格数、针数、14ct 英寸和厘米尺寸。点色块用系统取色器换色。
7. 只在状态变了才重算；Spin 和 Smoke 开着时每帧重算。烟圈三个一组从烟囱升起，越高越大、轮廓变浅。

## 关键判断

- **问题**：直接把模型画成图再按格取中心像素，1–2 子像素宽的轮廓线大量丢失，屋檐断成虚线。**改**：照原作面板的「Lines win + Line coverage 15%」，每格统计深色覆盖率，过阈值就绣深色。**验证**：115 格、15% 时屋檐、门框、烟圈都是连续一格宽的线，深色格 1,777 个；拉到 60% 只剩 1,389 个，墙的竖线整段消失，只剩屋顶和影子。这正是原作把这个阈值做成滑杆的原因。
- **问题**：第一版字用 600 字重，在 115 格里笔画糊成块，和原作细笔画像素字差得远。**改**：400 字重、字高 8% 格高、单独画在一条带上再阈值化。**验证**：并排图 01 里两行字的笔画宽度接近原作的 1 格。
- **问题**：模型和影子太大，影子压进文字带。**改**：投影中心从 0.56 移到 0.5 高度、缩放从 0.2 降到 0.185，文字带顶部留 3 格。**验证**：01 和 03 并排图里模型、字、虚线框的比例和原作接近。

## 差距

- 原作的模型更复杂（锯齿屋顶、斜面），转动时影子形状随之变化；这里是简单的木屋，影子是底面平移。
- 原作的标题和正文用的是她专门做的像素字体；这里用系统等宽字阈值化，笔画不如原作整齐（这是有意不搬她的字体）。
- 视频分辨率看不清单个针脚的画法，X 形针脚 + 底针加深是推断。
- DMC 编号和 hex 对照是凭常见色卡记的一张 13 色小表，没有对着官方色卡核对，只用来示意「最近色号」这个功能。
- Lettering / Threads / Fabric 三个折叠栏原作没展开过，内容是自己补的最小版本。
- 原作的 Smoke 烟圈数量、速度只看到三帧，节奏是估的。

## API 和 CONFIG

```js
const tool = createStitchTool(document.body, { stitchesAcross: 90, lines: ['Hello', 'there'] });
tool.set({ yaw: 0.4, pitch: 0.5, coverage: 25 }); // 改状态并重画
tool.render();   // 立即重算，返回 { cols, rows, cells, box }
tool.destroy();  // 停 rAF，解绑事件
```

CONFIG 在 `<script>` 顶部：`brand`（左上标题）、`lines`（两行字）、`stitchesAcross`、`threadColours`、`sampling`（`lines` / `majority`）、`lineCoverage`（%）、`skipWhite`、`trim`、`view`（初始 yaw / pitch）、`threads`（4 个色调对应的线色）、`fabric`、`stitchesPerSkein`、`sub`（每格子采样数）。

file:// 直开，零网络：只用系统字体，没有外部脚本。`prefers-reduced-motion` 下不自转、烟圈静止。导出按钮把当前画布存成 PNG。

## 可拆

- `#stage` 三维模型 → 格子：子采样渲染 + 拖动转角。
- `#sampling` 线优先采样。
- `#pattern` X 针脚 + Aida 布面。
- `#key` 线色表、DMC 最近色、束数和成品尺寸。
- `#dock` Spin / Smoke / Reset view 浮条。
