# margin-answer-reader — 答案写在页边的文章阅读器

来源：[@nutlope](https://x.com/nutlope/status/2108596109333483640)，复刻于 2026-11-05。

## 机制

- 选中文字后，选区正上方出现深色工具条：Ask、Explain、Define，以及高亮和复制。
- 点 Ask 变成更宽的深色输入条，带三个建议问题；选中后直接打字也会进入这里。
- 答案卡片写在右侧页边，顶部对齐被问的那一行，用一根细线和圆点连回原文。
- 先显示三条骨架，再显示答案；答案第一句加粉色底，引用用 ¶ 段号小标。
- 新答案展开时，旧答案收成两行摘要，原文保留下划线；点摘要或下划线可重新展开。
- 底部悬浮输入条针对全文提问；点段号可以把整段作为提问对象。

## 可学

答案不进聊天窗，留在被问的文字旁边，读者不用离开原文，读完还能看到问过什么。

## 不学

没有接模型：只有 NatSec 和 Kepler 两个词有写好的回答，其余词显示明确的占位说明。页边卡片堆叠只做了简单下推，问题很多时会越排越长。

## 替换和取舍

- 原视频的风景照壁纸有版权，换成 CSS 渐变，只保留大致色块。
- 模型名换成 Model · Flash。
- 文章正文是原视频里出现的段落（作者 Vinoo Ganesh），只用于版式比对，没有扩写；第 10 段被截断后自行收尾。如果要对外使用，请换掉。
- 滚动条按原文约 60 段的长度画，所以它的比例不反映这里的节选长度。

## 打开方式

打开后自动演示一次，点击页面任意处会停止演示。`?state=kepler / toolbar / natsec / askpanel / idle` 可定格到不同状态。
