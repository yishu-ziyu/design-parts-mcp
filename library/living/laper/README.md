# laper 落地页复刻

来源：https://laper.ai/ ，2026-11-05 用 ego-browser 打开核对。页面：`replica.html`（旧的 `index.html` 保留未动）。

## 做法
- 整页在 1450×900 下打开原站，读出渲染后的 DOM 和可读的样式表，删掉移动端和未显示的部分，只保留用到的样式规则。
- 所以这一版的结构和样式来自原站，不是手写的参考实现。学机制看 `part.json`，发布前要重写。
- 交互（主题、登录光效、入场、横向稿纸、灯箱、输入卡）是自己写的，在页尾脚本里。
- Logo、品牌名和真人姓名换成占位。

## 机制
- 外圈斜纹，主栏靠实底和半透明竖线分出来。
- 编辑器是真实 HTML，按 1536 宽排好整体缩放，滚动时从 0.9687 放大到 1。
- 深色主题切 html 的 dark 类，颜色全走变量。
- 登录按钮：渐变底色上叠低分辨率模糊光。原站是 WebGL，这里是 2D 近似。
- 滚到才播放的钉子（`landing-draw-scope`），页脚大字描边展开。

## 可学
- 只有标题用打字机体，题材感集中在一处。
- 界面图用真实 HTML，深浅主题自动跟着变。

## 不学
- 三条彩色顶条和语言提示条是原站自身需要。
- 深色主题下配图仍是浅色截图，很亮。

## 差距
见 `原料/x-收藏/results/note-laper.json` 的 gap。

## 素材
`source-assets/`：`c-*.jpg` 是原站截图裁出的配图、头像和视频封面；`lb*.jpg` 是视频截图。`app-frame.jpg`、`video-poster.jpg` 是上一版留下的，这版不用。字体 Montserrat 在 `fonts/`。
