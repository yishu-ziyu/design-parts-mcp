01 纸

7px 点阵，透明度 0.55。施工线是窗帘，不是淡入。钉是旋转 45° 的 7px 菱形，晚 420ms。

02 字

03 入口

输入卡，不是按钮

白卡 628 × 145，圆角 32。关掉「输入卡」，才会长出 Get started。那是对照，不是原站。

先忘掉淡入

整页透明度从 0 到 1，那是另一台机器。这台不是。

纸在第 0 秒就已经画完。点阵在。竖线在。横线在。交点上的菱形钉也在。你看不见，是因为每样东西前面挡着一块窗帘。

动画做的唯一一件事：把窗帘拉开。竖线的窗帘从下往上收，所以你看见笔从上往下走。横线的窗帘从右往左收，所以你看见尺从左往右走。点阵跟竖线同一块窗帘，只是晚 0.50 秒才拉，拉 1.80 秒。

钉不用窗帘。它用透明。前 55% 的时间透明度保持 0，像盖章的手还没落下。线先穿过交点，章再生出来。

线不是匀速铅笔画。cubic-bezier(.2, .7, .2, 1) 前段很快。停在 0.42 秒，线已经露出约九成，下面只挡住大约 8%。所以钉这时开始倒计时，不会浮在空白里。

原站量过：竖线 30 根、横线 20 根，delay 全部是 0。没有一根比另一根晚。钉默认晚 0.42 秒。标题 animation: none。

窗帘的四个数

clip-path: inset(上 右 下 左) 写的是挡住多少，不是露出多少。

竖线起点 inset(0 0 100% 0)：下面挡住整段高度，等于一条还没画的线。终点 inset(0)：四处都不挡。

横线起点 inset(0 100% 0 0)：右边挡住整段宽度。终点同样是 inset(0)。

上面实验室那三个小条是冻住的。它们不转。对照着抄。实验室的线画深一点，方便看窗帘。标本上的线仍然是浅灰，那是原站的弱化。

按这个顺序写

  1. 先画一根静止的 1 像素线。竖的就高 100%、宽 1px。先不要动画。你应该看见一根浅灰线。
  2. 给它加上 clip-path: inset(0 0 100% 0)。线应该消失。消失了，窗帘才是对的。
  3. 写关键帧：从 inset(0 0 100% 0) 到 inset(0)。动画 0.9 秒，曲线 cubic-bezier(.2, .7, .2, 1)，both。再播时线应该从上往下长，不是整根冒出来。
  4. 横线把第三步的挡住方向改成右边：inset(0 100% 0 0)。其它数不动。
  5. 在交点放一颗 7×7 的正方形，transform: translate(-50%, -50%) rotate(45deg)，底色跟纸一样，1px 浅灰边。先设 opacity: 0。
  6. 钉的关键帧：0% 和 55% 都是透明 0，100% 才是 1。动画 0.76 秒，ease-out，延迟 0.42 秒，both。没有 both，播完钉会消失。
  7. 点阵是另一块同款窗帘。7px 点，透明度 0.55。延迟 0.50 秒，拉 1.80 秒，曲线 cubic-bezier(.16, 1, .3, 1)。

若线整根一起出现，你写的是透明度，不是窗帘。

若钉从第 0 秒就在闪，你漏了 55% 那段死透明，或者忘了 0.42 秒延迟。

若每根线依次出现，原站不是那样。原站 delay 全是 0。

若标题也在淡入，删掉。原站标题没有进场。

不是把 laper.ai 搬过来

原页 laper.ai。这一页只收第一屏这台机器。底下九千像素的功能墙、真编辑器、登录钮里 29×14 的 canvas，都不收。产品窗走 creed 那种「窗坐在风景里」时，仍先问是不是图纸。

Logo 和片头帧是原站的图。网格、线、钉是抄他们的数画的，不是截一张静图。

第一屏四根竖轨：外 48，内 177。点「慢放 ¼」把 2.30 秒拉成墙上的 9.2 秒。点时间表上的秒数，会停在那一帧。
