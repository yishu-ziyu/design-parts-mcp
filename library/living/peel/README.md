# peel — 贴纸一角一角撕下来：中垂线折页 + 拖动速度控音量、撕开比例控音高

来源：https://x.com/workcinprogress/status/2112800799361221074 （cindy @workcinprogress，2026-10-21，视频 8.7 s、1108×720，原文只有 "claude code 🤝 gsap / sound on for sfx :)"）。没有找到 live 站点、仓库或 CodePen。作者在回复里亲口说了两件事（事实）：音效是让 Claude 从零合成、再自己调到顺耳；音效不在 GSAP 时间线上，而是跟着拖动走——"speed = volume, how far it's peeled = pitch"。另一条回复说她想做的是"像真的贴纸页"。下面的颜色、尺寸、格距是把视频逐帧画进 canvas 截图后量的像素（视频像素，1108 宽），不是读源码；折页怎么实现、GSAP 用在哪一步，原作没说，都是推断。

## 这一页是什么

- 方格纸背景上一张 3×3 贴纸板，8 张自己画的 12×12 像素贴纸（标签、咖啡杯、仙人掌、樱桃、闪电、蘑菇、月亮、小幽灵）+ 一格 RESET；右边一张转了 −3.5° 的横线待办纸，文案是自己写的。
- 按住贴纸往里拖：从拖动方向背后的那条边开始翻起，露出灰白背面和卷边高光，底下是灰色模切孔。撕过一半贴纸脱离、跟手；松手随机转 ±10° 贴在哪儿算哪儿。没撕够就松手会弹回去。
- 撕的时候有沙沙声：拖得越快越响，撕得越开越高。脱离一声 pop，贴上一声 thump。右下角可以关声音。

## 怎么做的

1. 每张贴纸开局渲染成三张离屏 canvas：正面（像素图 + 24 方向平移叠出的白色模切边）、背面（同形状填灰）、孔（同形状填浅灰再模糊），并留一份 alpha 掩码。
2. 按下不动作；移动超过 4px 才定方向 d，从按下点沿 −d 在掩码里走到形状边缘，得到起翻点 G。之后指针每动一下，P = G + 位移。
3. 折线是 GP 的中垂线（法向 n = d/|d|，过中点 M）。同一张覆盖 canvas 依次画：孔 → 折线 P 侧的正面（半平面裁剪）→ G 侧的背面，用反射矩阵 `[1−2nx², −2nxny, −2nxny, 1−2ny², 2(M·n)nx, 2(M·n)ny]` 翻过去，再带投影画上。背面先在小 canvas 上用 `source-atop` 叠一条沿 n 的渐变当卷边。
4. 撕开比例 = 折线越过贴纸在 n 方向跨度的比例；≥ 0.5 就把贴纸 DOM 元素放出来，先画背面、`rotationY` 180→0 翻回正面（过 90° 换成正面图），用 `gsap.quickTo` 跟手（x/y 0.16 s、旋转 0.35 s 按横向速度倾斜，最多 ±18°）。
5. 声音：循环白噪声 → 高通 400 → 带通，增益 = min(1, 速度/0.9 px·ms⁻¹) × 0.32 × (1 ± 25% 随机)，带通中心 = 700 + 比例 × 2700 Hz，都用 `setTargetAtTime` 平滑。pop / thump / 复位音是短的噪声包 + 下滑正弦。

## 三个判断

- **折页从哪条边开始。** 一开始直接拿按下点当 G，从贴纸中间按下往右拖时，整张一下子翻过去。改成"沿拖动反方向走到形状边缘"当 G：从角上按下往里拖就和原作 1.7 s 那帧一样角先翻，从中间按也是背后那条边先起。用 Playwright 从右上角往左下拖 8 步截图核对，翻起的是右上角。
- **背面颜色。** 先用了接近白的 `#f4f4f2`，和原作并排看，翻起来那块太亮、像纸没有厚度。量原作 1.7 s 帧的翻面和 8 s 帧的孔都在 228 左右，改成背面 `#e9e9e8`、孔 `#e4e4e3`，再加一条折线处 1.5px 的白高光当卷边。第二轮并排截图里卷边出来了。
- **声音挂在哪。** 作者说音效不在 GSAP 时间线上、跟着拖动走，所以只在 pointermove 里更新增益和频率，不做任何预排的音频；GSAP 只管松手后的弹回、落下、复位。

## 不足

- 原作翻起的部分是有弧度的卷（圆柱状），这里是平折 + 渐变假装卷边，撕得很开时能看出折线是直的。
- 脱离后贴纸先背面朝上、0.42 s 内绕 Y 轴翻回正面（无透视）。原作里背面朝上能一直拿在手上，拖到纸上才翻回来，这里翻得更早。
- 原作的贴纸边更圆润（像真的模切），这里是像素图膨胀出来的白边，转角是小台阶。
- 音色是按作者描述的映射自己调的，没有原音可对（视频音频没有提取）。
- 原作里 Hello Kitty、CN Tower、寿司等贴纸和待办文案都没有用，换成了自己画的像素图和自己写的文案。

## API / CONFIG

```js
const api = createStickerSheet(document.getElementById('board'), { popAt: 0.5 });
api.reset();          // 撕下的贴纸全部飞回原位
api.setSound(false);  // 关声音
api.destroy();        // 移除事件、贴纸节点和覆盖层
```

`CONFIG` 在页面脚本最上面：`design`（1108×720 设计稿里贴纸板和待办纸的位置）、`pixel` / `border`（像素格和白边）、`popAt`（撕开多少算脱离）、`liftScale`、`dropTilt`、`colors`（背面、孔、白边）、`note`（待办标题和条目）、`palette` + `stickers`（12×12 字符画，`.` 透明，字母查 palette；`type: 'tag'` 是文字标签）、`decor`（预先贴在纸上的装饰贴纸）、`sound`（总音量、撕声增益、满音量速度、音高上下限、带通 Q、随机抖动）。

依赖：`vendor/gsap.min.js`（npm `gsap` 3.15.0），字体 `fonts/playfair-display-latin-400-italic.woff2`（@fontsource/playfair-display 5.3.0）。`prefers-reduced-motion` 下所有补间时长为 0，撕和拖仍然跟手。
