# inline：一段话当作品集

来源：ozzy（@ozzyxs1a）「my portfolio is a paragraph now」，2026-08-24，https://x.com/ozzyxs1a/status/2091644603203989587 。样式和滚动逻辑读自他的站 https://ozzyx.xyz 2026-11-05 的线上版本。

`replica.html` 是按帖子视频复刻的页面；`index.html` 是更早的拆解笔记，保留不动。

## 机制

- 整页只有一个 `p`，字号 `clamp(15px, min(2.5vw, 3.5vh), 30px)`，字重 500，行高 1.42，字距 -.02em，`text-wrap: pretty`。
- 三层：#101010 是事实，#a6a6a0 字重 400 是补充，四色底（#ffefad / #d4e6ff / #d6f0dd / #e9defc）是能点的名词。
- 品牌词不换行，带 .88em 小标，下沉 .06em。
- 右栏 30vw（300 到 460px），卡片 16:10，宽 22vw（200 到 330px）。每张的横移和旋转由序号决定，幅度约 30px 和 3.5deg，排成一条波。
- 滚动：目标位置每毫秒加 .045px，当前位置每帧按 `min(1, .008*dt)` 追目标；悬停时目标停走，滚轮直接加减目标。到一半高度时两个值一起减回去，所以循环看不出接缝。
- 768px 以下，右栏改成段落上方的横向条，速度 .03px/ms。

## 可学

- 层级全靠颜色和底色，字号不变。
- 用「目标值 + 追赶」做滚动，匀速播放和滚轮共用一套逻辑。

## 不学

- 灰色从句太多时段落会难读，要控制补充说明的数量。

## 和原版的出入

卡片内容是原站视频的 20 张截图，每张约半秒多一帧，所以比原版视频卡顿。人名和品牌换成了等长占位，两个小标是自绘占位。占位品牌的衬线用 Newsreader，原字体未确认。原站后来改过文案，这里按帖子视频的文案。
