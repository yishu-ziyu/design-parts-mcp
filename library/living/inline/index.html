01 流

浏览器自己排

一个 p。词是 span / a。不要 position: absolute。窄了它会换行。

02 灰

先把次要弄淡

不是把重点撑大。黑 #111，灰 #aaa9a5，色块才是第三层。字号可以一样。

03 块

名词带着底

链接没有下划线。底色换行不断开，靠 box-decoration-break: clone。

先忘掉按钮行

传统个人页是标题、一段介绍、一排按钮。这台机器把按钮拆开，塞回句子里。

DOM 必须是：字、链接、字、灰字、链接。不是一列卡片。卡片把句子杀了。窗口变窄以后，卡片会折成一堆砖，不再是一段话。

层级不是字号。Refactoring UI 写过：重要的加粗，次要的改淡，不要把标题撑到不舒服。NN/g 的眯眼测试：糊掉以后，该先看见的还在。点「眯眼」，色块还在，灰句融进纸里。

三层墨

扫一眼只能带走这些。那是故意的。

#111       奕枢 · two years · kairos · living notes
#aaa9a5    补充从句。关掉「灰句」，它们会抢戏。
色块       inspiration / writing / X / github
           能点的名词，不是装饰

色盲不能只靠颜色。色块同时是链接，键盘能 tab 到。底纹只是让手知道「这里能进」。

窗帘换成底纹

色块换行时，默认会变成一整块矩形，第二行的底连在一起很难看。写上：

.highlight {
  display: inline;
  padding: 1px 4px 2px;
  border-radius: 3px;
  box-decoration-break: clone;
  -webkit-box-decoration-break: clone;
}

点「窄栏」。living notes 后面那句灰会折到下一行。色块自己也必须能折。clone 的意思：每一行各裁一块底，圆角跟着走。

按这个顺序写

  1. 先写一整段纯文字，放进一个 p。不要切成多个 div。把窗口拉窄，它应该还是一段话。
  2. 把事实包进 strong，字重 600，颜色 #111。字号不要变。
  3. 把从句包进 span.muted，颜色 #aaa9a5。不要用更细的字重，也不要把字缩小。淡掉就够了。
  4. 把能点的名词换成 a。去掉下划线。颜色继承。再加上浅色底：黄 #fff0a9、蓝 #dce8fa、绿 #dff1df、紫 #e8def8。
  5. 给底加上 box-decoration-break: clone。再把栏挤到 320，看色块折行时是不是每行各有一块。
  6. hover 只做一件事：filter: brightness(0.94)。不要位移，位移会把行高撑乱。

若每个词都能点，没有灰句，这页会变成一张标签云。先弱化，再给名词底。

若做成 flex 卡片墙，句子死了。对照上面第三格。

若用 position: absolute 摆词，窗口一窄就撞车。

原参考用 Geist / Inter。标本不走 CDN，用系统无衬线。配方里写了原字体。

一个名词可以再展开

hover writing 或 living notes，旁边会出一张小纸。这不是必须。句子先成立，预览后加。预览用绝对定位，不要把预览写进 p 里，否则会把行撑开。

来源是一段个人介绍：流动的字、三层墨、句法里的链接。这里换成奕枢的词，机器一样。干净个人页、灰纸斜体仍走 you-find。字里夹物体仍走 chapter-one。长文栏宽仍走 type。
