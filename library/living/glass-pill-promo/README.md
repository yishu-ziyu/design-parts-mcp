# glass-pill-promo — 五十秒绿色渐变产品片

来源：[x.com/chhddavid/status/2102666619029999989](https://x.com/chhddavid/status/2102666619029999989)，复刻日期 2026-11-05。原帖 49.86 秒，1920×1080。

## 机制逐条

- 全片是 `render(t)`，约 28 个镜头各占一段时间，`?t=秒` 能定住某一帧，`window.seek(t)` 可逐帧驱动。
- 位置、比例和换场时刻用 `pl(t,[[时间,值],...])` 查表，数值来自原片逐帧（30 帧每秒）量取。段内是线性插值，所以段内运动曲线和原片不完全一样。
- 底色只有几种：满屏薄荷绿、白到薄荷渐变、深绿、纯白；几处换底色用叠层淡入淡出。
- 玻璃胶囊：半透明白渐变加内描边，当前项描边变亮，换词带过冲。
- 遮罩字：分析页就是 RESEARCH 字母的里层，字母从 46 倍缩到 1 倍，蒙版带柔边。
- 星形：四尖路径，位置、半径和转角查表，盖在两个镜头上面。
- 头像环：12 张头像，半径 305→255px，红色闪烁绕一圈走，中间金额从 0 涨到 699993。
- 产品界面：整屏 DOM，窗口宽 1086、消息栏 720，图表先模糊色块再画线。

## 可学 / 不学

- 可学：一两句话配一个镜头的节奏；同一个界面反复拉近来讲不同的卖点。
- 不学：品牌名和 Logo（已换占位）；金额和薪资的对比话术。
