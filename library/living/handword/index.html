看见什么

一句自我介绍里塞进三个荧光绿的手写词：SPORTY、TENDER、CURIOUS。它们嵌在印刷体行内，各自歪一点点（-1.4°、-0.7°、+0.5°），像用马克笔在打印稿上批注。整句进场时上浮 18px 淡入。

先关「蒙版」。三个词立刻变成三个纯绿色矩形——刚才看到的字形根本不存在于元素本身。这就是这篇笔记的发明：手写词不是字体，是一个色块被 PNG 抠出了字。

蒙版的配方

每个词是一个 inline-block：底色涂绿，mask-image 指向手写 PNG（center / contain / no-repeat），外加 0.32px 的 drop-shadow 收边（rgba(91,119,0,.52)）。尺寸全部用 em：宽 2.86 / 3.42 / 3.52em，高约 .8em——所以拖动「字号」滑杆，手写词跟正文一起缩放，行内关系不塌。基线靠 vertical-align: -.11em 微抬，transform-origin: 50% 62% 让旋转围绕视觉重心而不是几何中心。

无障碍文字（"Sporty"）用 1px clip 藏在里面——屏幕阅读器读到的还是词，不是图。

谎

不是手写字体。是每个词一张手绘 PNG，作者自己在 Procreate 里写的（CSS 注释原话："Jiaying's original Procreate lettering, used as a restrained semantic accent"）。代价：换词要重画；收益：字体引擎给不了的笔压和连笔。同一页还有第二个谎——人像照片那圈绿色轮廓也是烤死在抠图 PNG 里的贴纸（alt 自曝 "cut from the original photograph with a lime outline"），页面上没有任何活的描边。两处绿还不是同一个值：手写字用 #a6df00，另一节 section 的 lime 是 #c8ff00。

进场

reveal 机制极简：.js .reveal 初始 opacity:0; translateY(18px)，可见后加 .is-visible 归零，过渡 680ms（另一处 760ms），缓动 cubic-bezier(.16,1,.3,1)。reduced-motion 下全部直接可见。

什么时候用

印刷体正文里要「人味重音」：个人站、作品集、品牌宣言页，一句话里最多三个词。规则：词宽用 em（跟字号联动）、旋转不超过 ±1.5°、origin 用视觉重心。别整段用——那是荧光笔，不是正文。想换词又不想重画 PNG，就退回手写字体：先开「手写字体」开关看看你会损失什么。

配方 · 下次遇到「正文里的手写字」：右键看它是不是 <span> + mask-image；量词的宽高（em）和旋转角；找藏起来的无障碍文本；确认 PNG 从哪来（作者手画还是字体导出）。
