# handword：手写词嵌进正文

来源：Jiaying Chen 个人站 https://cicichen.com/ ，2026-11-05 核对线上版本。样式数值来自线上 CSS（`handwriting.css`、`ai-portfolio-concepts.css`）。

`replica.html` 是全页复刻（首屏、能力、售货机、AI 圆环、履历、联系、页脚和 760px 以下的手机版）；`index.html` 是更早的拆解笔记，保留不动。

## 机制

- 每个手写词是一个色块，用作者手写的 PNG 做 `mask` 抠形，所以不是字体。尺寸用 em，跟着正文缩放。
- 三个词的旋转分别是 -1.4、-0.7、+0.5deg，绕 `50% 62%` 转；下沉 .11em。
- 正文 `clamp(37px,3vw,58px)`，字重 390，字距 -.048em，行高 1，最大宽 `min(730px,45vw)`。
- 人像压在正文右侧：左 49vw，上 `clamp(110px,12.5vh,150px)`，宽 `clamp(410px,31vw,560px)`，比例 1086/1448。
- 导航当前项下面 1px 亮绿线，悬停时从左向右画出。

- 能力区：一屏 sticky，滚动进度分四段驱动卡片、抠图、标题和文字。
- 售货机：CSS 画机身，瓶子透明抠图，Web Animations 串起下落、取货和案例面板。
- AI 区：33 个标签 11 度一格排成圆环，滚动吸附转动。
- 履历区：左栏不动，右栏随纵向滚动横移三屏。

## 可学

- 手写效果只用在三个词上，其余都是系统字体。
- 手写词和正文共用 em，缩放时行内关系不变。

## 不学

- 换词要重新手写一张图；词多或要翻译时不适合。

## 和原版的出入

人名、公司名、商品名和外链换成了占位，履历里的公司 Logo 换成灰色占位图形。瓶子和海报图上的品牌字是原图，没有改。样式和脚本取自线上页面（`replica.html` 内联），只改了素材路径和占位文字。

素材都用 ego-browser 截取：把图片按原始像素放到空白背景再截，需要透明的用透明背景截，然后从 Display P3 转回 sRGB。这一步解释了之前“手写绿偏淡”：ego 的截图是 P3 像素，转回后 #cfff00 读出来正好是 (207,255,0)。小于原图的只有贴纸和履历人像：贴纸压到最长边 1400–1500，人像压到 1800 宽。

并排图左右都用 ego 截，右边是 `http://127.0.0.1:8791` 上的复刻页。Playwright 无头 Chrome 里瓶子缩放更糊（同一张图），是渲染环境差异，所以关键帧也用 ego 截。

**取材说明：**页面内联了线上 CSS 和 JS（用 page.fetch 读取），只替换素材路径和占位文字；部分素材把线上图片地址放进空白页后截取。不是重写。
