# particle-palette

含原作素材，只留本机。

来源：Oriku @Oriku175，https://x.com/Oriku175/status/2113603374470013133 ，2026-10-23。查看日期 2026-11-05。原帖是三张静态海报，不含视频。

## 机制

- 主体不是图片，是 1500–3000 个小圆。位置、大小、颜色都从原帖截图逐点取样（`source-assets/particles.js`）。
- 浅色先画、深色后画，颜色密度自然勾出脊背和壳片结构。
- 背景层也来自原帖截图（`source-assets/plate-*.jpg`）：去掉主体后只留角落的模糊色块，再撒白色细颗粒。
- 细线多边形加圆点和等宽标签，把插画变成研究图表的样子。
- 打开时小圆从四周收拢，鼠标靠近时被推开再弹回。这段动效是我加的，原帖没有动效，无法对照。

## 可学

主色配一个互补暖色；图表细线只用主色的浅版；留白和角落模糊色块撑起呼吸感。

## 不学

小圆数量上万后 2D 画布会掉帧，要换 WebGL。标签文字原帖是占位语，真实产品不要照抄。

## 和原版的差别

小圆是纯圆，原版的边缘更不规则、更有水彩感；鱼鳍这类极浅的部分比原版略稀。Manrope 是目测最接近的免费字体，不确定是否原字体。
