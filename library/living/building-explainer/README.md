# building-explainer — 用线描房屋讲建筑

来源：[@aymericrabot 的帖子](https://x.com/aymericrabot/status/2110010920839561542)（2026-10-13），外链 https://architecture.pascal.app，2026-11-05 查看。

复刻的是首页第一屏：窄目录、衬线大标题、可转动的线描房屋，以及右侧的控制栏。品牌名已换成占位。

## 机制
- 房屋是程序画的：Canvas 2D 把每个面投影到屏幕，按深度从远到近填色，再画线。
- 投影参数从原站截图反算：方位角 -0.738 弧度，仰角 0.41 弧度，每英尺 8.62px。
- 八个系统（地基、地梁、一层、楼板、二层、屋顶、门廊、场地）各有一个偏移量；Apart 滑块按比例推开。
- 场地挖去房屋前角的一块 L 形土，露出地下室墙和基脚。
- 排版：衬线 46/50.6，正文 14/22.4，目录 13 和 12.5，全部取自原站计算样式。

## 可学
- 只靠线宽和浅灰填色区分材料，不用颜色，也能读出屋面、外墙、土层。
- 右侧栏把快捷键、节点和层级放在一起，一屏里看全所有操作。

## 不学
- 原版有 2340 个构件。这里的墙是实心面，没有内部的柱和钉，不适合照抄当建筑教学。
- 面排序是简单算法，转到极端角度时可能穿插。
