# cite — 停在这句，片子出现

来源：[x.com/raunofreiberg/status/2037627143530729594](https://x.com/raunofreiberg/status/2037627143530729594)，2026-03-27。原帖 Video player with soul，10.25s、2580×2072、60fps。白纸两段字，一句蓝双下划线，停在上面片子从段上方淡入。原帖片子是 Xerox Alto 档案，有版权，本页换成工房打样机原件。

打开 [index.html](index.html)。

## 机制逐条

- **栏**：640px。Georgia 18.5px / 1.55。墨 `#282828`。两段字靠下，上面留白。
- **蓝字 `#mark`**：`#2a24d0`。两道略弯的线，高 9px。
- **片子 `#clip`**：栏宽 84%，3:2。贴在段上 18px。循环，静音。
- **淡入**：220ms `cubic-bezier(0.23, 1, 0.32, 1)`。只动透明度。原帖约 150–200ms。
- **渗光 `#bloom`**：同一片子放大 118%，模糊 36px，透明度 .52。

## 可学 / 收窄 / 启示

- **可学**：下划线是播放器。正文不动。渗光跟画面走。
- **收窄**：标本只收这一句和这一段片子。工作室视频块走 [tubik](../tubik/index.html)。阅读器工具栏走 [pageflow](../pageflow/index.html)。
- **启示**：片子要出现在句子旁边。控件一加，它就变成另一块界面。
