# cutup-reading-poster — 把一次阅读剪贴成海报

来源：[x.com/andy_matuschak/status/2098137186319114310](https://x.com/andy_matuschak/status/2098137186319114310)，作者 @andy_matuschak，2026-11-05 看原帖配图。原作是**桌上的一张实体海报照片**，不是网页。

- `index.html`：底图是原帖图片（帖子灯箱里 4096×3072，用 ego 截取，`source-assets/poster-4096.jpg`）。纸条、手写、荧光笔和中央图各是一块对齐底图的裁切，指针移上去放大。放大是本页加的读取方式，原作没有交互。
- `rebuilt.html`：之前的纯代码重建版（字体手写、占位正文、自绘文具）。要在产品里写同样的纸条和荧光笔，抄这份的 CSS。

## 机制逐条

- **纸条**：每段是一块略歪的小纸；从段落中间剪下来时第一行空出来，切口也切掉。
- **四色荧光笔**：黄标观点，青标术语，绿标对象，粉标机会；另有细下划线。
- **手写**：黑笔是评论，绿笔是第二轮追问，大写字母是分区标题；手写穿插在纸条之间，和纸条同等地位。
- **中心图**：论文的四象限图放在中央，四周纸条用手画箭头指回图上具体位置，粉色胶带补写标签。

## 可学

- 既看得到全貌，又不丢原文片段：摘录按自己的论证重排，而不是跟着原文结构走。
- 手写和摘录不分主次，比页边批注更像“读者自己的东西”。

## 不学

- 字小且歪，不适合长时间阅读。
- 照片里有论文作者姓名和邮箱，未遮挡，所以这一页不能公开。
