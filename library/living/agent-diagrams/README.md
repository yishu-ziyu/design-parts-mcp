# agent-diagrams — 智能体用图示代替长文

来源：[@Wattenberger 的帖子](https://x.com/Wattenberger/status/2102425299237720493)，2026-09-22，61 秒录屏。作者说受够了读大段文字，智能体工作台应该在乎图示。

## 机制

- **图在笔记正文里：** 右侧是一篇可滚动的笔记，标题、说明、链接之后直接是图，图不开新窗口。
- **线上的文字打断线：** 标签放在线中间，线在标签两边断开，不压字。
- **颜色只有三档：** 普通节点 #202020，当前节点橄榄色 #3c3f26，点亮节点黄绿色 #a9b54a。其他靠灰度。
- **分步图：** 底部一条说明、圆点、1/3 和前后按钮。切换时节点滑到新位置（700ms），线先淡出，330ms 后按新路径淡入；窗口滚动到说明条还在屏幕内。
- **图的工具按钮只在悬停时出现：** 编辑、放大、更多。
- **双字体：** 正文 Inter，带类型的节点用 Source Serif 4 配小字类型。

## 可学

- 智能体回复架构或流程时，先给一张图，再给一句话；分步图能把一张复杂图拆成三步讲。
- 少颜色、多留白：深色界面下靠极淡的描边分组，就不显得杂。

## 不学

- 窗口外的桌面壁纸和标签页内容都是录屏环境，不是设计本身。
- 没做自动布局：坐标是从原帧量的，换内容要重排。

## 和原版的差别

原版有 24 个图例，这里复刻第 1、2、10、13、17 这五个；3、11、14、18 只有标题。壁纸是自绘，原图是照片。产品标识和小图标是自绘。第 2 步的线路是根据抽帧估的。
