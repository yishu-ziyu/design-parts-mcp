# retroprint — 把 Photoshop 的六步复古印刷加工搬成浏览器里的六个 pass：粒子、纹理层、颜色比较（明）、2 阶调化、双色映射

来源：https://x.com/DesignSpot_Jap/status/2111383799791776021 （タマケン @DesignSpot_Jap，2026-10-17，4 张图，原文日文「画像をレトロな印刷風に加工する方法 #Photoshop」）。四张图分别是封面（Before / After 对比）、第 1–2 步、第 3–4 步、第 5–6 步加两条补充说明，每一步都写了菜单路径和参数。没有代码、没有 PSD、没有 live site；回复里作者只补了一条「アレンジ例」。下面的 Photoshop 参数是从截图里原样抄的（事实）；浏览器里每个 pass 怎么算是我按 Photoshop 行为推出来的（推断），其中粒子强度和偏移是拿原作 Before→After 量出来的曲线反推的。

调性一句话：金属产品照里大量 0.7–0.95 的浅灰，经过强粒子再一刀阈值，变成疏密不同的墨点；暗部再被一层灰色纹理打出白色细纹，最后只剩墨和纸两种颜色。

## 怎么做的

1. **原图**：白底。透明像素按 alpha 合到白上。长边缩到 `CONFIG.workSize`（默认 1100）再算。
2. **粒子**：每像素加噪声 = 平滑值噪声和逐像素随机按粗糙度混合，再加一个负偏移 `bias`。强度乘 `2.2·√(l(1−l))`，纯白纯黑不动，所以白底在阈值后不会长斑点。
3. **纹理层（第 2–4 步合并）**：`#808080` 平涂经过半调图案应是一张点阵棋盘，龟裂缝的浮雕光照再把它扭成短蠕虫。这里用 `cos·cos` 点阵，拿值噪声做坐标扭曲，加一点逐像素抖动，按对比度放大后截断到 0–1。
4. **颜色比较（明） 60%**：每像素比亮度，取亮的那个，再按 60% 混回去。只会变亮。
5. **2 阶调化 161**：亮度 ≥ 161/255 为白，否则为黑。
6. **渐变映射**：黑 → 墨，白 → 纸。白底直接成了纸色，所以不用抠图。

全部在 Canvas 2D 的 `ImageData` 上逐像素算，噪声用整数哈希，同一个 `seed` 每次结果一样。1100 px 长边一次全流程约 0.5 s（headless Chromium 实测 470–520 ms），只在换图或拖滑块时跑，没有动画。

## 关键判断

- **粒子才是网点的来源，不是半调层。** 第一轮照字面实现（粒子小幅、纹理层只提亮），螺丝帽那片 0.8 的浅灰全变成了纸，原作却是一半墨点。按亮度分箱一量，原作 0.8 处还有 34% 墨，说明阈值前的噪声幅度很大而且整体往暗推。改成强粒子加负偏移，再扫了 10 组参数对齐覆盖率曲线（见上表），对比图 `02` 里帽面的疏密和原作一致了。之后把粒子格从 1.2 px 缩到 0.8 px，颗粒粗细接近原作，覆盖率曲线没变。
- **噪声必须在纯白处归零。** 加了偏移以后，第一次跑出来整个白底都是墨点。原作第 6 步截图里白底是干净的，所以把噪声和偏移都乘上 `√(l(1−l))` 形状的权重，白底恢复干净，覆盖率曲线只在最亮一箱掉了约 0.08。
- **纹理层只负责暗部的白纹。** 「颜色比较（明）」只会提亮，所以它对亮部几乎没影响，作用在暗部：把实心墨块打出细碎白纹。增益从 0.5 降到 0.28，暗部覆盖率从 0.86 回到 0.93 附近，和原作暗部一致。

## 没做到的

- 我没有 Photoshop，粒子、半调图案、龟裂缝三个滤镜的真实算法都没对照过，是按截图效果近似的。尤其龟裂缝：这里没有真正的裂缝网络，只用了坐标扭曲和一层很淡的「脊线」。
- 对比用的原作是 X 截图（原图 0.41 倍），Before 也是从这张截图放大回去的，所以边缘比原作软，细节对比只能看疏密和颗粒，不能看单个像素。
- 原作帽沿、螺纹边是实心墨线，本页是碎点。一半原因是输入边缘偏软（见上一条），另一半是本页噪声在 0.5–0.7 的过渡带也很强，没有原作那样「边缘保留」的感觉。
- 最亮的高光（原图 0.9 以上）墨点比原作少。

## API / CONFIG

```js
const api = createRetroPrint(document.body, { workSize: 1600, threshold: 150 });
api.setImage(imgOrCanvas);          // 换源图，自动重算
api.setParam('grain.bias', -0.2);   // 点路径改任意参数
api.showPass('texture');            // source | grain | texture | lighter | threshold | final
api.getPass('final');               // 拿到某一步的 canvas
api.destroy();
```

| CONFIG | 默认 | 对应 Photoshop |
|--------|------|----------------|
| `grain.amount / size / roughness` | 100 / 25 / 50 | 粒子三项 |
| `grain.strength / bias` | 0.75 / −0.22 | 无；按原作覆盖率曲线反推 |
| `fill` | 0.5 | 纯色 `#808080` |
| `halftone.size / contrast` | 2 / 12 | 半调图案 |
| `craquelure.spacing / depth / brightness` | 35 / 15 / 3 | 龟裂缝 |
| `texture.gain / lift` | 0.28 / 0 | 无；控制纹理层白斑多少 |
| `blend.opacity` | 0.6 | 不透明度 60% |
| `threshold` | 161 | 2 阶调化 |
| `gradientMap.ink / paper` | `#24207A` / `#F2D4DC` | 渐变映射 |
| `workSize` | 1100 | 处理分辨率（长边） |
| `seed` | 7 | 噪声种子 |

页面文案在 `CONFIG.copy`。示例图由 `drawSample()` 用 Canvas 渐变画出，不加载任何图片；拖进来的图用 object URL 在本地读，不上传。页面没有动画，`prefers-reduced-motion` 只影响缩略图按钮的过渡。
