一个平面像素小怪，长出厚度

终端光标先占住画面，像素一行一行刷出来，腿掉下来落定；然后每个像素沿 Z 轴拉成体素，镜头同时转到四分之三侧，最后体素缝消失，变成一整块。

    可拆

    #stage
    整段时间线：一个 t 驱动所有图层，关键帧插值 + 每段自己的缓动；9 s 一循环，最后 0.6 s 黑场。
    #cam
    CSS 3D 镜头：perspective 放在舞台上，.cam 只做 rotateX / rotateY / scale，角色和地面都挂在它下面，转镜头不动角色。
    #caret
    开场前景：大号光标贴近镜头、带景深模糊，2.2 s 硬切成远景小光标，用来交代「这是在终端里」。
    #glow
    平面阶段的底光：角色还没有厚度时，用脚下一团同色径向光撑住体积感，拉伸开始后退场，换地面和地面上的软影接手。
    #beats
    节拍表：每一拍的起止时间，点一下跳到那一拍，方便逐拍对照原片。
