# extrude — 平面像素角色逐行刷出、掉腿落定，再沿 Z 轴拉成体素、合缝成一整块，镜头同时转到四分之三侧

来源：https://x.com/LexnLin/status/2110389810258968965 （Leon Lin @LexnLin，2026-10-14，视频 60 s，X 给到 480×270）。作者原话只说这是用 Opus 5.5 Ultracode 做的动画，后来在回复里贴了 prompt：让模型做一条一分钟的吉祥物短片，自己找 SVG 素材重建并动画化，渲染 3D 物体（终端、自然等），作者说跑了大约 12 小时。没有找到 repo、live 页面或源码，所以渲染器是什么（很可能是 Three.js 一类的 WebGL，这是推断）不知道。下面的节拍和比例都是把推文视频逐帧画进 canvas 截下来量的。原片主角是品牌吉祥物，本页**不画它**：换成自己的薄荷绿圆顶小怪（天线、两只方眼、一张嘴、两条腿），只复刻开场 0–9 s 的手法和节奏。

## 怎么做的

- **一个时间 `t` 驱动全部图层**：`render(t)` 是纯函数，rAF 只负责算 `t`。所以暂停、拖进度条、点节拍跳转都只是换一个 `t`，截图对照原片也能精确到同一时刻。
- **角色是一张 ASCII 像素图**：每个非空格子生成一个 `.vx` 体素，体素只给「暴露面」建 DOM（左右上下有邻居的那一面不建），所以拉厚后没有内部面打架，也省一半元素。
- **拉伸只改一个变量**：所有面都用 CSS 变量 `--d`（厚度）和 `--s`（格边长）算位置：前后面 `translateZ(±d/2)`，侧面宽度就是 `d`。`d = 0` 时侧面宽 0、只剩正面，就是平面像素图；`d` 往上走，整只角色同时长厚。
- **体素缝**：正面用 `inset box-shadow` 画 1px 黑边，再用两条 `linear-gradient` 按半格重复画细缝（原片体素网格的密度约是平面像素的 2 倍）；侧面和顶面同样按半格画缝。所有缝都乘同一个 `--seam`，合缝时只把它降到 0。
- **镜头**：`perspective` 放在舞台上，`.cam` 只做 rotateX / rotateY / scale，角色和地面挂在它下面。关键帧数组 `[秒, rx, ry, scale]`，段间用三次缓入缓出。
- **地面接手底光**：平面阶段没有厚度，只能靠脚下一团同色径向光表示它「站在」那里；拉伸开始后底光退场，地面淡入，地面背景第一层是一团黑色椭圆当软影。
- `prefers-reduced-motion`：不播放，停在 7.6 s 的成品姿势。

## 关键判断

1. **问题**：第一版角色 10×11 格、两只 2×2 大眼、四条细腿，平面阶段看起来像骷髅。**改**：换成 14 格宽的圆顶，加一张 2×1 的嘴，腿改成两条 2 格宽。**验证**：同一时刻（3.9 s）和原片并排，读起来是「小怪」，不再是骷髅（见 `cmp/2-legs-flat.png`）。
2. **问题**：第一版只拉 1 格厚，转镜后像一块饼干，和原片那种近似立方体的体量差很远。**改**：厚度改成 `depthCells: 8`（身体宽的 0.57）。原片接近 0.8，但我的角色是阶梯圆顶，太厚侧面台阶会很碎，所以取小一点。**验证**：5.4 s / 6.9 s 并排，体量感接近（`cmp/3-extrude-orbit.png`）。
3. **问题**：侧面的体素缝一开始完全没出来。原因是 JS 里用 `style.background = 颜色` 设面色，内联的 `background` 简写把 CSS 里的 `background-image`（画缝那条渐变）重置掉了。**改**：只设 `backgroundColor`。**验证**：5.9 s 截图侧面出现按格的竖缝，6.4 s 后消失。

## 和原片的差距

- 原片是真正的 3D 渲染：有圆角倒角、软阴影、地面反射、景深和体积光；这里是 CSS 3D，面是平涂的，合缝后是直角，不是圆角。最大的一条。
- 原片的刷出是「整条横带一次出现、亮斜光掠过」，这里是逐格逐行，颗粒更细。
- 原片拉伸时体素网格会先错开、再收拢（4.4 s 那帧看得到错位），这里所有体素同时、等速拉厚。
- 原片的镜头一直在微微推和摇，背景里有显示器边框和光带；这里背景只有一道斜光。
- 只复刻了 60 s 里的前 9 s；后面键盘、草地、体素树、拼成巨型角色那些镜头没做。
- 声音没做（原推文说改进了音效）。

## 接入（file:// 直开，零网络）

- 单文件，系统字体，没有外部脚本、字体或图片。
- 工厂：`createExtrude(container, options) → { play, pause, seek(t), time, playing, onTick, destroy }`。`container` 里要有 `.stage` 和 `#cam #caret #slot #glow #fade`（照抄本页结构即可）。
- `CONFIG`：
  - `sprite`：ASCII 像素图，`#` 身体、`o` 眼睛、`m` 嘴、`a` 天线、`L` 腿（腿走掉落动画）、`.` 空。
  - `colors`：`body / top / side / under / eye / antenna / antennaSide`。
  - `cellOfWidth`：格边长占舞台宽的比例（0.03）；`depthCells`：拉伸后的厚度（8 格）。
  - `loop`：循环秒数（9）；`beats`：节拍表；`camera`：`[秒, rotateX, rotateY, scale]` 关键帧。
- 测试钩子：`window.__extrude`。
- 验证：Playwright 拦掉所有非 `file:` 请求打开，零请求、零控制台错误；1100×700 和 400 宽都没有横向滚动。
