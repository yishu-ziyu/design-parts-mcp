# 咖啡杂志硬切翻页

来源：@KoiGeorgi（Georgi Valkov）https://x.com/KoiGeorgi/status/2109682003209797673
复刻日期：2026-11-05

## 机制
- 原版是 5.3 秒的翻页录屏，共 6 个跨页（12 页），没有过渡，约每 885 毫秒硬切一次。切点按 0.1 秒步长的逐帧差异测得。
- 纸平放在灰底 #E4E4E4 上，只有向下的大软阴影。
- 复刻页加了原版没有的控制：点击或左右键换页，空格暂停；减少动态效果时不自动播放。

## 可学
节奏本身就是表现：大字、粗糙插画和等宽小字靠硬切形成冲击，不需要翻页动画。

## 不学
不要把这些跨页图当成通用模板，内容和插画都是原作者的。

## 和原版的差距
6 个跨页都是原帖视频暂停帧的截图，不是重新排版，所以文字不能选中、不能改。分辨率上限是视频帧（2400 宽）。视频里没有翻页交互，点击和按键是复刻时加的。右侧滚动条是录屏里带的，这里照样画了一条。

## 素材说明
source-assets/ 是从 X 视频暂停帧截图后裁出的 6 张跨页，只留本机，不公开。
