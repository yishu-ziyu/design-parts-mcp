scrawl

Hand-drawn UI. Fresh pen sketch
every mount.

可拆

#s1
手绘控件组：按钮、单选、复选、开关、输入框、分隔线、卡片全部是原生元素外面套一层 SVG 墨迹。
#boil
墨迹抖动（看右下角卡片）：每个控件预先算 3 帧噪声不同的路径，每 125ms 换一帧，只改 path 的 d。
#redraw
悬停重绘（看 Retry 按钮）：换一颗种子，用 280ms 把笔画从起点长到终点。

URL 加 ?seed=7 固定种子；不加时每次打开都是新的笔迹。

来源：@dwhitedesign，取自帖子视频。原库作者尚未开源，算法和代码为本页自写；原视频背景是系统壁纸，这里换成自绘渐变；“scrawl”是原作者的库名，只作占位文字。
