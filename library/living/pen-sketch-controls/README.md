# pen-sketch-controls — 钢笔手绘控件

来源：[x.com/dwhitedesign/status/2087944253833916867](https://x.com/dwhitedesign/status/2087944253833916867)，取原帖 24 秒视频，读取日期 2026-11-05。原库尚未开源，算法和代码为本页自写，和原版算法不一定相同。

## 机制逐条

- **种子：** 每个控件一颗种子，打开页面时随机，`?seed=7` 可固定。
- **墨线：** 把圆角矩形拆成点，用三组频率的正弦波加细抖动偏移；再把折线扩成宽度起伏的闭合多边形。每个控件描两遍。
- **抖动：** 预先算 3 帧，每 125ms 换一帧，只改 path 的 d。
- **悬停重绘：** 换种子，280ms 内让笔画从起点长到终点。
- **原生控件：** button、input、checkbox、radio 都是原生元素，键盘可用。

## 可学 / 不学

- **可学：** 预算帧加循环的抖动开销小，不用逐帧算噪声。形状和状态分开，勾选时只多画一笔。
- **不学：** 三十个控件同时抖动会分散注意力，只适合品牌页和玩具类产品。减弱动效时必须停下，本页已停。
