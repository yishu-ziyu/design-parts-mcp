# fork — 两张卡，一句问话

活笔记。复刻 Claude Console 的「How will you use the Claude API?」选择页（Individual / Organization），
内容换成 By-Your-Side。`file://` 直开 `index.html`，无网络、无构建。

测试参数：`?gap=fixed`、`?hint=fixed`、`?hover=solo|team`、`?measure=0`。

## 来源

- 用户截图（2026-10-21），Claude Console 新账户引导页。没有拿到源码，尺寸全部从截图量出来，按 1200 宽折算。
- 字标、手绘手插画属于原站，不搬。字标换系统衬线，插画是这里自己画的光标 + 对话气泡。

## 原版的好

- 只用灰阶。层级靠字号和灰度，卡只有 1px 线和 12px 圆角，没有阴影。
- 情绪全交给一处插画，线宽和正文笔画差不多，所以有手感但不吵。每幅只有一块浅灰实心。
- 一页只问一件事，两张卡等宽等重，不替用户偏向任何一边。

## 原版的毛病，和这里怎么修

| 毛病 | 修法 | 怎么验证 |
|---|---|---|
| logo 钉顶，块在剩余空间里居中，中间空出两百多 px，像没加载完 | 块顶改为 0.24 × 视口高（182），块中心落到 46% | 红标尺读真实 DOM：gap 从两百多降到 133，中心从低 59 变高 23 |
| 卡静止时没有任何「能点」的暗示 | hover：描边 #E4E4E3 → #B9B8B4、上浮 2px（弹簧 350ms）、右上箭头淡入、插画转 −6deg；选中描边变墨色；卡本身是 radio，键盘可达 | `?hint=fixed&hover=team` 截图对比 |

## 不学

- 不搬原站字标和插画。
- 不把 hover 暗示做成常驻按钮或「Continue」行，那会破坏两张卡的对称和安静。

## 可学

- 极简页的情绪预算只给一处，其余全部退到灰阶。
- 插画线宽对齐正文笔画（这里 1.8px 对 13–16px 字），插画就不会喧宾夺主。
- 手抖用 `feTurbulence` + `feDisplacementMap`（0.06 / 1.6）加在几何路径上，比手画贝塞尔省事，也好改。
- 页眉钉顶 + 内容居中是常见组合，一定要量中间那段空：超过块高一半就不是留白了。
