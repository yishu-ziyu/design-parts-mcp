# 问题画布（复刻）

来源：https://x.com/aka_kosasih/status/2090798099505807471（Angelica，2026-08-21），原作为 74 秒视频。2026-11-05 查看。

## 机制
- 提问框贴底，磨砂半透明，内容从下面透过来。
- 提问后生成节点，镜头飞过去放大，文字流式出现，然后出示意图。
- 节点四边的加号生成追问节点并连线。
- 画布可拖动，滚轮以指针为中心缩放，点阵背景跟着平移缩放。
- 侧栏从图标栏展开，画布和提问框一起让位。

## 可学
聚焦和总览是同一层的两个镜头位置，所有并行问题都留在画布上。

## 不学
原视频的演示者画面不属于设计；回答是预写的，不要当真实生成看。

## 和原版的差距
空画布、提问后的卡片、总览、聚焦和带侧栏的椅子画布都能和视频并排对上，差距在细节：原视频右下角演示者的摄像头画面没有放（这部分壁纸是补出来的，略糊），鼠标指针没有画；回答是预写文案，不接模型，任何提问都回同一段；世界模型配图和椅子图是视频截图，放大后糊；节点内正文和原视频略有不同，因为原文读不全；节点不能滚动内容也不能拖动；侧栏里只有两个条目有内容，其余进空画布；品牌名和用户名换成占位。
