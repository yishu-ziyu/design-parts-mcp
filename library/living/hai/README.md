## 机制逐条

- **房间**：奶油底 `#f6f1e8`。左栏珊瑚色 39，字号约 168px。
- **九宫**：3×3，间距 10px，圆角 14px。排布 B C D / E A F / G H I。A 橙底 `#f15a29`，其余黑底。
- **面板**：默认打开 A。同时只亮一簇。原则编号与原文 1–39 对齐，例子压缩成一行。

## 可学 / 不学 / 启示

- **可学**：九块当入口，正文按需打开。强调色只给中心那一块。
- **收窄**：第一屏只放九簇入口。强调色只给 A。
- **启示**：A 放在正中，对应第一句「同一输入可以给出不同输出」。位置在说论点。
