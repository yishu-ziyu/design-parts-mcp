# 随问随生成的界面

来源：https://x.com/ahmadafterhours/status/2108325993979277417（@ahmadafterhours，2026-10-08）

复刻页：`index.html`。并排核对图：`原料/x-收藏/originals/2108325993979277417/compare.jpg`。

## 机制

- 只有一块面板，改位置和尺寸走弹簧过渡，内容交叉淡出加模糊，看起来是同一个东西在变形。
- 卡片内部元素错峰进入，每项间隔 70ms。
- “把 3 点移到周五”时，那一行先变白，再飞到周历的目标格。
- 柱状图散成粒子再换下一屏，用 canvas 按柱高撒点。
- 3D 翻转用于换到内容差别很大的一屏。
- 邮件正文逐字打出；折扣滑块和正文高亮数字双向绑定，能拖。
- 右上角状态胶囊有聆听、构建、说话三态；字幕条用圆点区分助手说的话。

## 可学

一块面板贯穿全程的变形，让不同内容感觉连续；状态胶囊持续告诉用户系统在听还是在做。

## 不学

这是脚本化的概念片，时间线写死，没有真实语音和生成；复刻时只有滑块、时间跳转能操作。

## 和原版的差距

面板的版式、尺寸、字号和节奏并排基本重合，壁纸和程序坞玻璃底条已换成视频帧合成的真实素材。还存在的差距：应用图标和产品名按规则是占位（Aria、通用色块、回复卡片的 Outlook 图标）；壁纸是 1920 宽视频帧合成，状态胶囊背后和程序坞图标背后是补出来的，胶囊和图标盖着时看不出；粒子散开和 3D 翻转是近似，粒子形态和翻转角度与原片不同；说“Make it twelve”时的镜头放大按帧量出约 1.05 倍，曲线是估的；等宽字体用 Geist Mono 代替。

## 素材处理

壁纸（`source-assets/wallpaper.webp`）由已截取的视频帧逐像素取中位数得到，再补掉面板、字幕、菜单栏文字、状态胶囊和程序坞图标。世界地图点阵的 976 个点位从视频帧（f0200）里提取。应用图标和产品标志仍是占位。原帖外链 agently.dev/access 已打开看过，是申请访问页，没有可取的界面规格。
