# companion-onboarding — 把工具型产品改成伙伴感的语音引导

来源：[@kai_brokering 的帖子](https://x.com/kai_brokering/status/2101117493548892389)，2026-09-19，35 秒录屏。作者称改成伙伴感后留存 +21%，换声音后转化 +36%（作者自报，未核实）。

## 机制

- **桌面压暗：** 引导不开窗口。桌面保留，只盖一层上紫下黑的渐变；1.2 秒压暗，权限窗口出现时亮回来。
- **发光球收成标志：** 球从屏幕底部升起，边升边缩，白色部分翻转到全白，最后收成圆点，方块从旁边淡入成标志，再展开成完整字标。
- **Get Started 后点飞向刘海：** 小白点飞到顶部，刘海展开、亮起一个圆点，表示助手开始说话。
- **逐词字幕：** 助手的话逐词淡入，两句之间有停顿，配合语音节奏。
- **问到才给输入框：** 问完称呼才升起胶囊输入框，回答后的下一句用上用户名字。
- **语言面板：** 半透明面板，多选加星标主语言，下一句会说出选的语言。
- **权限窗口：** 左侧逐条打勾，右侧用系统设置示意图教拖拽，打开开关后提示卡消失。

## 可学

- 像人一样先问名字、用名字回话，比一上来列权限更像伙伴。
- 把屏幕其他东西压暗，只留一句话，让用户知道现在只需要听。

## 不学

- 原版的标志、产品图标和作者摄像头画面不收，这里是自绘占位。
- 没接语音：节奏是按视频抽帧估的，真接语音要由音频驱动。

## 和原版的差别

壁纸是自绘渐变，波纹层次比原图少。程序坞是纯色方块，摄像头是占位插画，字标换成了占位字。球的白色翻转是简化的两块形状。
