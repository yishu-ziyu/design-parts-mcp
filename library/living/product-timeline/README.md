# product-timeline — 拖标尺翻看电子产品史

来源：[x.com/vista8/status/2104238864647016572](https://x.com/vista8/status/2104238864647016572)，2026-09-27 转发介绍；原站 [bentossell.com/devices](https://bentossell.com/devices/)（Devices, in time）。原站样式和脚本可以直接读到，所以数值是从源码来的，不是估的。

## 机制逐条

- **标尺**：99 根 3px 竖条，高度 `13 + 62·e^(-距离/9)` px，不透明度 `0.14 + 0.86·e^(-距离/8)`。位置是连续值，所以拖动时山峰是平滑移动的，设备一格一换。
- **舞台**：270px、600 字重、字距 -0.08em 的灰色年份压在物件后面，物件在 390×350 的框里，上下压住数字。
- **年份标签**：只放在真实的设备停靠点上，太挤（小于 58px）就省略。
- **按钮**：had / wanted 计数按钮，按下缩到 0.97；下面放键帽提示回车和 Shift+回车。
- **键盘**：左右键一格，Home/End 到两头。
- **标尺不代表时间**：88 个设备等距分布，间距不表示年份差。

## 可学 / 不学

- **可学**：用一条指数衰减公式同时控制高度和深浅，比画一个游标更有手感。
- **可学**：连续位置与离散选中分开算。
- **不学**：线上投票。计数是占位数，只存本机。
