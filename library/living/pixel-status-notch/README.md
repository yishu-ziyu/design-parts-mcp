# pixel-status-notch

来源：@k_grajeda 的界面，经 @insporadesign 转发，https://x.com/insporadesign/status/2102012194057511070 。取样日期 2026-11-05（看视频，每 0.2 秒取一帧）。

## 机制

- 上行灰字显示读到的文件和行数，下行白字显示当前动作。
- 宽度由两行文字中较宽的决定，用带回弹的过渡变化，不用任何布局动画。
- 文字更换时旧字模糊淡出、新字模糊淡入，同放在一个 grid 格里。
- 3×3 像素方块每 140ms 换一帧，图案和颜色随动作变化。
- 进入 Creating prototype 后下方才淡入 0/1 雨。
- 时间线抄自原视频，循环播放；减弱动效时停在最后一个状态。

## 可学

- 状态文字两行分工：上行讲刚做了什么，下行讲正在做什么。
- 用图案和颜色表示工作类型，不靠文字也能看出变化。

## 不学

- 文件名和行数是原视频内容，接入时换成真实数据。

## 和原版的差距

方块每一帧的图案是看视频重写的，节奏和形状只是相近，不是逐帧相同；0/1 雨的具体数字随机。

测试参数：`?i=<时间线序号>` 停在某一状态，`?f=<帧号>` 停在某一帧。
