# notch-feedback

含原作素材，只留本机。壁纸、复古电脑图、贴纸和地图都是从原帖录屏截的，不公开、不推送。

来源：Amelia Wattenberger（@Wattenberger）2026-10-30 发帖 https://x.com/Wattenberger/status/2116242404366037068 ，产品叫 Intent，帖子放的是 56.8 秒录屏。页面布局、文字、时间线都从录屏量出。

## 机制（从录屏看到的，源码未公开）

1. 反馈入口藏在屏幕刘海里。平时只有一条 320×37 的黑条，打开时在原位变成 485×522 的面板，顶边始终贴屏幕，不离开原位。
2. 工具条跟随刘海或面板的下沿，收起时贴刘海，展开时贴面板；当前工具用黄底。
3. 按下录音后，菜单栏亮一颗橙色麦克风，面板显示 Listening，输入框的按钮变成黄、橙、黄。
4. 录音时可以收起面板去操作页面：拖框圈选、切换页面、再展开。圈选的序号和转写文字里的序号对应。
5. 转写里插入“Recording 1 / Recording 1 ends”这种标记，表示这段话对应屏幕录制的起止。
6. 不打开完整应用就能反馈，这是原帖作者说的卖点。

## 可学

- 入口放在每个应用都看得见的位置，又几乎不占地方。
- 语音、圈选、录屏共用一个时间线，反馈就能指着东西说话。
- 文字标记不只是文字，还和页面上的圈选一一对应。

## 不学

- 工具条七个图标没有文字标签，第一次用要猜。
- 刘海形态只适合带刘海的 Mac。

## 和原版的取舍

- Logo 换占位：Apple、Chrome、Slack、ChatGPT、Gemini、标签页站点图标、头像都是几何形。“Chrome”写成 Browser，“Ask Gemini”写成 Ask AI，标签名写成 Thoughts。
- 地图上的卡片和路线烘在截图里，不是真 DOM。
- 三个页面之间的滚动只做了相邻两屏的平移，滚动中经过的内容没有做。
- 文章字体用 Source Serif 4 代替，字形和原版不完全一样。

`?t=秒` 定格某一时刻。
