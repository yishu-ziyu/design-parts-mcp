> Chat is AI’s command line _
As we build interfaces for these new AI models, we keep
leaning on familiar ones. Increasingly, everything is
chat. Much in the same way that everything used to be a
command line.
We kept the command line as computing evolved, but we also
added new ways to work (and think).
Chat is great for giving rough direction. It’s less suited to the
fine-grained changes and little tweaks that follow. Sometimes
I just want to reach in and move something.
