# piano-film — 同一段编舞的 2D 和 3D

含原作素材，只留本机。不公开、不推送。

来源：[@kevin_t_ngo 的帖子](https://x.com/kevin_t_ngo/status/2108582192481992922)（2026-10-09），2026-11-05 查看。作者说明先让 Claude 用 JavaScript 画 2D 动画并写钢琴谱，再把它交给另一个 Claude，用 Blender 按同样的编舞做 3D。

页面上方是 215 张视频截图按 3 帧每秒播放。下方的蜡笔场景是我重写的机制，不是原作者的代码，也没有猫。

## 机制
- 左 2D 右 3D，共用一条时间线，每个动作同时发生。
- 蜡笔质感来自大量短笔触；每秒换几次笔触，线条会抖动。
- 角色踩到哪，哪个琴键下沉；乐谱上的爪印记录走过的步子。

## 可学
- 整部片子都是代码时，可以把编舞原样交给下一步。
- 主角只用方块和两道眉，就有表情。

## 不学
- 帧序列只有 3 帧每秒，没有声音，只能看编舞，不能当成片。
