## 机制

- 画面固定 1440×800，再按 `min(视口宽/1440, 视口高/800)` 整体缩放，所以任何窗口里构图不变。
- 贴纸是一层绝对定位的透明图，每张只有 `translate3d + rotate`，靠 z-index 互相压叠。没有拖拽，也没有物理模拟。
- 「乱」和「整」两个按钮换的是同一批元素的坐标、旋转和宽度，过渡统一 `.9s cubic-bezier(.22,1,.36,1)`；文字块也一起移动和改字号。
- 可点的六张悬停时上移 6px，过渡 .2s。纯装饰的贴纸 `pointer-events:none`。
- 名字是两层：底层白字加 6px 白描边和浅阴影，上层黑字加 1.9px 黑描边，看起来像贴纸。
- 唱片机点击后，在唱片圆盘上叠一层圆锥渐变，`soft-light` 混合，1.4s 转一圈；不是真转唱片图。

## 可学

- 只用一组坐标数据就得到两种布局，切换动效不用另写。
- 把几张拼图当成场景里的导航，同时保留一个整理开关，解决「太乱找不到」。

## 不学

- 贴纸都很大、又是位图，移动端要另做一套布局（原站确实另有一套）。
- 按钮只有图标，没有文字说明。

## 替换和没做的

- 名字换成 yourname，decimal 换成 ledger，链接全部指向 `#`。
- 贴纸是从原站页面按原始像素截的透明图，放在 `source-assets/`。
- 没做：engineering、reading 等子页面，移动端布局，唱片音频。
