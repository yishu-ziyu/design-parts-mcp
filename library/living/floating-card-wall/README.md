# floating-card-wall — 星空里三行反向漂移的卡片墙

含原作素材，只留本机。

来源：[x.com/matteing/status/2105024607552172137](https://x.com/matteing/status/2105024607552172137)，2026-09-29。原帖视频 60 秒，1080×1080。所有数值从视频帧量出，原产品代码没看过。

## 机制逐条

- **三行反向**：中间一行向右，上下两行向左。实测 2 秒移动约 79px 和 80px（1080 画幅）。
- **60 秒一圈**：由测得的速度和第 1、57 秒的卡片位置推算，没有逐帧验证首尾相接。每行 10 张卡，弧长 270°，每秒 4.5°。
- **球面位置**：`x=f·tanθ`，`y=f·tanφ/cosθ`，f=480，φ=±31°。行线向两侧翘起，这是从多张帧反推的。
- **卡片不跟着变形**：真 3D 贴球面试过，梯形变形比原片重得多。改成位置按球面算，卡片自身只取 0.55 倍转角、0.35 倍透视。
- **边缘虚化**：离视线中心超过 46° 开始模糊。
- **内容在变**：幻灯片卡的标题在 Curves / Sage / Primary 之间换，点阵卡变成椅子，蓝卡的年份从 2025 变 2026。
- **协作者标签**：彩色名字牌在卡片上移动、隔一段时间换卡。四个彩色标签的位置和时刻从每 2 秒一张的帧里检测，中间线性插值；白色 AI 标签是看帧估的。
- **星空静止**：只有卡片在动。

## 可学 / 不学

- **可学**：上下行反向，三行就能产生很强的空间感。
- **可学**：位置和形变分开算，既有弧面感，内容又读得清。
- **不学**：原视频的卡片内容、产品名和 AI 品牌标志。本页卡片全部是视频帧摆正后的位图（`source-assets/`），文字不是真文字；品牌标签换成 Assistant。
- **校正值不通用**：`CAL` 是为贴合这段视频逐卡算的，换内容时应删掉。
