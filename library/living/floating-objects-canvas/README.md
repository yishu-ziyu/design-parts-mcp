# 环绕物件落地页和无限画布

来源：@Tanjim38 https://x.com/Tanjim38/status/2112964568616169890 ，站点 https://knowspace.si（查看于 2026-11-05）。物件和卡片图是用 ego 在原站截的图（`source-assets/`，156 张，透明背景保留）。`world.js` 的条目位置、结构和文字、`site-items.css` 的条目样式都读自原站。品牌名换成 Factspace 和 Your Studio，标志是占位。

## 机制
- 落地页：14 个物件沿半轴 600×322 的椭圆公转，每秒 .0749 弧度，前 1.8 秒从外圈旋入。靠下大而实，靠上小而淡并轻微模糊。数值是在原站逐帧读行内样式拟合的，残差约 1e-6。
- 四周有一层 backdrop-filter 模糊遮罩，中间透明，所以边缘的物件显得远。
- 进入：物件模糊放大退场，画布淡入。
- 画布：世界层只用一个 transform。拖动平移带惯性，按住 ⌘ 或 Ctrl 滚轮以指针为中心缩放，范围 .16–2.4。缩放分四档改变条目显示的细节。
- 主题导航：小圆点悬停展开成面板。选中后其他主题的条目变暗，相机飞过去。
- Surprise me：全场压暗，飞到随机主题后再亮起。

## 可学
界面层用毛玻璃岛屿，内容层只负责位置，两层互不干扰。公转用一个函数同时算位置、大小、透明度和模糊，一个数就决定了纵深。

## 不学
本页只收了原点附近约 190 条，原站有几百条并按视野动态生成。
