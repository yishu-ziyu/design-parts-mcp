# event-horizon-scene

含原作素材，只留本机。

来源：Three.js @threejs 转发 Bee 的作品，https://x.com/threejs/status/2113400110415860193 ，2026-10-23。查看日期 2026-11-05。回帖里提到着色器与 XorDev 有关，未核实。原作没有在帖子里给公开页面地址。

## 机制

- 吸积盘是真实光线弯曲：每个像素走最多 84 步，穿过盘面时查一张启动时生成的条纹贴图。上半的弧是盘背面被弯上来的像，靠近一侧因多普勒效应更亮。
- 视界下沿的奶白光带、左下扇形尾巴、盘外细沙不是算出来的，是按原片补的一层。纯光线追踪给出的形状对，但下沿和尾巴的样子到不了原片。
- 紫色场景的环仍是平面拟合，只加了一层条纹。
- 木屋、皮卡、宇航员、花田、草地来自原帖截图（`source-assets/plates.js`、`plates2.js`）。长焦用 86–108mm 原片帧裁的高清版，所以放大不再糊；三段之间按焦距交叉淡化。
- 焦距和拖动：取景数据逐帧量自原片，拖动是分层平移加视差。
- 掉帧时自动降内部分辨率。M2 上 2 倍屏，实测内部降到 1912×1076，约 44 FPS。

## 可学

用少量真素材配一个可信的主光学现象；取景器文字把网页变成“在操作一台相机”。

## 不学

把截图当 3D：贴图角度不会变，长焦和广角之间能看出换了一张图。别硬写“144 FPS”这种假数字，这里显示真实帧率。
