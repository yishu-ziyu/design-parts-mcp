# textbox-morph — 文本框变成控件

来源：[x.com/anishfn/status/2102327334485557422](https://x.com/anishfn/status/2102327334485557422)，取原帖 62 秒视频，读取日期 2026-11-05。代码未公开，本页自写。

原作用模型（帖子写 powered by jev）判断内容，有 19 种卡片。本页用本地正则，只认下面的句式，不接模型。视频里能看清 7 种卡片（日程、清单、专注计时、拆账、取色、提醒、骰子），时区卡只在列表里见过摘要，卡片外观是推测。“按 / 看全部”的列表也是推测。

## 机制逐条

- **同一个容器：** 输入框和卡片是一个元素，高度从 64px 过渡到内容高度，曲线有轻微回弹，420ms。
- **边打边认：** 每次输入都重新解析，类型一变就换控件，内容错峰 40ms 上浮。
- **控件是真的：** 计时能走，拆账人数能改且金额有滚动，取色滑杆能改，骰子能重掷，清单能勾。
- **进历史：** 回车后摘要进入列表顶部，最新一行深色，其余变灰。

试：`25 min focus`、`split 2400 between 3`、`minecraft diamond`、`roll 2d6`、`buy milk, eggs and coffee`、`remind me to pay rent tomorrow urgent`、`dinner with priya friday 8pm`、`3pm pt to ist`。

## 可学 / 不学

- **可学：** 不离开输入框就能得到一个能操作的结果，切换成本接近零；外框连续变形，让人知道这还是同一件东西。
- **不学：** 边打边换控件时不要把未完成的内容当结果提交；识别错了没有手动切换类型的入口，真实产品要补上。
