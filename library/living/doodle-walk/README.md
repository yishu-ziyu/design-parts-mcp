# doodle-walk — 走进手绘小世界的作品集

来源：[x.com/pablostanley/status/2094797787754082449](https://x.com/pablostanley/status/2094797787754082449)，作者 @pablostanley；原站 [world.pablostanley.com](https://world.pablostanley.com)，2026-11-05 查看。

`source-assets/` 是用 ego 在原站逐张截的透明图和角色雪碧图。`world.js` 的摆放、层级和动画、`site-world.css` 的世界样式读自原站页面。`index.html` 的行走、碰撞、提示和扣心是本页自己写的，碰撞不是原站的数据。`rebuilt.html` 是之前的纯代码自绘版。

原作世界里的产品名路牌（hilos、efecto、ROBOTOS、YOINKS、newt、VIZ、squig 路牌、狼头标志）按规则去掉了，左上标志和名字条是占位。

## 机制逐条

- **分层**：地面、物件、天空三层，摄像机只改三层的 transform，天空层多走 3%，云就有一点视差。
- **遮挡**：物件的 z-index 按脚底 y 递增，角色每帧查表取层级，能走到树后面。
- **角色**：一张雪碧图五行五个朝向，左边镜像；前两帧站立，后六帧走路。
- **地形**：浮岛只能从缺口上下，崖壁挡人。
- **界面**：左上生命和硬币，左下名字条，右下键盘按钮。只有这三处。
- **互动**：走近才出 E 提示；撞到人扣心并弹回，弹一句玩笑话；走过硬币自动收。
- **阴影**：真网点，用 CSS 径向渐变铺点。

## 可学 / 不学

- **可学**：作品集可以是一个能走的地方；界面退到角落；扣心这种小惩罚配玩笑话；用 DOM 图片加 z-index 就能做出几百个物件的世界，不必上画布。
- **不学**：手绘素材量才是它好看的主因，这部分不能靠代码替代。
