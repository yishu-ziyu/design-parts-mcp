深圳手账印刷藏品

2026-10-24 的独立快照。这个目录内的代码与图像足以离线运行，不依赖原项目或临时目录。

  • index.html：页面与样式
  • app.js：叠放、抽出、拿近、指针反馈与画中动态
  • assets/：三张 PNG；assets.js：供本地页面读取的同组内嵌图像
  • generation.js 与 generation.css：图像显影

饮料与煎饺以原型照片为题材生成，花朵为示意。当前是本地设计实验，未接入原生 App。

显影使用 Jakub 的公开实现，原 JS 保留为 reference-generation.js。本地 JS 移除了模块导出以支持 file://。

拿取结构参考 Sanyam 的复刻实验；视觉起点是 Adi 的 Live stamp；画内局部动态参考 Chloe 的 Stickers with Jobs。

复用时可整目录复制。改素材时同时更新 PNG 与 assets.js；新方向另存，不覆盖这个已记录的版本。
