# 手绘可操作洗衣机

来源：@Aprilzz423 https://x.com/Aprilzz423/status/2111474111541284890 ，站点 https://colorfigures.vercel.app（查看于 2026-11-05）。原站放了几十个手绘物件，每个是一页 SVG。

## 机制
- 投影：地面圆压扁一半再随转角旋转，每个面得到一个 SVG 矩阵。面的内容按平面坐标画，投影只改矩阵。
- 手绘感：SVG 滤镜用低频噪声移动线条，再叠高频噪声做颗粒。原站的位移图是内嵌图片，这里用 feTurbulence，所以线条的具体走势不同。
- 影子：底面四角沿光线方向平移后取凸包，平涂蓝色。光线滑块转动这个方向，面的明暗也跟着变。
- 舱门：绕竖直铰链算矩阵，超过 90 度切到内侧图形。
- 步骤：按钮推进状态机，状态不满足时弹提示条。

## 可学
用矩阵而不是逐点投影，文字和细节可以直接写在面上，转动时不用重算。

## 不学
滤镜作用在整张图上，动画时比较耗性能。复杂物件要分层。

## 替换和差距
只做了 Fig. 01 洗衣机，左侧其他条目只显示名字，点不开。站点名换成 Playfigures。机器为自绘，机身文字沿用视频里的 WASH、WASHMATIC 9。字体沿用原站的系统等宽字体栈，未打包字体文件。
