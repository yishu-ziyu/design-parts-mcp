# promise-wall

来源：https://x.com/thebuggeddev/status/2088279833130491950（@thebuggeddev），公开源码 https://github.com/thebuggeddev/promise-wall 。日期 2026-08-14，复刻于 2026-11-05。

这一页不是照视频重写，而是原仓库 `index.html` 的本地化副本：Three.js r128、GSAP 3.12.5、字体都放进本目录，Logo 名字换成占位。仓库没有许可证文件，不要公开或用到产品里；要用就只学机制。原站 promise-wall-ashen.vercel.app 在 2026-11-05 显示部署已暂停。

## 机制
- 所有纸条都是世界坐标里的网格，不是 DOM；纹理由 Canvas 2D 画（撕边、横线、手写字）。
- 摄像机每帧向目标靠近 8%，鼠标让视线轻微偏移。
- 选中：纸条抬起放大，其他变暗，摄像机推近，右侧面板滑入。
- 放置：纸条跟手、带速度倾斜；屏幕边缘自动平移；点击后下落、压扁回弹、图钉后落。
- 程序化音效只在用户操作后才启动。
- `prefers-reduced-motion` 时去掉摇摆和下落动画。

## 可学
- 把“提交”做成一个摆放动作。
- 纸张纹理全程序化，不用图片。

## 不学
- 手机上和读屏器上的可用性：纸条内容只在 canvas 里。
- 数据只在内存里，刷新就丢。
