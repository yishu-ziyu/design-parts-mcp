#goo
黏糊本体（前层 SDF 着色器）：头（椭圆 17.5×13）、脖子、身体在同一张距离场里，blend() 按 smooth-min 权重同时混距离和颜色（k = 11），所以脖子从头的 #323237 渐到身体的 #fe5462。脖子 = 头 → 控制点 → 身体的二次贝塞尔上排 10 段 round-cone，中段收细 pinch = clamp((L − 60) / 220, 0, 0.38)；两中心距超过 118 断开，两边各留一根尖尾巴弹回（头侧 27、身侧 16）。变胶囊不换图形：猫的距离场直接 mix 到圆角矩形。
#desk
窗口和标签（后层 SDF 着色器）：代码窗口（圆角 32）和顶边梯形标签 smin(k = 9) 合成一块；标签停稳高 37，弹簧 230 / 9 给出回弹；变输入框时长到高 67、顶部半宽 193，里面是 #3d3d42 灰胶囊。拖着靠近时窗口朝小猫鼓起（吸引的 smin 半径 0 → 26），能放下时外沿亮一圈 6.5 宽的浅蓝描边。刘海同一套梯形：底宽 87、顶宽 130、深 44、底角 13。
#world
字和着色器用同一台相机：DOMMatrix = 居中 → 适配缩放 → 透视 m34 = −1/1150 → rotateX/Y/Z → 缩放 → 平移。DOM 层（代码、报错、输入字）直接吃这个 transform，着色器吃它 3×3 部分的逆（uHinv）把屏幕像素映回世界坐标，两边逐像素对齐。镜头 23 个关键帧从原视频帧拟合（刘海段缩放约 2.3、窗口段约 1.12），关键帧之间按时间加权的 Hermite 插值。
#stage
一个状态机，两种驱动：home → grab →（retract | carry）→（return | dock）→ input → think → done → dock，弹簧按固定 240 Hz 步长积分。自动演示是写死的光标路径加按下 1.38 s、松开 5.16 s、打开 6.28 s、提交 7.78 s，喂给和真人输入同一个 step()：12 s 循环，任何时刻都能复现。点画面任意处切到试玩，镜头按 1 − e^(−3.2·dt) 趋近能同时看见刘海和窗口的机位。
#faces
表情和反馈是叠在着色器上的 SVG：点眼 → 悬停眼睛放大 → 按住眯眼「> <」→ 拖 1.35 s 后惊讶（竖条眼 + 小圆嘴）→ 拉断变笑脸，3 颗心在 0 / 0.2 / 0.34 s 冒出；两中心距 45–75 之间汗滴（#9cc6e4）渐显。思考：右上蓝点 #0a8bff（半径 = 猫宽 × 0.19）加头顶红色火星；完成：点变绿 #24c15a，12 颗红点 0.9 s 内从半径 22 散到 40。
