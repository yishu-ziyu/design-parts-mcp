# notchpet — 刘海里的黏糊小猫：拖出来、拉断、停到窗口上变输入框、修好代码

来源：https://x.com/imbabybrooklyn/status/2113469231429980501 （Brooklyn Nicholson @imbabybrooklyn，2026-10-23，视频 12.05 s，960×540）；引用推 https://x.com/imbabybrooklyn/status/2113441535304040617 。原作是 macOS 原生 app，有人问是不是只支持 Mac，作者答 "Swift/Metal is very good"；产品代码还没发布（原推说之后会完全开源）。拉丝怎么画的，作者在回复里说了："It's 2D SDF smooth unions"，界面其他部分也是这种黏糊元素。演示片不是录屏：作者说是用 [brag](https://github.com/latent-spaces/brag)（agent skill，读项目、写镜头计划）交给 HeyGen 的 [Hyperframes](https://github.com/heygen-com/hyperframes)（用 HTML 渲染视频）出的片。

调性一句话：同一团形状贯穿所有状态——刘海里的头、拖拽手柄、窗口标签、输入框、状态点都是它变出来的，画面里从来没有「弹出一个新控件」。

## 这一页是什么

- **12 s 自动循环**，一个连续的 3D 倾斜跟拍镜头：刘海 → 拉出 → 拉断 → 跟拍横移到代码窗口 → 停靠 → 变输入框打字 → 思考 → 代码修好 → 完成 → 拉远。底部进度条走一圈重来。
- **试玩**：点画面任意处切过去，镜头拉远到同时看见刘海和窗口。从刘海拖出来，放到窗口上就停靠；不过线松手会缩回去；点小猫打字（中文输入法也行），回车提交；「自动演示」回到循环。窄屏（< 560px）换一个镜头。
- 自动演示和试玩**共用一个状态机**：自动演示只是一段写死的光标路径加按下 / 松开时刻，喂给和真人输入同一个 `step()`。
- 底栏右端「可拆 ↓」跳到页尾零件清单。

## 实现要点

- **叠层顺序**：`#desk`（后层着色器）→ `#world`（代码、报错、输入字，DOM）→ `#goo`（前层着色器，透明底）→ `#faces`（表情、汗、心、火星、红点圈、状态点，SVG）→ 光标层。
- **一台相机两种吃法**：`DOMMatrix` = 居中 → 适配缩放 → 透视 `m34 = −1/1150` → rotateX/Y/Z → 缩放 → 平移。三层 DOM 直接用它当 `transform`；着色器拿它 3×3 部分的逆矩阵 `uHinv`，每个像素映回世界坐标再算距离场。抗锯齿宽度按「一个屏幕像素在世界里多长」现算，倾斜镜头下边缘也不糊。
- **颜色和距离一起混**：`blend()` 用 smooth-min 的同一个权重 `h` 混距离和颜色，所以拉丝的颜色过渡天然落在形状过渡上。
- **状态机**：home → grab →（retract | carry）→（return | dock）→ input → think → done → dock。从停靠的标签上也能再拖出来（锚点换成标签）。
- **确定性**：自动演示每圈从 `fresh()` 重来、随机数种子复位，任意时刻可复现；`window.__seek(T)` 跳到循环里的 T 秒同步渲染一帧（截图对比用），`#clean` 隐藏底栏。
- **点击不丢**：一次按下 + 松开可能落在两帧之间，补两步「按下」再积分，点小猫一定能打开输入框。
- **打包时的改动**：原页是 `position:fixed` 铺满、不能滚；这里改成 `100svh` 高的舞台，页尾接「可拆」，底栏加「可拆 ↓」入口（触屏上舞台吃掉了滚动手势，靠它下去）；代码窗口内容重写；字体本地化。

## 和原作的差距

- 原作是 Swift + Metal 原生渲染，视频有压缩和轻微动态模糊；这里边缘更干净，没有动态模糊。
- 表情是照着帧画的近似版：眯眼、惊讶、思考时的眼神没有逐帧对齐，思考时左右看的节奏是猜的。
- 脖子：原作靠近身体那段更鼓、更像液滴，这里是一串圆锥，鼓得不够；2.0 s 时身体也比原作小一点。
- 火星粒子和完成时那圈红点，数量和轨迹是估的。
- 相机在关键帧之间是插值出来的；2.0 和 2.5 s 两帧拟合误差较大（10–15 px），这段运动和原作有偏差。
- 代码字体用 JetBrains Mono 代替，原作斜体更圆；标题字用 Inter 600 代替 SF Pro Semibold。
- 作者答应加的「别打扰我一小时」睡觉状态没做；没有声音。

## 接入（file:// 直开，运行时零网络）

- `fonts/`：Inter 400 / 500 / 600 取自 `@fontsource/inter` 5.3.0，JetBrains Mono 400 正体 + 斜体取自 `@fontsource/jetbrains-mono` 5.3.0，都是 latin 子集 woff2（OFL-1.1）。`@font-face` 相对路径 + `unicode-range`，中文落到系统字体。
- 没有外部脚本、没有构建：两段手写 GLSL + 原生 JS。`grep http index.html` 只剩 SVG 命名空间字符串，不产生请求。
- 没有 WebGL 时显示一行提示，不画形状。
- 验证：Playwright（swiftshader）拦掉所有非 `file:` 请求打开，零失败请求、零控制台错误，5 个字体文件全部 `loaded`；自动循环在 2.5 / 4 / 6.45 / 10.6 s 定帧正确；试玩里拖出 → 拉断 → 停靠 → 点开输入框 → 打字回车 → 思考 → 修好 → 绿点，一路走通。

## 可拆

- `#goo` 前层 SDF：头 + 10 段 round-cone 脖子 + 猫身，颜色随 smooth union 权重混，过阈值断开、两根尖尾巴弹回。
- `#desk` 后层 SDF：窗口 + 梯形标签 smin 合一，标签弹簧回弹、长成输入框，拖近时窗口鼓起、外沿描边。
- `#world` DOM 和着色器共用一台相机（DOMMatrix + 逆单应），镜头关键帧从视频帧拟合。
- `#stage` 状态机 + 240 Hz 弹簧，自动演示是喂给同一个 `step()` 的光标脚本，点一下切试玩。
- `#faces` 表情序列、汗滴、心、火星、完成红点圈、蓝 → 绿状态点。

## 启示

产品页不放静态截图：只挑一个最核心的交互，做成带 3D 倾斜的跟拍循环，再让人直接上手拖，两者共用一个状态机。对着参考视频复刻时，先从帧里把镜头参数拟合出来，再调动作——镜头对了，剩下的差距才看得清。
