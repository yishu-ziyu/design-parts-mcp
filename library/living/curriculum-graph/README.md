# curriculum-graph — 课程前置关系的三维点云

来源：Lionel Mora（@lionel_mora）为 Marble 做的动态课程图谱，https://x.com/lionel_mora/status/2074488408425066842 ，2026-07-07。复刻于 2026-11-05，依据是帖子视频的 18 帧。没有打开原站，帖子里也没有外链。

## 机制

- 1144 个点分布在三片竖直扇面上，整体是一个向上张开的 V。正对一片扇面的边时，它会缩成一条竖线，这是这个图形最抓人的瞬间。
- 点云中轴是一条弯曲的线，和自转轴不重合。转动时点云摆头，转到特定角度才变直。这是从三张视频帧反推的，原站实现未知。
- 点按高度分布：下面稠密（低龄），上面稀疏（高龄），顶部有几个离群点。
- 点一个点：沿前置关系走完整条链，边按层级依次长出来，其余点压暗到 17%，右上角钉住计数卡。
- 钉住后悬停别的点只出提示，不换链；点空白处或关闭按钮才解除。
- 图例按学科开关；拖动旋转带惯性；滚轮缩放，缩到最小后滚动还给页面。

## 可学

- 只用一个暗到几乎没有的页面，把全部颜色留给数据。
- 「压暗其余 + 高亮一条链」把一团毛线变成一句可读的话：学这个之前要先学这 87 个。
- 大字衬线标题和极小的无衬线说明之间的字号落差。

## 不学

- 1144 个点的颜色没有编码信息，同一学科里混着多种色相，只是好看。需要读数据时不要这样配色。
- 没有文字版的同等入口，键盘用户点不了点。

## 和原版的差距

点和边的数据是按种子生成的，只有形状和数量对得上，不是真实课程。只从视频读到 9 个概念，其中 2 个没有正文，其他点复用同学科的文字；有几段因帧太小按可读部分补全，可能有出入。Logo 换成占位。
