# manga-flip — 动画改成能翻页的漫画

含原作素材，只留本机。不公开、不推送。

来源：[@aicreataro 的帖子](https://x.com/aicreataro/status/2109192628818563353)（2026-10-11），2026-11-05 查看。作者说明用 Python 把动画分离线稿和颜色，再排分镜、翻页。

页面上方是 171 张视频截图按 5 帧每秒播放，上半是原动画，下半是漫画版。下方三块是我重写的机制，不是原作者的代码。

## 机制
- 同一镜头依次出现草稿、线稿、上色。
- 分镜是歪斜的粗黑框，镜头在纸面上移动、跟随分镜。
- 拟声词一字一字落下，配爆炸形和集中线。
- 翻页时书页绕书脊转动，纸面有书脊阴影。

## 可学
- 把“一张一张做图再排起来”当成做法，修改只需重新导出。
- 上下对照原片和加工结果，一眼看出加工了什么。

## 不学
- 帧序列只有 5 帧每秒，又没有声音，只能用来看分镜和节奏。
- 拟声词是系统字体，手写感不如原版。
