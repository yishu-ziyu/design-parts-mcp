# terrain-builder

来源：https://x.com/artficialisabel/status/2081861163256783337（@artficialisabel，2026-07-27），复刻于 2026-11-05。

状态：未达标，见 `原料/x-收藏/results/2081861163256783337.json`。工作台界面接近，3D 地形还差得明显。

视频的界面部分只有 480p，看不清的文字是按字形猜或自拟的。名称 NAPOLEON 换成了占位。

## 机制
- 高度函数生成地形，按坡度把三角形分给草地和岩石。
- 河流是贴地的带状网格，贴图滚动。
- 角色是从视频裁下的 PNG，朝向相机；这里只做上下轻晃，没有逐帧动画。
- 战术草图可以涂，涂的结果目前不会反馈到 3D 场景。
- `prefers-reduced-motion` 时停止水流和角色晃动。

## 可学
- 两步式编辑：先涂地块，再出效果。
- 按坡度分流三角形，低成本得到断崖。

## 不学
- 手工按截图摆平台，这只是为了贴近原版的这一个画面。
