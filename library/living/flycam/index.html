vendor/three.min.js
three.js r147 的 UMD 构建（构建期 npm pack three@0.147.0，解包取 build/three.min.js，608 KB）。普通 <script src="vendor/three.min.js"> 加载：file:// 直开可用，ES module 版会被 CORS 拦。运行时零网络。
#panes · 一个 renderer，两个窗格
一块 canvas 铺满两窗格，setScissorTest(true)，每帧两次 setViewport + setScissor + render：左 = 正交俯视 + rig 覆盖层，右 = 透视成片机位。选 scissor 而不是两个 renderer：一个 WebGL 上下文、几何/纹理只上传一次，代价只是多一遍 draw call；两窗格共用同一 scene、同一 render(t)。雾按相机深度算，逐遍改 FOG.near/far（编辑视图抬到 1e6）。
#camrig · POV 铸镜头
起点 + 5 站共 6 个体位（位置 + lookAt 目标写在参数区），段长 [0.20,0.16,0.24,0.20,0.20]，总 12s。每帧 position 走段内 smoothstep；lookAt 目标在两站之间线性插值（前 62% 段长稳住看本站，62→82% 段长转头看下一站）。没有 parenting、没有 null：位置和朝向都是 t 的纯函数，scrub 到哪帧都对。
#rig · 真 CameraHelper 黄视锥
three.js 原生 CameraHelper(shotCam)：视锥线框 + 机身 + 朝向三角由它自己画。左窗格渲染时把 shotCam 的 near/far 收成 8/620——这样视锥是「一台相机」的形状而不是一根长针；setColors() 把原生红蓝白收成暖琥珀一套。航线 = LineDashedMaterial + computeLineDistances()，5 枚八面体路径点 t ≥ 到达时刻 从线框换实心，站号 01–05 是 Sprite。
#timeline · 双向时间轴
播放/暂停/重播、拖拽 scrub、菱形刻度跳关键帧、?demo=progress=X 定帧；两窗格 + 时间轴同吃一个 render(t)。reduced-motion：无自动播放、t=1 终帧静态、时间轴仍可拖（?rm=1 等价，便于无头自检）。
#cards · CanvasTexture 排版
三张卡（MOTION / GRAPHICS · 001 / UI 面板）都是 CanvasTexture 现画：衬线大字 + 等宽小字 + 琥珀细节，anisotropy 拉满（斜看字不糊）。文字绕柱 = 实底画布上横向平铺的字（绕一圈出现两次）+ 画布自带柱面明暗，材质 FrontSide（DoubleSide 会从镂空里看见背面镜像字）。
