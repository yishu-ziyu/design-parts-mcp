# camera-frustum-split — 相机视锥与成片并排的编辑器

来源：[x.com/JCKHLRY/status/2097668575255236907](https://x.com/JCKHLRY/status/2097668575255236907)，复刻日期 2026-11-05。原帖 5 秒，3488×2160。

## 机制逐条

- 左边是侧面灰度视图，右边是相机看到的彩色画面，两边用同一张世界图。
- 相机路径不是猜的：用 SIFT 逐帧匹配右侧画面，得出每 0.1 秒的相机位置和缩放，存进 `cam-data.js`。
- 右边：世界图乘相机矩阵。左边：再乘一个从原帖量出的单应矩阵（`matrix3d`），加灰度和压暗。
- 视锥固定在屏幕同一位置，世界在它后面移动，所以看起来是相机不动。
- 长棍面包离相机更近，单独一层；原片里面包会转动，所以用两张截图交叉淡入（0.2–0.35 秒）。
- 时间轴可拖动，读数按 60 帧走（秒:帧）；关键帧菱形在 0、0.98、2、3、3.73、4.59 秒。
- 3.4 秒后的右边、4.1 秒后的左边改为逐帧播放原帖截图（通知弹出和地图切换）。

## 可学 / 不学

- 可学：把成片和镜头在场景里的位置放在一起看；用一个矩阵表同时驱动两个视图。
- 不学：Paris 手账的具体素材；窗口标题已换成占位。
