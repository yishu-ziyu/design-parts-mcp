第一份偶像卷宗。

交互机是 Mosby 那套。点贝克勒的页签。抽屉走，同一块皮 Flip 到纸上，封面从左边翻过去。桌上是能单独拖开的照片、便签、剪刀、圆规。另外三格空着，不虚构人。

内容在 cases.js。动效不重写。这是试版：先看效果，再接到功能档案的房间海报。

GSAP Flip / Draggable 和 Lenis 都在 vendor/。封面还是 1.5 秒 power3.inOut。只有一份卷宗时，下一案小窗不出现。

这次怎么换的

  1. 壳是 living/mosby 已验证过的交互机，不是 Codex 那版卡片墙式档案柜。
  2. 点开还是同一块皮。Preserve Context。
  3. 文件夹就是文件夹。Familiarity。空格写明「待归档」，不是坏了。
  4. 先柜子，再纸，再剪贴。渐进揭示。没有第二个人，就不假装有下一案。
  5. 颜色跟案子走。贝克勒是高地绿 #2F6B4F。不要蜡笔红。
