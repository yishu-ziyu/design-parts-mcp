# craft-diagram — 蜡笔手绘的工序状态图

来源：[x.com/ann_nnng/status/2116811409921372642](https://x.com/ann_nnng/status/2116811409921372642)，读取日期 2026-11-05。帖内 32 秒视频和 4 张图，以及回复里的公开演示 https://cloud.typingmind.com/artifacts/a-01m6b40rcmy915sapez8bxyae6 。节点、连线、步骤文案和场景摆位读自演示页源码；蜡笔引擎是我重写的，用来画状态图；人物、道具和场景是用 ego 在演示页按步骤截的图（`source-assets/`），每个区域按步骤分状态，每个状态 4 帧循环，切换时淡入（`sprites.js`）。`rebuilt.html` 是之前全部用代码自绘的版本。演示未写明许可证，TypingMind 徽标不收。

## 机制逐条

- **蜡笔线：** 折线每 4px 重采样，叠两组正弦抖动，粗细沿线变化，画两遍。
- **颗粒：** 颜色画到 96px 图块再随机打孔，当图案填充，出现蜡笔的纸纹。
- **影线填色：** 先裁剪形状，再铺颗粒底色和分段的斜向短线。
- **手绘颤动：** 所有随机数由“名字 + 颤动序号”决定，每秒换 5 次、循环 3 个序号，线条微颤但不乱跳。
- **状态图节奏：** 每步 3.6 秒：走线描出、红点沿线走、标签打字、票据弹出并加粉色描边。默认 3 倍速，实测 1.6 秒从 1/27 走到 3/27。
- **并行区域：** 第三张里天气和院子两条泳道同时亮，下雨时插画里的花扇收起。
- **插画状态：** 插画随步骤切换状态，和状态图同步；第一张的花扇仍是代码画的，逐把打开。
- **自动跟随：** 活动节点离开视口中段才滚动，用户滚轮或按下就停。

## 可学 / 不学

- **可学：** 把流程图和它描述的世界画在一张纸上，状态变化同时驱动图和插画；用可重复的随机种子得到稳定的手绘感。
- **不学：** 插画量大、难复用；27 步自动播放不适合需要快速查阅的文档。
