# column-deck — TweetDeck 式多列个人站

含原作素材，只留本机。

来源：[x.com/cheweileee/status/2098276399723221354](https://x.com/cheweileee/status/2098276399723221354)，2026-11-05 看原帖视频（15s，960×720）。帖子没有外链，作者主页写着 cheweilee.com，2026-11-05 打开过。数值按视频像素量，CSS 1px 对应视频 1px。配图是用 ego-browser 在原站放到 2 倍截的（source-assets/），工作台第一张是原站视频的 14 张暂停帧逐帧播放，背景画只有视频露出的上边和左边是真的，其余用这两条边填充并模糊。原站现在的列宽和部分内容已经和视频不同，本页按视频。

## 机制逐条

- **骨架**：毛玻璃窗口套白底；左侧固定 264px 侧栏，右边一排 299px 定宽的列，整排横向滚，每列各自纵向滚。
- **导航**：点某项，把对应列平滑滚到侧栏右边（约 620ms，三次方以上缓出，我按帧估的）；到不了就停在最大滚动处。
- **活动标记**：3×13px 黑竖条进入，文字右移 7px 并变深。
- **闪一下**：目标列背景先灰 #dcdcde，保持约 0.7s，再用 0.6s 退掉（按帧估），告诉你眼睛该看哪。
- **列内滚动**：往下滚时列头滚走，顶部 46px 模糊遮罩出现，浮出“↑ 列名”胶囊，右侧出现 6px 滚动条，停下 0.7s 后淡出。
- **卡片**：项目卡用媒体主色做深底、图片四周模糊融入；工作台卡是白卡，图居中，两侧是同一张图的模糊版；相纸卡白边加手写字。

## 可学

- 把个人站每个分区做成一列，全部内容同时可见，不必翻页。
- 导航不换页，只滚动，再用一次背景闪烁把视线带过去。

## 不学

- 作者的姓名、经历、照片和产品图：文字来自原帖视频和原站，图是原站截图，里面有 Nav、Wahoo 等产品名；要用时全部替换。
- 窄屏上这种布局不成立，要另做单列。
