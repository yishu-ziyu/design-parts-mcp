# telemetry-dash — 显示真实数据的遥测面板

来源：[x.com/mickces/status/2065387473794994355](https://x.com/mickces/status/2065387473794994355)，读取日期 2026-11-05。帖内 21 秒视频，以及帖子外链的公开站 https://project-nullframe.vercel.app 。CSS 数值、字形函数、数据逻辑、文案读自该站公开页面和脚本，用原生 JS 重写。线上版已有声音开关并改了文案，这里按视频的 V4.0.0 版默认显示，加 ?sound 才出现声音开关。

## 机制逐条

- **一条总线：** 一个 rAF 驱动所有画布，指标每 0.5 秒刷新。
- **真实优先：** 帧率来自 rAF，内存、电量、网络读浏览器接口，读不到就标 SIM。实测本机读到帧率 60，四个标签都是 LIVE。
- **地震仪：** 300 点环形缓冲记录指针速度，速度除以 1800 后取 0.7 次方，再叠正弦底噪。实测移动指针后 EVT/MIN 从 0 升到 10，曲线起伏。
- **字形屏：** 11×7 格，9 个图案函数每 1.6 秒切换，每格错峰回弹。
- **贡献格：** 对角线错峰砸入，每 650ms 随机闪白一格。
- **状态行：** 打字机循环 5 句，活动流老行逐行变淡。
- **⌘K 面板：** 专注模式、重摇时钟、关闭动效。

## 可学 / 不学

- **可学：** 把读不到的数据明说成 SIM，装饰性面板也能保持诚实；单一 rAF 让十个动画共享节奏。
- **不学：** Contributions 和 Streak 是假数据，不能当真实指标；电量和内存接口不是所有浏览器都有。

## 和原版的差距

版式、字体、配色、各卡内容与视频并排几乎重合。差距：贡献格按种子随机，单格分布不同；视频里 3 行活动流的透明度是目测；页面默认读真实数据，并排图第一行用 ?demo=1 固定成视频里的数值。
