# beacon — 一张字形表排三张动态海报：形状定密度，光束把字解码成格子

来源：

- 原帖 https://x.com/nickbakeddesign/status/2113391263345263048 （2026-10-23，「more from the boat series / motion posters」，三段视频；引用了 10-22 那条四张静帧的帖子）。
- 作者 Nick（@nickbakeddesign），[Baked Design Studio](https://baked.design) 创始人兼创意总监。工作室在温哥华，订阅制给初创公司做品牌、产品设计、官网和发布视频。
- 这组属于他 2026-10-22 开的系列：给想合作的公司做探索稿。boat 是第二个（boat.dev，给 agent 用的云端虚拟机 / 沙箱）。
- 代码没有公开。过程只有一句回复：「figma + claude + my imagination + custom app I built for creating posters based on our designs」（https://x.com/nickbakeddesign/status/2113429172626608209 ）。他说之后会分享流程，到 2026-10-24 还没发。
- 下面的数字来自把视频逐帧画进 canvas 读像素，坐标都在 1240 × 1754 的原始帧上。

调性一句话：一张字形表、一个 9 秒节奏，每张只换形状；画面里只留一个一直在动的东西，而且它在演产品的动作。

打开 [index.html](index.html)。左边是海报和多泳道时间轴，右边切三张海报、调参数、打开「显示网格与密度图」看规则。

## 这一页是什么

- **三张海报**：01 BEACON（灯塔，深灰）/ 02 SWELL（涌浪，浅底 + 蓝色块）/ 03 CREST（卷浪，蓝底 + 深色面板）。同一张字形表，只换形状。
- **品牌是虚构的 skerry**：自绘的灯塔标（底座、收窄的塔身、灯室、两道光）+ Funnel Display 写的 `skerry`。表格、终端日志、标题文案都是新写的；原作 boat 的帆船 logo 和文案一个都没进来。
- **参数**：网格列数（灯塔 36–90，浪 20–60）、密度偏移 ±0.35、光束张角 12–70°（只有灯塔）、播放速度 0.25–2×；「换一组随机」换噪声种子，「从头播放」。
- **字形表**：右栏一条，从稀到密排出这张海报用到的字形。
- **这张的规格**：画幅、网格、字体、循环和色票，随参数实时更新。
- **时间轴**：每个阶段一条泳道（表格逐行 / 灯塔自下而上 / 光束，或终端逐行 / 标题去模糊 / 字形场 / 状态灯），可拖；空格暂停，← / → 换海报。
- `window.__poster.{select, seek, set}` 给截图定帧；`prefers-reduced-motion` 时停在 6.0s 的定住帧。深浅主题跟系统。

## 实现要点

- **一张 Canvas 2D，一套逻辑坐标**：1240 × 1754 里布局，`setTransform(kScale)` 缩到显示宽度，像素比封顶 2。窄于 760px 时改成上下排。
- **密度图**：灯塔和浪先画成白色矢量剪影，画到每格 4 × 4px 的离屏画布上，模糊约 0.55（灯塔）/ 0.7（浪）个格，每格取平均透明度当密度。浪 = 浪体 × 0.5 + 浪顶带 × 0.62，所以浪顶最密。
- **挑字形**：密度加一层分形噪声（灯塔 ±0.17，浪 ±0.21），按几档阈值分类：灯塔 0.14 / 0.36 / 0.62，浪 0.1 / 0.3 / 0.55 / 0.78。最稀的一档再按哈希空掉约一半，所以边缘是散的。灯两侧手放了两个黄格（0 和 1）。
- **出现时间**：每格存一个 `t0`，`t < t0` 不画。灯塔按行号从下往上，浪按列号从左往右，再加一点随机延迟。
- **光束**：两个反向楔形当裁剪区；区内重铺一遍底纹把文字盖掉，再叠 `#8598F7` × 31%。文字层（表格、logo、标题）预先用白色以半分辨率画到离屏，按 0.65 × 灯塔格统计每格笔画覆盖率，≥ 0.07 的格子换成字形；中心角度落在光束里的格子才画。灯塔长完就不再变，光束只改它压到的文字。
- **纹理**：值噪声 + 分形噪声。蓝色块按全分辨率生成，用阈值做出浅色斑点和暗坑，再加逐像素颗粒；深灰和纸色是低频云状噪点。按显示宽度生成一次，缓存复用。
- **字体加载后重算**：字形格子的字号和光束解码都依赖真实字形，字体加载完清掉字高缓存和解码缓存，下一帧按真字体重新统计。

## 和原作的差距

- 灯塔轮廓是按测量值近似画的。原作塔身更有结构：左侧有整列的 I / A，中间有成块的空格，像窗户；这里分布更均匀，更像纯噪声，而且偏宽偏密。
- 原作有些地方看得出手工调过，比如底座右下那几排十字和菱形；这里全部由噪声决定。
- 蓝色纹理是程序生成的。原作更像扫描来的孔版印刷纹理，放大后斑点形状和颗粒都不一样。
- 02 和 03 的浪形是自己画的曲线。原作的卷浪更陡、浪唇更长，涌浪的起伏节奏也不同。
- 字体是推断（Kode Mono、Inter Display、Funnel Display）。这里没有 Inter Display 的文件，01 标题用带 opsz 轴的 Inter 可变字体。
- 02 / 03 长完后每 0.5s 换约 1% 的字形；原作基本完全静止。
- 没有复刻 10-24 收尾帖里的 4 段 explorations。

## 可学之处

- 一张字形表管三张图：灯塔、涌浪、卷浪只换形状，细节不用重画，放在一起自然是一套。
- 动作在讲产品：光束扫过表格，文字被换成 0/1 和 I/A 的格子，像在读数据；boat 做的正是给 agent 用的云端机器。动效本身就是信息，不是另加的装饰。
- 前 2 秒长出来，后 7 秒定住：任何一帧都是完整的海报，所以作者也直接发了静帧版。能动的只剩一个元素，注意力不会分散。

## 启示

- 作品封面可以共用一张字形表，每个项目只换一张密度图（产品轮廓或界面截图），封面自动成套。
- 封面动效只留一个持续运动的元素，并让它演示这个产品的核心动作：读取、扫描、同步。
- 做一组作品时先定字形表和时间节奏，每件只换形状；多做一张的成本很低。
