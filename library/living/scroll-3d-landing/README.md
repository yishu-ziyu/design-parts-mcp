# scroll-3d-landing

来源：https://x.com/MengTo/status/2085765403729653877（@MengTo，2026-08-07），复刻于 2026-11-05。原帖视频是在桌面应用里滚动本地页面的录屏，没有可打开的线上页面。

这不是原版的真 3D。原版用 three.js 的 3D 场景；这里用从视频截下来的画面做分层贴图，按滚动关键帧移动，只还原了版式和滚动节奏。名字 KAGE 换成占位 SAGE。

## 机制
- 固定画布加滚动关键帧；滚动值每帧缓动 14%。
- 大字夹在前后图层之间。
- 正文用 DOM，叠在画布上。
- 画廊卡片用细分平面，顶点随时间和鼠标轻微起伏，模拟原版的布料感。这个效果是按视频猜的，不是原版参数。
- `prefers-reduced-motion` 时取消缓动、飘动和萤火。

## 可学
- 前后层夹大字的纵深。
- 暗场景上的半透明目录格。

## 不学
- 把文案烧进贴图。这里只有贴图能带来的那部分效果，换内容就得重新截图。
