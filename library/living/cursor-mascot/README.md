# cursor-mascot — 跟随鼠标、被点时眨眼的页面吉祥物

来源：[x.com/nilbuild/status/2099450737684029539](https://x.com/nilbuild/status/2099450737684029539)，原站 [koboyo.com/page-mascot](https://koboyo.com/page-mascot)。2026-11-05 看原帖视频（43.7s，1280×720）并在原站量了样式和时序。2026-11-05 返工：角色换成原站精灵图截图，字体改成和原站一样的系统字。

## 机制逐条

- **两张 3×3 精灵图叠放**：一张放九个朝向，一张放九个表情，都是 `background-size:300% 300%`，只换 `background-position`，不做过渡。原站同样如此。
- **朝向判定**：鼠标离角色中心不到 64px（200px 尺寸下，从原站探测在 50–80px 之间，取 64）时看正前方；否则按 `atan2` 分到 8 个方向。每个角色自己算。
- **戳一下**：`transform-origin:50% 78%`，420ms 压扁回弹，关键帧从原站读出：`scale(1.1,.86)` @18%、`scale(.95,1.08)` @45%、`scale(1.03,.97)` @72%。
- **表情节奏**：立刻切到表情图第一格，很快（原站采样在 70–140ms 之间）随机换到另外 8 格之一，约 570ms 切回朝向图。
- **抽屉**：右侧滑入 220ms，`cubic-bezier(.22,1,.36,1)`，遮罩 25% 墨色。

## 可学

- 用换帧代替骨骼动画：九张图就有了“转头”，零依赖，很便宜。
- 压扁回弹配换表情，反馈比单独动一项更像活物。

## 不学

- 不要把 `source-assets/mascots/` 发布出去，也不要照抄 npm 包名。要公开用就换自己画的两张 3×3 精灵图。
- 52 个角色同时监听对小页面可以，大列表要只算视口内的（页面里已跳过视口外）。
