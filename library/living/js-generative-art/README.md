# 工程图信号流（复刻）

来源：https://x.com/camillerouxart/status/2091525022582030351（Camille Roux，2026-08-23），原作为 30 秒视频，文字写明 100% JavaScript，未公开代码。2026-11-05 查看。

## 机制
- 底图：29 帧逐像素取中位数，去掉移动的信号，留下静态图面。
- 信号：珠串沿折线匀速走，三种珠子（圆环、实心、胶囊）按字母序列排，另有灰色和橙色单珠。
- 读数：面板上的红色折线、条码、色块、放射环轮流出现，每个有自己的周期和偏移。
- 虚线弧：虚线偏移持续变化，箭头沿弧走。

## 可学
一张静态图加几条路径就能活起来：把动的东西压到一种颜色，图面其余保持黑白。

## 不学
底图是截图。要的是生成式手绘线条，需另外实现。

## 和原版的差距
静态画面用的是视频截图取中位数合成的底图，所以版式和线条几乎一样，分辨率也只有视频的水平（1134 宽，放大会糊）。差距：原作每处都由 JS 生成，这里只有红色信号和读数是代码画的，生成算法没有复刻；信号路线和读数位置是从画面量的，时机是自己排的，不和原视频逐帧同步；原作面板内部的小动作（指针转动、线条重绘、灰色小点）大多没做。
