# bencho — 目录是正在工作的组件

来源：[bencho.dev](https://bencho.dev/)，2026-09-14 从计算样式与打包脚本测量。原站是可交互 UI 块目录。本页收 Blocks 第一屏：轮换动词的标题，加三列全部 29 个正在工作的组件卡片。Bench（`#bench` 点阵无限画布）不收录。原站 GitHub 仓库私有；每个块的 Code 页提供 MIT 的 Usage / CSS。配方抄在 `source/*.css.txt`。

打开 [index.html](index.html)。

## 机制逐条

- **房间**：底 `#fff`，墨 `#17181a`。UI 字体 Inter / Google Sans。
- **标题 `#copy`**：46px / 48.76px / 500 / 字距 −0.92px。最后一个词表 `tune #2231dd`、`bench #b8431c`、`share #7c3aed`、`take #17181a`。字母交错 18ms；进入 `y -0.5em`、`blur(5px)`，弹簧 stiffness 420 / damping 30 / mass 0.9。周期约 6s。
- **胶囊**：14px / 500，padding 12px 18px，圆角 999，底 `rgba(23,24,26,.06)`。
- **副文**：15px / 22.5px，`#a3a29c`。
- **网格 `#grid`**：三列，间距 12px。卡片 472px 宽（1495 视口），圆角 28px，底 `rgba(23,24,26,.06)`。29 张均可指针操作，顺序与原站网格一致。挂载见 `blocks.js`。
- **山羊标**：`apple-touch-icon.png` 180×180。

## 可学 / 不学 / 启示

- **可学**：组件库首页把活组件放进卡片。标题只轮换一个词并染色。卡片层级用浅灰面，不用投影。
- **不学**：不要用分享封面的轨道构图代替 Blocks 第一屏。不要把 Bench 画布和网格混成同一发明。不要把原站照片当 MIT 素材；封面与插图用本页原件。
- **启示**：目录如果只放截图，用户看不到手感。静帧对照开关就是为了把这件事拆开。
