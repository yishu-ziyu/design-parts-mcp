/* THE THREE FORMATS HAVE THE SAME AREA, and that is the
   whole idea. The common build fixes the width and lets the
   height do whatever the ratio says â which makes the
   landscape a third of the portrait, so switching feels like
   the picture GREW rather than like it was cropped.

   Equal area is what a crop actually is: the same amount of
   picture, held a different way. Within 0.02% across all
   three, and every shape fits inside one 276 square, so the
   block's bounding box never changes and the wall cannot
   rescale it mid-move. */
land   276 x 207     /* 4:3 */
square 239 x 239     /* 1:1 */
tall   207 x 276     /* 3:4 */

/* WIDTH AND HEIGHT, NEVER A SCALE. The same rule the detail
   overlay's block follows and for the same reason: a scaled
   box drags its corner radius with it, and the corner has to
   read as the same rounded frame throughout rather than as a
   rectangle being stretched. */
transition: width 520ms cubic-bezier(0.22, 1, 0.36, 1),
            height 520ms cubic-bezier(0.22, 1, 0.36, 1);

/* COVER is what keeps the picture undistorted while the frame
   moves, so this reads as a crop changing â which is what it
   is â rather than as an image being squashed. Contain would
   letterbox it and fill would stretch it. The source is 3:4
   and is not cropped in the file, so one picture makes all
   three and the portrait tab is the whole illustration. */
background-size: cover;
background-position: center;

/* THE STAGE IS THE FULL SQUARE and never changes size, so the
   picture is centred in a box that is not moving. Sizing the
   stage to the picture instead makes the tabs below it climb
   and drop as the shape changes â the one thing here with no
   business moving. */

/* ONE THUMB SLIDING, not three backgrounds fading. A fill
   that appears under the new tab while another disappears is
   two events; a thumb that travels is one, and it is the one
   that says these three are positions of the same control.

   And it LEADS: its duration is a fraction of the picture's
   rather than a number of its own. A control that takes as
   long as the thing it controls feels like it did not hear
   you; one that arrives first reads as the cause of what
   follows. */
transition: transform calc(var(--asp-ms) * 0.55) ...;

/* THE ICONS ARE THE SHAPES. Drawn rather than imported â
   lucide does ship a rectangle in each orientation, but here
   the icon is not a symbol FOR the format, it IS the format,
   so it has to be at the real ratio. Same constant area as
   the pictures, or three marks of visibly different size
   would say the formats are different sizes. */
