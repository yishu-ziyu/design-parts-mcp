01 拖

玻璃跟着指针走

折射的是一份克隆。真场景还在下面。两层要对齐，不然字会裂开。

02 穿

蓝球用 left，不用关键帧

Safari 把 transform 动画丢给合成器，滤镜采不到。所以球的位置写在主线程上。

03 收

× 变成一粒按钮

500ms 收到底边。回来 600ms。圆角跟着边长走，地图提前烤好，第一次不闪。

不要用 backdrop-filter 冒充

毛玻璃只是糊一层。这块是透镜：离屏画出位移图，喂给 SVG feDisplacementMap，再用 CSS filter 套在克隆上。Safari 不能把 SVG 滤镜接到 backdrop-filter 上。

每动一次换一个 filter id。不换的话 Safari 会把第一帧冻住。这条是 Aave 的办法。
