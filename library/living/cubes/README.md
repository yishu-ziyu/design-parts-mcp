# cubes — 方块长出第三边

来源：[x.com/0xCharlota/status/2098094554259800245](https://x.com/0xCharlota/status/2098094554259800245)，2026-09-10。原帖是 Framer Agent 把三枚正方形建成等轴立方体的录像，72.5s、1920×1080、25fps。本页收完成态：油画底上的三枚立方体，可重播建造，可关漂浮。不收 Framer 编辑器壳。

打开 [index.html](index.html)。

## 机制逐条

- **房间**：站点块白底。画布 `assets/paint.jpg`（本页原件，绿 / 紫 / 赭）。
- **立方体 `#field`**：边长 148px。六个面 `translateZ(74px)`。转角三枚相同：`rotateX(-26deg) rotateY(-38deg)`。描边 1px `#17181a`。无透视缩短。
- **标签**：写在 `.front` 上，IBM Plex Mono 11px。01 Foundation / 02 Systems / 03 Applications。
- **建造 `#build`**：01 → 02 → 03，间隔 520ms。每枚：正方形（只正面）→ 转到体积并露线框 → 填正面与背面 → 两侧 → 顶底。步长 160–420ms。
- **漂浮 `#drift`**：三枚站稳后才开始。`translateY(0 → −22px)`，2.4s / 3s / 3.8s，中间反向。悬停在单独的 `.lift`：−16px、scale 1.055、420ms `cubic-bezier(.22, 1.12, .36, 1)`。
- **减少动态效果**：跳过建造，直达填色；不漂浮。

## 可学 / 不学 / 启示

- **可学**：体积用六个面。字贴在正面。先线框后填色。错开出现。漂浮等站稳。悬停不和循环抢同一层 transform。
- **收窄**：标本只收立方体。六个面。01、02、03 依次到场。
- **启示**：标签如果做在立方体旁边，体积立刻变成装饰。字在面上，第三边才成立。
