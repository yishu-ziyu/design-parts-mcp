# 手绘抖动图标组

来源：https://x.com/nicoletang0717/status/2093896036951691408（@nicoletang0717）
复刻日期：2026-11-05

## 机制

- 全页共用一个 SVG 滤镜：feTurbulence 产生噪声，feDisplacementMap 把线条错开。
- 定时换噪声种子，线条和文字一起抖；速度五档 3/5/8/11/15 次每秒，幅度五档 1/1.9/3/4.2/5.6。
- 每一笔是一条 path，pathLength=1，用 dash 偏移按笔顺描出来，卡片之间错开 35ms。
- 点卡片导出 SVG，把换种子写成 SMIL 动画，文件自己会抖。
- 把图标拖进标题，落下后弹七色色板。
- 60 个图标全部自绘（24 格），字体是 Schoolbell（Apache 2.0）。

## 可学

一个滤镜统一全部手绘感，比给每个图标做动画省太多；导出时把动画写进文件。

## 不学

原作者的 Logo 和图标路径没有收；抖动范围太大时小字会糊。

## 和原版的差距

版式、字体、尺寸和节奏在并排图里几乎重合；图标是自绘，形状只是相近，个别（如相机、笔记本）细节不同，线条抖动的形状也不是原版路径。说明文字用 IBM Plex Mono，是肉眼选的，和原版字形略有差异。原版的录屏光标圆点没有收。原作者说要开源，但没有找到源码，滤镜参数是按画面估的。
