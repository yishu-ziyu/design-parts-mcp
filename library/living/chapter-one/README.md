# 图当词（Chapter One 首页）

来源：https://www.chapterone.com/（2026-11-05 用 ego 打开核对）。原 `index.html` 是早先的笔记页，`replica.html` 是首页复刻。

## 机制（常量读自线上打包代码，只读取未改动）

- 片头：逐字打两屏，每字 .035s，可跳过。
- 首屏：书沿斜线走，50px/s，每本 y 由 x 算出；悬停停下，两边让开 120px。
- 宣言：钉住 2800px，每词 .25 到 1，时长 .5、错开 .08，图片当词排。
- 投资：钉住 8400px，11 本书，每本 2 个时间单位；名单同步上移。
- 翻书转场：飞到中间、翻封面、翻三页、放大撑满、淡入文章，实测 3.55s。
- 关于：钉住 3400px 加长页超出高度，翻书后变成长页继续滚动。
- 媒体：三卡轮播，底部横条长度 120、40、6。

## 可学

图片按词的高度排进句子，读者不用停下来看图。同一个翻书动作用了两次（滚动驱动、点击驱动），把“书”这个比喻贯穿全站。

## 不学

- 长时间钉住会让滚动变慢，全页高近 24000px。
- 宣言段读者只能跟着滚动速度读。

## 和原版的出入

- 字体：原站 Edict Display 不内嵌，这里用 EB Garamond，按原站逐项量了字宽和行高再调字距，字形仍不同。
- 品牌名换成 Chapter Two，Logo 换成圆点，邮箱换成 example.com。封面、报纸等截图里仍能看到原站标识。被投公司名和人物信息保留。
- 四个独立子页面（Investments、Library、Reason to Exist、Our Team）没做，顶栏链接改成滚到对应段落；点肖像直接打开文章。
- GSAP 换成自写的小时间线引擎，滚动滞后用指数平滑近似 scrub:.4。

## 素材

`source-assets/` 由 ego 在白底和黑底各截一次图后算出透明通道，超过 1400px 的缩小。书层、钞票、报纸、电脑五类沿用 2026-08-17 建笔记时取的原图。

**取材说明：**字体和原站 JS 曾用 page.fetch 读取；复刻页没有保存原站 JS 文件。图片在白底和黑底各截一次算出透明。
