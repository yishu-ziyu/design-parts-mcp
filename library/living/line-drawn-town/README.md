# 一笔画出来的街

来源：onoshin @o_shinworks https://x.com/o_shinworks/status/2102406624099041559
原站：https://syncraft.dev（作者主页写的地址）
复刻日期：2026-11-05

## 机制
- 主线连续走，门窗在主线继续走时补上。复刻页不重新画线，而是给长图的每个像素记一个出现时间，再按时间显示。
- 取时间的方法：把原站放进一个可单步的时钟，每步截一张只有墨线的图，某像素第一次变黑的那一步就是它的出现时间。
- 笔画完后镜头继续匀速前进，最后约 500 单位的墨线是在画面外画好的。这一段的镜头和角色轨迹是按最后速度外推的，没有原站记录。
- 原站的动画速度和帧率有关：每帧走固定距离。按 45 步/秒播放时，镜头速度和视频一致。

## 可学
一段难重写的动画，可以拆成“成品图 + 每像素时间”，用一个数字控制进度，暂停和重播都很简单。

## 不学
不把线稿、角色和产品图用到公开页面。
