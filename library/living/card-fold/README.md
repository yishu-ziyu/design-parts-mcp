# 名片折叠（card-fold）

来源：<https://x.com/iamncdai/status/2101608687702053067>（@iamncdai，2026-09-20）。帖子只有视频，没有外链。复刻依据是逐帧读视频，帧里的 p 和 θ 读数直接可见。

## 机制
- 进度只有一个数 p，θ = p × 180°，页面拖动和滑杆都写它。视频里 p 0.52 对应 94°，是线性映射。
- 卡片不是整张 3D 翻转。真正做 3D 旋转的只有一块黑片，它只露出上下楔形；内容层是平面的，按黑片投影后的宽度裁切，所以文字不变形。
- 透视原点在舞台中心，不在折痕上。这样 θ 过 90° 后黑片远边才会落到折痕左边约 28px，和视频一致。
- 整张卡同时横移重新居中：合上时右半页左移半个页宽，打开时折痕就是中心。
- 暗度按角度查表，表里的值从视频灰度读来。翻开时内页远边最暗，近折痕处和右半页相同。
- 远边有渐进模糊：一层 backdrop-filter 配横向遮罩。内页文字的模糊随角度减小。
- 拖动超过 3px 算拖动，松手按 0.5 吸附；没移动算点击，切换开合，约 600ms。

## 可学
只旋转一块纯色片、内容走平面裁切，开销小，文字也不糊。查表取暗度比用公式更容易对上视频。

## 不学
- 头像是原帖视频里裁出来的（`source-assets/avatar.png`，只留本机），不要发布，公开使用要换。字标是作者的，已换成自绘的占位字标。
- 松手吸附和点击切换是从视频行为推断的，弹簧参数是估计值。
