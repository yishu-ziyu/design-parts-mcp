# 转录稿阅读器

含原作素材，只留本机。

来源：@Huanusa，https://x.com/Huanusa/status/2048195370476294500 ，2026-04-26。视频 3 分 27 秒，1378×1080。  
复刻日期：2026-11-05；同日第二轮用帖子播放器的全屏按钮暂停取帧后重做。

## 机制（来自暂停帧）

- 当前段的时间戳处有一条红线，随进度在段内从上往下走；当前小句铺绿底。
- 正文上指针附近约 40 个字符出现下划线。
- 指针在时间戳列时是上下箭头，当前行跟着指针走（帧里只拍到一次）。
- 荧光笔打开时光标变十字，划过的字变黄，并在摘录里写成 ==文字==。
- 视频和开关条置顶，正文从下面穿过并淡出；关掉置顶后开关条单独贴顶。
- 目录：红色短线跟播放，黑字跟屏幕正在看的章节。
- 手动滚走后底部出现 Current position 胶囊。
- 亮色配色是 Flexoki，暗色是 Rosé Pine，名字在设置菜单里能读到；暗色配 Newsreader 衬线。

## 可学

- 把进度条换成时间戳列，找内容时不用来回拖时间轴。
- 红线同时表示「在哪一段」和「段内走到哪」。

## 不学

- 三栏加视频信息密度很高，小窗口会挤。

## 替换和推断

- 视频帧是原帖暂停帧，4 帧/秒循环约 6 秒；右上角频道标志已模糊。网址、标签名、面板按钮换成占位。
- 正文和摘录是照暂停帧逐字录入的，保留原转录稿的错字。帧里没露出来的段落没有录入，所以时间戳有跳跃，目录里部分章节点了不跳。
- 这些是看帧推断、未经原版核实的：开关条和右上工具何时出现、目录何时变淡、倍速卡怎么呼出（这里用 s 键）、面板动画的时长和缓动、拖动的细节。
- 查询参数（doc、panel、dark、i、f、top、frame 等）只用来还原对照画面。
