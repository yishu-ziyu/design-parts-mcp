# cross-stitch：矢量图实时转十字绣图样

来源：[@LottieCoxon 2026-10-15](https://x.com/LottieCoxon/status/2110764430229225942)，工具名 cross purposes。原帖是 44 秒录屏，没有公开链接，页面和参数都从录屏读取。

打开：`index.html`。`?yaw=&pitch=&t=` 固定视角和烟雾时刻，`?panel=lettering&words=` 打开字母面板。

## 机制

1. 自绘的三维工厂（锯齿屋顶轮廓沿 z 拉伸）按视角投影，画到离屏画布，线、填充、白面用三种纯色区分。
2. 每个针格是 4×4 采样。线条覆盖不低于阈值（默认 15%）就算线色，否则取多数色；白面默认不绣。
3. 每格画两条对角线，形成一个 X。线材颜色和灰色按 6:4 混合，贴近录屏里被布面压暗的观感。
4. 拖动改视角，烟雾是三个环按 7.5 秒循环上升，上半段换浅色线。每次变化都重算图样，约 26 帧每秒。
5. 文字用 5×7 点阵字母绣在图样下方，每行 11 针高，所以两行文字让网格从 115 行变成 141 行。
6. 右栏数字都来自当前图样：针数按实际格子数，每束约 1600 针（从录屏 1549 针 1 束、1827 针 2 束估计），尺寸按 14 目换算。

## 可学

- 「线条优先」的采样规则。细线在低分辨率下不会断，这是线稿转针法的关键。
- 把输入控件和输出清单放在同一栏，改一个滑块就能看到用线量和成品尺寸变化。
- 产品字标也用同一种针法绣出来，工具的主题从第一眼就成立。

## 不学

- 工厂插画来自原作者，这里是自绘替代，不要当作原图使用。
- Threads、Fabric 两个面板在录屏里没有展开，这里的内容是推测；撤销、剪刀和导出按钮没有功能。
