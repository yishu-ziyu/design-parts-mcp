# caustics — 一个片元着色器画出「从水底往上看」：日光光晕、浑浊水体、水面亮斑、光柱和悬浮物

来源：https://x.com/Yuki_1t0/status/2110706000726810932 （Yuki Ito @Yuki_1t0，2026-10-15，视频 54 s）。推文原文是日文，大意是做了两年 X、把用 3DCG 做的东西剪成一条合集，作者在其他行业上班、周末自学 CG，标签 #Houdini；个人简介写「週末CGアーティスト｜Houdini｜Nuke」。这些是事实。推文里没有链接、没有工程文件、没有讲具体怎么做。合集里是十几个写实流体镜头：泡沫、气泡团、礁石边的浪、水下仰拍、乳白色流体蔓延等，都是离线渲染的成片（推断是 Houdini 模拟 + Nuke 合成，依据只有简介和标签），网页里没法 1:1 重做那些模拟。这里挑的是 16 s 那个水下仰拍镜头：它的视觉主要来自光照和体积，而不是逐粒子的模拟，所以能用一个着色器复刻构图、色调和动势。

原片取样方式：在 X 页面里把视频逐 2 s 画进 canvas 拼成缩略图表，16 s 那一格只有 231×97 px（X 当时给的流是 480×270），颜色和亮度分布是把这一格缩成 8×4 读出来的。分辨率低，细节纹理只能看个大概。

## 怎么做的

- 一个全屏三角形 + 一个片元着色器，没有贴图、没有库。
- 底色：深色 → 中间色的竖向渐变，底部再压暗。
- 光晕：以太阳为圆心，横向拉宽（距离乘 0.75）的两个指数衰减，乘上低频 fbm 让它发虚、不圆；中心混 45% 近白。
- 浑浊：两层 fbm 乘到整幅画面上——低频的大团让光晕边缘不规则，横向拉长的细纹给水体一点流动感。
- 水面：画面上部 30% 用迭代三角函数的焦散图案（4 次迭代，取 8 次方只留细亮线），越靠近太阳越亮；离太阳远的水面压暗，对应从水下看出去「斯涅尔窗」以外的水面反射的是暗的水底。
- 光柱：以太阳为原点取角度，在「角度 × 7」上采 fbm 再随时间平移，只在太阳下方出现，按距离衰减；强度压得很低，因为原片里光柱几乎看不出来。
- 悬浮物：三层网格哈希点，近大远小、速度不同，亮度乘上该处光照。
- 太阳会向指针方向偏一点（最多 6% 画幅），缓动跟随。

## 关键判断

1. **光太硬 → 改成发虚的大光晕**。第一版太阳是一个过曝的白盘加一圈放射状光柱，像游戏里的镜头光晕。原片的光是散在浑浊水里的一大团，几乎没有明确的光柱。改法：光晕横向拉宽、乘 fbm，光柱强度 0.55 → 0.2。验证：8×4 色块每通道平均差从第一版的 26.9 降到 11.5，对比图见 `cmp/`。
2. **画幅不是 16:9**。缩略图表里这一格上下有黑边，量出来内容区约 2.38:1，所以画框用 2.39:1，页面底色接近黑，跟片子放映的样子一致。
3. **悬浮物少而暗**。第一版悬浮点 45% 的格子都有，满屏散景。原片里的悬浮物只在亮处隐约可见，所以只留 18% 的格子，亮度乘光照，背光处几乎看不见。

## 和原片的差距

- 原片的纹理是真实体积渲染：泡沫、气泡、湍流的细节很多，左上角的水面有成片的亮斑和破碎感。这里只有两层 fbm，近看是平滑的雾。
- 原片取样只有 231×97 px，细节对不上，只对上了构图、色调和亮度分布。
- 中心那团亮光原片偏白偏灰，这里仍略偏青（中心格 G 通道 248 对 224）。
- 最亮区域的重心比原片高、偏左（离顶 14% 对 23%）：光晕和水面亮斑叠在一起把亮度往上推了。试过把太阳上移到重心位置，色块差反而变大（14.3），所以没改。
- 原片镜头本身在缓慢移动，这里机位不动，只有光和颗粒在动。
- 合集里其他镜头（泡沫、浪、乳白流体）没有复刻。

## API 和 CONFIG

```js
const shot = createCaustics(container, {
  sun: [0.53, 0.66],          // 太阳位置，uv，y 向上
  colors: { deep: [16,56,49], mid: [74,149,138], light: [202,228,225] },
  rays: 0.2, surface: 0.8, motes: 0.5, murk: 0.55,
  speed: 1.0,
  followPointer: 0.06,        // 0 关掉指针跟随
});
shot.setSun(x, y); shot.setLayer('rays' | 'surface' | 'motes', on);
shot.pause(); shot.play(); shot.renderAt(t); shot.destroy();
```

- 片名条文案在 `CONFIG.caption`，是自己写的，没有用原作的片名卡。
- `prefers-reduced-motion`：只画一帧，不跟随指针。
- 滚出视口暂停（IntersectionObserver）；尺寸变化用 ResizeObserver；设备像素比上限 1.5。
- 没有 WebGL 时退回一张同色的 CSS 径向渐变。
- file:// 直开，零网络请求，只用系统字体。
- 验证：Playwright（swiftshader）拦掉所有非 `file:` 请求，1100×700 和 400×800 两种视口都零请求、零控制台错误、无横向滚动，可拆里 6 个锚点都在真实元素上。

## 可拆

- `#shot` 整个着色器：底色、光晕、浑浊、各层的叠法和颜色。
- `#rays` 角度噪声光柱。
- `#surface` 水面焦散 + 斯涅尔窗外压暗。
- `#motes` 三层哈希悬浮物，亮度跟光照走。
- `#layers` 图层开关（`setLayer`）。
- `#caption` 宽银幕片名条。
