#shot
2.39:1 宽银幕画框（原片 16:9 视频里上下带黑边），，一个全屏片元着色器画整幅画面，没有任何贴图。几层叠在一起：竖向渐变底色（深 #10382F → 中 #4A958A）、横向拉宽 1/0.75 的太阳光晕（两个指数衰减，亮色 #CAE4E1，中心再混 45% 近白）、两层 fbm 浑浊（低频大团 + 横向拉长的细纹，乘到整幅画面上）、水面、光柱、悬浮物。颜色都是从原片 16 s 那一帧缩成 8×4 读出来的。
#rays
光柱：以太阳为原点取角度 atan(d.x, -d.y)，在「角度 × 7、时间 × 0.12」上采 fbm，2.4 次方压暗缝隙，再乘浑浊度，再乘距离衰减 exp(-1.5r) 和「只在太阳下方」的遮罩。角度噪声随时间平移，光柱就会慢慢左右摇。
#surface
水面：画面上 35% 是从下往上看到的水面。用迭代三角函数的焦散图案（4 次迭代，结果取 8 次方，只留细亮线），纵向压缩 2.4 倍做透视，越靠近太阳越亮，越往下越淡出。
#motes
悬浮物：三层网格哈希，只有 18% 的格子有点，近层大而虚、远层小而实，各自以不同速度上漂并横向摆动。点的亮度乘上该处的光照，背光处的点几乎看不见，和原片一样。
#layers
三个图层开关直接改着色器 uniform（强度置 0 或恢复 CONFIG 值），用来单独看每一层贡献了什么。工厂返回的 setLayer(name, on) 就是它。
#caption
片名条：小号大写、字距 0.18em、灰绿色，跟画框同宽。文案全在 CONFIG.caption 里，是自己写的，不是原作的片名卡。
