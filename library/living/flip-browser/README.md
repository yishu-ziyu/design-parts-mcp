# flip-browser — 整页都是生成图的浏览器

含原作素材，只留本机。

来源：@Jingyuan_521 介绍 Flipbook（@zan2434 等人做的无限视觉浏览器）的视频，https://x.com/Jingyuan_521/status/2047951936683425812 ，2026-04-25。复刻依据是视频里 30 到 100 秒的产品画面，复刻于 2026-11-05。没有打开 Flipbook 本身，帖子也没有外链。这里没有任何生成能力，只是把视频里出现的 7 张图串起来。

## 机制

- 窗口里只有一条地址栏和一张图。页面没有 DOM 内容，所有文字都在图里。
- 地址栏同时做三件事：走过的页是面包屑（当前页加粗），请求时显示 `Fetching information about…`，空闲时是输入框，提示 `Continue this session`。
- 点图上任意位置就是发请求：点击处出现圆环，旁边弹一张小卡，用下一页的缩略图占位，告诉你可以先看草稿。
- 图到了以后以点击处为中心放大、模糊，新图从稍小处清晰起来。视频里这段是真实视频流，这里用 0.65 秒的缩放和模糊近似。
- 空状态只有一句话和一个上传按钮。

## 可学

- 把「点哪儿问哪儿」做成唯一的交互，界面可以几乎为零。
- 等待时给缩略图和一条退路，而不是只有进度。
- 面包屑让无限生成的内容仍然能回头。

## 不学

- 图里的字不能选中、不能被读屏软件读到，也不能搜索。
- 没有可点的提示，第一次用不知道哪里能点，只有底部一行小字。

## 素材

`source-assets/` 全部来自视频暂停帧：同一页多帧取中值去掉鼠标，字幕用透明度反算还原，还原不了的部分用周围内容修补。讲解人的圆形头像用窗口另一侧的花纹镜像盖掉。Chiang Mai 和 Khao Soy 底部的缎带文字是重新写上去的，用的是 Times New Roman。

## 和原版的差距

Paris 路线的 5 张图底部中间有肉眼可见的修补痕迹，`Tickets Confirmed` 最明显。视频里这条路线是放大后录的，这里缩回到和 Chiang Mai 相同的窗口大小。点图不看点击位置，都走向同一个下一页。
