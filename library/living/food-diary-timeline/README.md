# 饮食手账

来源：@faemuggie https://x.com/faemuggie/status/2112162351906718012
复刻日期：2026-11-05

## 机制
- 相机按钮拉起抽屉，弹簧曲线 cubic-bezier(.2,1.05,.3,1)，.5 秒；顶部保留可见的主页并压暗。
- 点菜或点对勾取消，按钮数字实时变。
- Keep：每份抠图错峰 120ms 飞向时间线，提示条从 Adding 1 of 4 走到 4 saves added。
- 翻滚：圆形刚体，重力 .45，弹性 .42，圆与圆互相推开；能拖能甩。
- 短按盘子弹出详情抽屉，星级和标签可点。

## 可学
抽屉里按钮的数字跟着选择变；录入后的奖励动作（飞入、翻滚）。

## 不学
`source-assets/` 里的餐点照片和绘本背景是原产品和原帖作者的，只在本机参考，不要发布；公开使用要换成自己的图。

## 和原版的差距
见 `原料/x-收藏/results/2112162351906718012.json`。

## 素材说明
餐点来自原帖配图（列表）和视频暂停帧（抽屉、贴纸），用 cv2 GrabCut 抠图；场景背景由 25 帧视频取中位数去掉盘子，再修补被界面盖住的顶部。Logo 用代码重绘，品牌名换成虚构词。字体在 fonts/（nunito.woff2, outfit.woff2），均为开源字体，不是原版字体。

演示入口写在页面脚本末尾的 URL 参数里。
