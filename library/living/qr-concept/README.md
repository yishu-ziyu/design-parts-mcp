# 取餐二维码

来源：@SolutionB2u https://x.com/SolutionB2u/status/2109424625742713341
复刻日期：2026-11-05

## 机制
- 下拉抽屉把进度 p 从 0 拉到 0.2，松手走完；全部画面由 p 算出，所以能拖也能倒放。
- p 0.14 到 0.5：立面绕 X 轴后仰 24 度，路面淡掉。
- p 0.46 到 0.56：世界缩小，同时平移到二维码中心。
- p 0.52 到 0.9：二维码从 16 倍缩到 1 倍，模块用 crispEdges 保持硬边。
- p 0.84 到 1：取餐抽屉带轻微回弹升起。
- 标题切换：两层标题叠放，opacity 和 blur(6px) 交叉 0.4 秒。

## 可学
把两个界面当成同一个镜头里的两个距离；用一个进度数字驱动所有画面。

## 不学
不学自绘品牌店面的做法：这种转场依赖插画，没有插画资源就别硬上。

## 和原版的差距
静态版式（抽屉、取餐页、字号、配色）几乎重合；店面是自绘，比原版插画简单（没有室内细节和地砖纹理），店名和“Apple Wallet”已换掉。转场结构对了，但缩放中段原版是从屋顶俯视的 3D 建筑，我这里是平面立面缩小并落进二维码中心。二维码是占位图形，不能扫。

## 素材说明
图片、封面、Logo 全部用代码重绘，品牌名换成虚构词。字体在 fonts/（inter-latin-var.woff2），均为开源字体，不是原版字体。

演示入口写在页面脚本末尾的 URL 参数里。
