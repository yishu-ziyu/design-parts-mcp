# 快碰上的地方长出词（Causa sui / PIXELASSAULT）

来源：https://x.com/__causasui/status/2042632462548050088，作者 @__causasui，2026-04-10。2026-11-05 用 ego-browser 打开确认视频还在，时长 5.05 秒、700×700，和本地 `assets/source.mp4` 相同。

## 机制
- 121 帧、24fps，在四种画面之间硬切：照片帧、字符帧、斜线色带帧、纯黑帧。切点逐帧测得，写在 `KIND`。
- 字符帧：42px 网格，白色等宽字。手部覆盖的格子放随机字符，每列从手的上沿往下越来越稀（0.92、0.38、0.14、0.06，这组数是对着原片调的）。
- 色带帧：3px 方块取手部亮度分三档：>=88 紫，64 到 88 红，52 到 64 橙，更暗留黑。再用周期 3px 的斜线镂空。阈值由第 48 帧和第 56 帧的对应关系量出。两只手在色带帧里的左右位移是手动设的（第 49 到 55 帧各 75px，之后不移或少移）。
- 词块层：红色词、白色小数、白色细曲线、贴图方块，集中在两只手快碰上的地方。

## 实现分两层
- `#stage`：照片帧直接逐帧播放原片（含原片已烧进画面的词块），来自本地 `assets/source.mp4` 的抽帧，没有再次下载；字符帧和色带帧是页面用 canvas 现算的。
- `#chips`：单独一块，用干净的手部画面加 DOM 和 SVG 现做词块层，位置从第 18 帧读出。这一层才是可以拿走改的部分。

## 可学
用硬切和极短的停留制造紧张感；把抽象数据贴在身体快要接触的位置。

## 不学
这些词和数字没有真实含义，用在产品界面上会误导。
