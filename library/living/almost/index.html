快碰上的地方长出词。

x.com/i/status/2042632462548050088。Causa sui / PIXELASSAULT。不是网站，是一段五秒的图。

两只手还没碰上。词卡先结在指头上，细白线把它们拴住。过一会儿，同一姿势被处理成紫和橙的网点。作者自己的话：a processed world，a reimagined reality。

HUG 上那件也叫 Traces/Recollect，画面是另一个人。这页只复刻推上这一段。手的底板从原片里去掉字。网点层用原片里那一帧，不另做 Bayer，也不用蜡笔红。

可拆

  • 词卡图：照片上叠一层会动的词和线。
  • 差一点碰上：构图本身。空隙比碰上更要紧。
  • 再处理：同一姿势换成紫橙网点。游戏标题雾走 halftone。

下次怎么用

  1. 要一张图当界面的骨架：先放身体或手，词卡结在关节上，不要另开一张信息图。
  2. 卡片要小。玻璃一块、橙一块就够。线要细，不要箭头。
  3. 词用原片上的。不要改成产品功能名。
  4. 处理层是另一眼，不是滤镜滑杆。要能再结、再处理。
