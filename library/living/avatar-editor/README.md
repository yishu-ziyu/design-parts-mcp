# 动态形象编辑器（复刻）

来源：https://x.com/yijie4188y/status/2091524948510785787（@yijie4188y，2026-08-23），页面 https://oneworks.cloud/avatar/ ，2026-11-05 查看。

## 机制
- 中心放大轮播：七个档位靠 `data-position` 切换，宽高、圆角、透明度和位置都走 .52s cubic-bezier(.16,1,.3,1)。
- 新居中的卡片再播一次 settle：scale .965 → 1.008 → 1。
- 缩略图条：每项按序号乘 64px 平移，选中项放大到 1.08 并带主色描边。
- 十列 dense 网格：五种占格尺寸，按固定序列排成错落的墙面。
- 编辑器：左侧分组资源栏，右侧画面，右下角三环显示朝向。

## 可学
轮播的所有档位只用 CSS 变量和一个属性切换，拖动时只改一个 --drag。

## 不学
形象是逐帧截图，不是原站的 3D 渲染；要做真实形象渲染请看原项目。

## 和原版的差距
首屏、编辑器和深色主题与原站并排几乎重合。差距：形象是原站截图不是实时渲染，只有小狗能跟指针和拖动，而且是 5×5 张截图跳变；其他形象是静态图；编辑器里狗狗类型、面部预设和动画、形状标签只改选中状态，不改画面；三环控件是重画的简化版；深色模式的切换图标没有换成太阳。原帖配图是深色主题加壁纸的宣传图，并排核对用的是公开页面。
