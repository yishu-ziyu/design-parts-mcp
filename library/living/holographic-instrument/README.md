# Holographic Instrument

含原作素材说明：这条没有裁原帖图片，全部用代码画。默认画面的线条位置是照线上截图描的。

来源：Dash（@creativedash）https://x.com/creativedash/status/2090833170359079158 ，线上 holo.ui8.dev（2026-11-05 查看，只看画面、面板文字和计算样式，没有取它的代码）。

## 机制
- 暗底上一组线稿仪表：圆环、刻度、亮条、等高线、TRK 读数、数据小字、定位网格。
- 后期：景深（三层画布分别模糊）、泛光（高对比副本模糊后叠加）、色差（着色器里红蓝通道错位）、颗粒、暗角。
- 面板：整行就是滑条，行高 32，圆角 5，底色 #252525，标签 12px #989898。这些数值量自线上页面。
- 拖动画面改方位和俯仰；相机按钮存 PNG；红点只切换录制状态，不会真的录。

## 和原版的区别
- 原版是实时 3D 生成；这里种子 368 是二维描线，拖动只是整体旋转和压扁，没有真实视差。
- 换种子是我写的简化随机生成，和原版算法无关。
- 面板只接了一部分参数，没有 Tracker、Intro、Pan 等分组。
- 等高线形状和原版不一样，只保持了大小、线数和方向。
- “Built with Forge” 换成占位。

## 可学
- 一层色差和颗粒，就能把普通线稿变成有胶片感的仪表。
- 面板整行可拖，比单独的滑块省地方。

## 不学
- 手描坐标换不了构图；真要用，得写生成算法。
