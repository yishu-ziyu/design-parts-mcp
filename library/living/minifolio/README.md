# minifolio 三步流程复刻

来源：只有一张会话截图 `assets/source.png`，已复制到 `原料/x-收藏/originals/note-minifolio/`。minifolio.com 跳转域名售卖页，公开网站没有可对照的页面。2026-11-05 复刻到 `replica.html`（旧的 `index.html` 保留未动）。

## 机制
- 三列等高：上传卡、橙色文件夹、存储卡；中间一列的纸片高出卡片顶边，打破三列。
- 标题 Instrument Serif，界面 Plus Jakarta Sans，容量 IBM Plex Mono。

## 可学
- 三张卡只有中间用满色，视线直接落在中间。
- 说明写在卡外，卡内只放界面。

## 不学
- 字号普遍偏小，原图 8–10px 的字放到正式产品会看不清。

## 差距
- 原件是一张约 1x 的静态图：字体、颜色都是从图上读的，不是从源码读的，正文字体 Plus Jakarta Sans 是按字形推断的。
- 动效原图看不到：纸片悬停、拖入变色、重试过程都是这一版补的。
- 品牌名换成 SomeFolio，Logo 重画。原图里的鼠标指针没有画。
