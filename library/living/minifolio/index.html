说明书是三扇窗

说明书是三扇窗。

截图里的 MiniFolio。公开网上搜不到活站，按原图复刻。

三步不是三个图标。左边是投放区，中间是一叠文件夹，右边是容量条。产品自己的窗就是说明。

左边同时放失败和成功。designSystem.pdf 3MB 失败，components.pdf 1.2MB 已传，上限 5MB。点投放区或把文件拖进去，会在这台电脑上检查大小，不上网。

可拆

  • 投放区：虚线框，点选或拖入。上限 5MB。文件留在这台电脑。
  • 文件行：失败和成功同时在。失败有红字和 Try Again。
  • 叠卡：Images 248。放上去后面的卡让开。点一下换一叠。
  • 容量条：97 / 128 GB，四段色，进场自己长出来。

下次怎么用

  1. 讲三步时，把产品里正在用的窗直接摆上去。不要另画一套图解。
  2. 失败和成功要同时在。只给成功态，投放区是假的。
  3. 中间那叠要能让开、能换。只是一张静图不算。
  4. 容量条子要会长。数字用原图的，不要另编一套。
  5. 橙是产品色。要能再走一遍。
