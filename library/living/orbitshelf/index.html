#hero
底色和版式：页面 #F8F8F6，上面叠两层白色径向光（中心 700×420 纯白到透明、顶上 1400×900 的 90% 白），中间的字就像放在一块亮台面上。标题 Newsreader 360 字重、行高 0.98、字距 -0.035em；副标题 Geist 20/29、#5F5E59；按钮全圆角 48px 高、#141413、两层阴影。品牌字 0.85 s 先出，标题、副标题、按钮 1 s 后一起上浮 10px 淡入。
#ring
椭圆转盘：14 件物品等分在一个 600×322 的椭圆上（1650 宽实测），整圈约 83 s 转一周。每件用深度 d = cos θ 决定一切：缩放 0.85 + 0.23d、不透明度 0.75 + 0.25d、层级 round(50 + 50d)、模糊 max(0, 2.5(−d − 0.3)) px，旋转角 = 横坐标 / 100 度。没有 3D 变换，全是 2D 的 translate + scale。
#haze
边缘雾化：一整层 backdrop-filter: blur(14px)，用径向遮罩只在外圈生效（64% 透明、80% 半遮、100% 全遮）。转到远处、靠边的物品自然变糊，中间的字和前排物品保持清楚。
#objects
抠图物品：每件放在 168px 的盒子里，按 --sw / --sh 拉成自己的长宽比，内容 contain，统一一层 drop-shadow(0 18px 24px rgba(30,28,22,.1))。这里的物品是代码画的 SVG（球、蛋、骰子、罐子、碗、石头、书、柠檬），换成真实抠图 PNG / WebP 只改 CONFIG。
