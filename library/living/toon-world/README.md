# Toon World

含原作素材，只留本机。

来源：Evan（@DrCapsoul）https://x.com/DrCapsoul/status/2093028670034292764 ，线上演示 ref-world-demo.vercel.app（2026-11-05 查看）。

## 机制
- 世界是灰地上的墨黑生物，地面 #e4e4e4（视频里）/ #dedede（线上）。
- 拖动平移，滚轮缩放；生物走走停停，每次在出生点附近走 14–44 像素，速度 11 像素/秒，走动时带 2 像素起伏和 ±1.3° 摇摆。
- 按脚底 y 排前后，物体在世界坐标里排序。
- 鼠标停在生物上出现小写名字，点一下跳起 14 像素并冒表情气泡（2.4 秒）。
- 底部把手拉起整屏画板，过渡 .912s cubic-bezier(.17,.72,.24,1)；画完闭合形状填墨、开眼，掉进世界中央。
- 角上是手绘边框的二维码和小地图；小地图里有生物点和当前视野方框。

## 和原版的区别
- 原版是 three.js 三维卡通渲染，这里用画面截图做二维贴图，转不了视角。
- 二维码是占位图案，不能扫。

## 可学
- 全灰世界里只留墨黑一个重色，生物一眼跳出来。
- 用户画的任意形状都能成为角色，门槛低。

## 不学
- 贴图做法只适合固定视角；要旋转视角得回到真三维。
