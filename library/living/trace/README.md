# trace — AI 工具调用轨迹（步骤流 + 结果卡 + 收成摘要）

活笔记。复刻 Dimitar（@dimitroweb）2026-10-20 发的 "Iterating on AI traces" 视频：一个 agent 依次查 Slack、Granola、Gmail、GitHub、Linear，每一步在界面上长出一行、展开一张结果卡，跑完后写出答案，整串步骤收成一行摘要。

打开方式：`file://` 直开 `index.html`，无网络、无构建、无依赖。
测试参数：`?t=4.3` 定格在某一秒（关掉过渡，用来和原视频同一时刻逐帧对照）；`?demo=end` 直接到终态。

## 来源

- 原帖：https://x.com/dimitroweb/status/2112281659093504201 （视频 11.8s，1440×1080）
- 作者没有公开代码。下面的机制全部来自逐帧观察：在浏览器里把视频 seek 到 0.1–0.5s 间隔的时刻，截出 30 帧对照。看到的是事实，时长和缓动曲线是按帧间变化估出来的。

## 原版逐帧时间轴

| 时刻 | 看到什么 |
|---|---|
| 0.0–0.6 | 只有一行 "Working on it…"，橙色四点转圈，chevron 朝右，整行在扫光 |
| 0.8 | 顶行变成第一步文字，下面挂出同样文字的子步骤，子步骤在扫光 |
| 1.2 | Slack 卡片从上往下撑开，三条消息 + "+1 more" |
| 2.4 | 第二步 Granola 出现，顶行跟着换成第二步文字；之后卡片展开 |
| 4.2→4.3 | 第三步 Gmail 卡片展开的同时，Slack 卡片收起：始终只开最近两张 |
| 5.2 / 6.0 / 7.0 | GitHub、Linear 依次进来，同样的开两张、收最早一张 |
| 8.0 | 五步全部收起成五行，答案开始在下方按词流出 |
| 9.3 | 答案写到 "Mail"，顶行图标变成书写态 |
| 9.6–9.8 | 顶行从模糊淡入成 "Ran 2 searches and read 3 sources" + 三个来源图标叠片，子步骤整体收走 |
| 10–11.8 | 静止：摘要行 + 答案 + 复制、上下翻的图标 |

## 我判断错过、后来改掉的

- 第一版只看了推文里的一张静帧，把扫光做成「亮带扫过灰字」。原版是**变淡的带扫过正常颜色的字**：静帧里 "for un|read" 那段字是淡的，前后都是正常色；Gmail 那一步里淡掉的是 chip 本身。所以本页用 `mask-image` 而不是 `background-clip:text`——mask 会把 chip 里的图标和名字一起扫淡。
- 第一版把顶行当成固定的分组标题。看了视频才知道它是实时状态：开始、每一步、结束各换一次文字。
- 第一版所有卡片都保持展开。原版只开最近两张，否则五张卡片会把答案推出屏幕。

## 本页对应实现

| 原版行为 | 本页 |
|---|---|
| 扫光 | `.run>.hd .lbl` 上的 mask，260% 宽、28% 不透明的淡带，1.5s 线性循环，从右往左 |
| 顶行实时状态 | `setRoot(icon, html)`；换文字时 220ms 去模糊淡入，最后的摘要用 500ms、5px 模糊淡入 |
| 开两张收一张 | `KEEP_OPEN = 2`：第 i 张展开的同一回调里收起第 i−2 张 |
| 卡片撑开 | `grid-template-rows: 0fr → 1fr`，340ms `cubic-bezier(.2,.8,.2,1)`；内容不做逐行动画，原版也是整张从上往下露出 |
| 子步骤进场 | 透明度 0→1 + 上移 4px，260ms |
| 答案流出 | 按词切成 `.tok`，chip / code / 链接整体算一个词；1.4s 内均匀出完 |
| 节奏 | 首步 0.7s，每步间隔 1.45s，开卡延迟 0.4s，8.05s 全收，9.7s 收成摘要——与原视频同一刻度，可以用 `?t=` 对帧 |

## 与原版的取舍

- 品牌标（Slack、Gmail、Granola、GitHub、Linear）是自绘的简化示意，没有用官方矢量，颜色接近即可。真用在产品里换成官方 SVG。
- 字体用系统 UI 字体栈（Mac 上是 SF Pro）。原版看起来也是系统字或 Inter，帧的分辨率不足以分辨。
- 原版顶行结束态的图标叠片顺序是 Slack、Granola、Gmail，本页照抄；摘要计数写死 "2 searches / 3 sources"，没从步骤里算。

## 可学

- 过程信息分两层：顶行永远告诉你「现在在干嘛」，下面的列表是「干过什么」。用户不展开也知道进度。
- 展开窗口固定为两张，是在「看得到证据」和「答案不被推走」之间的折中；收和开放在同一帧，页面总高度变化小，眼睛不用追。
- 扫光表示「这一行还在跑」，不需要再加 spinner；跑完的那一刻扫光停，等于一个无声的完成信号。
- 结束时把整串过程收成一句带计数的话，过程没有丢，只是退到可点开的位置。

## 不学

- 原版 "Working on it…" 的四点转圈和后面的橙色放大镜在小尺寸下区分度很低，自己的产品里用一个图标就够。

## 可拆

- `.run .lbl` 扫光（mask 淡带）
- `#root .hd` 实时状态行（换文字去模糊、结束摘要 + 图标叠片）
- `#kids` 竖线缩进
- `keepOpen = 2` 展开窗口
- `.card` 结果卡（未读点 / 字母头像 / PR 与工单状态图标 / +N more）
- `.chip` 来源标签（行内与正文两种尺寸）
- `#answer` 按词流出
