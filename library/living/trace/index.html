#root .hd 实时状态行
顶行不是标题，是当前在做的事：Working on it → 每一步开始时换成该步文字（220ms 去模糊淡入）→ 结束时换成「Ran N searches and read M sources」+ 来源图标叠片。图标橙色，表示还活着。
#kids 竖线
子步骤缩进 21px，左侧 1px 线从顶行图标正下方起，一直挂到最后一张卡片下面。
keepOpen = 2 展开窗口
新卡展开的同一帧，倒数第三张收起，最多同时开两张。高度用 grid-template-rows 0fr → 1fr，340ms，cubic-bezier(.2,.8,.2,1)；收和开同时进行，所以总高度大致不跳。
.card 结果卡
比舞台亮一档的灰（#F5 对 #ED），圆角 11，1px 4% 描边 + 一层很浅的投影；行与行之间是白色分隔线而不是灰线。前导位放未读点 / 字母头像 / 来源图标 / PR 与工单状态。超出三条显示「+N more」。
.chip 来源标签
3.5% 黑底、圆角 6、图标 12px + 500 字重名字。正文里同一个 chip 缩小一号，夹在句末当引用。
#answer 逐词流出
步骤全部跑完先把所有卡片收起，再让答案按词出现（每词 180ms 淡入，整段 1.4s 内均匀流完）。答案写完后，整串步骤收成一行摘要，摘要文字从 5px 模糊淡入。
