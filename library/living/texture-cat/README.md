# 横线取样的黑白主视觉

来源：https://x.com/amananimates/status/2113508952524910707（@amananimates）
相关页面：https://www.scrolltide.co/templates/mitten
复刻日期：2026-11-05；2026-11-05 返工：主体改用原作画面

## 机制

- 原版模板页写明是 WebGL 着色器把一段循环视频变成横线、方块和淡光晕，每秒 12 帧。提示词要付费，这里没有看。
- 页面默认播放的主体是原作预览视频的逐帧截图：9.6 秒、115 帧，在 ego-browser 里暂停逐帧截取，存在 `source-assets/frames/`。
- `?mode=sampler` 跑反推的取样代码（Canvas 2D）：把帧模糊后每 6px 取一行、每 4px 取一个样，比阈值暗就画 3px 线，极暗就并成实心块。这个模式的线条比原作硬，也没有光晕，用来学方法，不用来比像。
- 标题是逐格量出的 5 格高方块字，用 SVG 矩形画。

## 可学

只用横线粗细就能表现明暗；把帧率压到 12 比流畅的动画更有采样感；页面其他部分零圆角、等宽字，和取样画面同一个语气。

## 不学

不要把这些帧发布出去，也不要用付费提示词。要公开使用时必须换自己的视频，走 `sample()`。
