# 剪报字母生成器

来源：https://x.com/ellyedita/status/2102141812081062351（@ellyedita）
相关页面：https://www.nandomp4.com/letras
复刻日期：2026-11-05

## 机制

- 窗口外观是 XP.css（MIT 授权，复制到本目录的 xp.css），布局数值取自原站样式。
- 每个字符是一张 500×500 的透明图，纸片只占中间一部分，所以字距默认 -60px 才贴得上。
- 每张随机旋转 ±8°、位移 ±10px。
- 动画按固定间隔（默认 200ms）换纸片和抖动，三种模式：Caos、Stop Motion、Pisca-Pisca；Desync 让约 60% 的字母跳过一帧。
- 按非透明范围用 clip-path 裁命中区，叠在一起的字母才能单独拖动。
- 原站的纸片是杂志扫描图，这里用 Canvas 现场画：不规则四边形纸片、字体、纸纹、印刷斑点。

## 可学

负字距加随机姿态就能得到剪报感；定格动画只需要低帧率换图；透明图要单独裁命中区。

## 不学

不要拿原站的杂志扫描图；导出按钮的提示音、捐赠窗口和视频里的虚拟形象都没有收。

## 和原版的差距

窗口、控件和布局与原站几乎重合（用的是同一份 XP.css）；差距在纸片：原版是真杂志扫描，这里是 Canvas 绘制，纸纹和字形没那么杂、没有印刷残缺。没收手形光标、捐赠窗口、提示音和视频里的虚拟形象；片头 COLAGEM 的字形和原版不同。
