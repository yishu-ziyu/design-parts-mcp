# asciimmo — 整个世界用彩色等宽字画出来的小型 MMO：草、水、倒影、队友、陌生玩家、法术，全是 canvas 上逐格 fillText

来源：https://x.com/Ekimko/status/2111347724071088497 （Dmitrii Eeeekimov @Ekimko，2026-10-17，俄语转述帖，带 4 段竖屏视频：720×1280 30.5 s、480×852 60.2 s、720×1280 55.1 s、320×320 67.7 s）。帖子原文末尾写 "Via:"，展开俄语原文后链接是 https://tiktok.com/@Ansenjeo ，所以原作者是 TikTok 上的 @Ansenjeo，视频是他的系列「Making the ASCII MMORPG of my dreams」（片段标题：Water reflection test / Boss fight 2nd attempt / Spell test）。没找到可玩的线上地址、源码或作者讲做法的文字；TikTok 主页这次没打开看。回复里 Cheng Lou 问过非等宽字版本、有人说 WebGL 滤镜也能做，都不是作者本人的说明。下面的数字都是把 X 上的视频逐帧画进 canvas、截图后读像素得来的。是 canvas 2D 还是 WebGL、地图怎么存、多人是不是真的联网，都看不出来，是推断。

## 怎么做的

- 一块全屏 canvas，每帧按相机位置算出可见格子，每格决定一个字和一个颜色。颜色都登记成调色板下标，同色的字放进一个桶，一个桶只设一次 `fillStyle` 再连续 `fillText`。
- 地图是固定种子的格子数组：每格存类型（草 / 水 / 塘边 / 路 / 树冠 / 树干 / 石 / 花）、静态字和颜色。草的疏密和明暗来自值噪声；树按抖动网格放，三角形树冠用 `Q @ 0 O o 8 d`，左亮右暗。
- 草叶单独一组桶，用大 1.3 倍的字号画、底边对齐格子，所以每根叶子会伸进上一行；每格位置按固定哈希错开一点，打散格子对齐。
- 风：两条正弦叠成一条斜带，扫过的草叶改成 `/` 并提亮一到两级，往绿薄荷色靠。
- 倒影：每个水格以所在塘的上沿为轴取镜像格，把那格的字镜像（`/`↔`\`、`'`↔`,`），颜色往底色压两次，加一格以内的横向抖动；离岸越远越稀。站在塘边的角色也按同一条轴画一份镜像。
- 角色：5×11 的亮度表 + 披风列 + 法杖列，两帧走路动画，左右翻转。队友沿你走过的轨迹（每 0.5 格记一个点）隔 26 个点跟随；陌生玩家在本地挑可走的目的地闲逛，停一会儿，6–15 s 放一次技能。
- 法术：一圈按 0.58 椭圆比例展开的符号环、16 个火花往外上飘、脚下白色 `( _ - )` 法阵、技能名在左上方用技能色飘起。施法扣蓝，蓝每秒回 2%。

## 关键判断

1. **字太大，看起来像终端而不是世界。** 第一版用 11px，对比原作的竖屏截图，原作的草几乎是一片纹理，我的是一格格能数清的字。改成 9px 粗体、角色从 8 行加高到 11 行，再并排看，草地成了纹理，角色和原作在画面里的占比接近。
2. **草发灰。** 9px 的细斜线在深底上抗锯齿后整体偏灰，缩小对比时更明显。把草的亮端往饱和绿推、改粗体，同时把风带从约 35% 的格子收窄到约 10%，因为原先亮带往白里混，一大片草被洗成灰色。并排截图里草回到绿色。
3. **草成了斜线阴影。** 叶片放大后，相邻行的 `/` 首尾相接，连成一条条长斜线，像铅笔排线不像草。给每格加固定的位置抖动（横 ±0.4 格、竖 ±0.3 格，取整到像素）并用一层低频噪声做暗块，再并排看，草成了一根根方向不一的叶片，和原作 Boss 战片段的草地最接近。

## 差距

- 草：原作更偏青灰、更密、暗处更多；我的偏绿，叶片之间空隙多一点。原作是不是字号大于行高，是从画面推断的，没看到代码。
- 原作角色是很细的灰阶小人（像 3D 模型转出来的），我的是手写的亮度表，轮廓更硬。
- 没做 Boss、伤害数字、聊天、真联网；陌生玩家只是本地模拟。
- 帧耗时：headless Chromium 软件渲染下 1100×700 约 20–28 ms，正常有 GPU 的 Chrome 会低很多，但没有在真机上量过。

## API / CONFIG

```js
const world = createAsciiWorld(container, {
  fontPx: 9, fontPxNarrow: 8, weight: 700,   // 字号决定格子大小
  bladeScale: 1.3,                            // 草叶字号相对格高
  bg: [12, 12, 22], seed: 7, world: { w: 240, h: 170 },
  speed: 82,                                  // 像素/秒，横竖按格子比例换算
  hero: { name, lv, gold, hp, mp, cape: [r, g, b] },
  party: [{ name, lv, hp, mp, cape }],        // 跟随你的队友
  strangers: [{ name, cape }],                // 本地模拟的其他玩家
  spells: [{ name, color: [r, g, b], glyphs }],
  hint, hintTouch, partyTab,
});
world.cast(); world.walkTo(x, y); world.pause(); world.resume(); world.state; world.destroy();
```

容器里需要一个 `canvas`、`#party`、`#hud`、`#hint`。操作：WASD / 方向键走，空格施法；点地面走过去，点自己施法。`prefers-reduced-motion` 下风停、萤火不动、陌生玩家原地站、相机不缓动、法术环不展开。
