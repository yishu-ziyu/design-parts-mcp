#ascii
整张画面是一块 canvas 上逐格 fillText 的等宽字。格子 = 字宽（measureText 取整）× 字号 × 1.12；桌面 11px，窄屏 9px。每帧把可见格子按颜色分桶，一个颜色只设一次 fillStyle，约 1 万个字一帧 3–6 ms。底色 #0C0C16，空格子就是夜色。
#world
世界是一张固定种子的格子地图：草（| / ' , 四种叶片，值噪声定疏密和明暗；叶片字号 = 格高 × 1.3，伸进上一行，每格按哈希错开 ±0.4 格，不然会连成斜排线；一条斜向正弦带当作风，扫过的叶片变成 / 并提亮）、水（暗底上稀疏的 - = . 缓慢横移）、塘边（按法线角度选 ( ) / \ _ -）、石路（= : 灰）、树（三角形 Q @ 0 O o 8，左亮右暗）。水面每格取「以塘上沿为轴」的镜像格，叶片字也镜像（/↔\），压暗 55% 再加一点横向抖动，就是倒影。
#party
组队面板：黑底 #070707、1.5px 浅灰边、2px 圆角，三张卡上下叠、间隔 3px，下面一个 party 小标签。血条和蓝条是带 1px 边框的细框，里面用 repeating-linear-gradient 画 2px 亮 1px 暗的竖纹，看起来像一排 |。施法扣蓝，随时间回。
#hud
右上角实测帧率和每帧绘制耗时（FPS · frame ms），淡灰绿 #B4BBB4。数字每 0.5 s 更新一次，是真的量出来的，不是摆设。
#hint
操作：WASD / 方向键走，空格施法；点地面走过去，点自己施法（手机同理）。两个队友沿着你走过的轨迹跟随；另外几个陌生玩家在本地模拟，自己挑目的地闲逛，偶尔放技能。施法是一圈按椭圆展开的符号环，脚下一个白色 ( _ ) 法阵，技能名用技能色飘在左上。
