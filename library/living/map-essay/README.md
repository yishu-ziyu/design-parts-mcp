# map-essay — 博尔赫斯地图短片的版式节奏

含原作素材，只留本机。

来源：@julianleiss的视频随笔，改编自博尔赫斯《Del rigor en la ciencia》，https://x.com/julianleiss/status/2116294919488716958 ，2026-10-30。复刻于 2026-11-05，依据是帖子视频（57.75 秒）。

## 机制

- 全片是一张竖版纸面，没有转场，只有硬切。每 0.75 秒左右换一拍。
- 扉页分块跳出来，先是小字，再是标题，最后是整页。
- 主体只有两种字：极小的打字机正文和撑满版心的衬线大词（I I I、SOL、INÚTIL、INVIERNOS），大词压在文献上一拍就走。
- 地图从局部放大、比例尺、切片、等高线一路堆到铺满，再被黑方块一格格盖掉，呼应故事里地图的毁灭。
- 全黑反相只有一拍，文献隐约透出来。
- 结尾打字机逐字打出，文本变长时整段往上走。

## 可学

- 字号落差比颜色更有力：6px 的正文和 345px 的 I 同屏。
- 大面积留白让任何一个新出现的东西都是事件。
- 黑白灰加上一个红点，够了。

## 不学

- 正文小到读不了，这在视频里是纹理，放进网页就是可访问性问题。
- 完全依赖时间线推进，读者不能按自己的节奏看。

## 素材和实现

纸面文字用 Courier Prime 和 EB Garamond 重排。地图、版画和黑方块那些帧（51 张）是帖子视频的截图，按 0.75 秒一拍逐帧播放，所以原片比这更细的切换会丢失。空格暂停，方向键单步，点击暂停。减弱动效时不自动播放，点击一次走一拍。
