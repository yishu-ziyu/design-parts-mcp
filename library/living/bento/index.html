可拆

#camera
一个 overflow:hidden 视口对 2400×1900 大画布做 translate+scale（transform-origin 0 0），transition:transform 1800ms cubic-bezier(0.65,0,0.35,1)。焦点矩形→变换由 JS 算：s=min(vw/fw,vh/fh)，居中补偿。循环：宽景 1.5s → A 停 5.5s → B 停 6.5s → 回 A，整圈 ≈15.6s。
#builder
卡内微动效与镜头解耦：镜头到达才挂 .play，离开即摘。光标是一段 cursorWalk 5.5s 的 transform 关键帧，两个节点用 glowA/glowC 在对应百分比点亮/熄灭——同一时长各管各的百分比，不用 JS 逐帧。
#chat
打字用 JS 逐字追加（26ms/字）+ CSS blink 光标；绿点 toast 和回复卡都是 transform+opacity 350/450ms 滑入，不单靠 fade。离开焦点即复位，回来重播。
#chart
SVG stroke-dasharray=总长，rAF 2.2s 推 dashoffset 到 0；红点用 getPointAtLength 沿线走，tooltip 两行数值跟点，横条 width 900ms 长出来。reduced-motion 下全部直达终态。
