# lasso — 圈一块，镜头跟过去

来源：[x.com/OhansEmmanuel/status/2096996689680978148](https://x.com/OhansEmmanuel/status/2096996689680978148)，2026-09-07。原帖是 PR Lens 的 18.8s 走查，1046×720、60fps。本页收圈选和运镜：圆角框圈住一块，其余变淡，镜头平移过去。不收他们的架构图和 PR 壳。画布换成写 / 核对 / 发布。

打开 [index.html](index.html)。

## 机制逐条

- **画布 `#world`**：1080×640，点阵 18px，底 `#f7f7f8`。三栏 WRITE / REVIEW / LIVE。
- **圈选 `#lasso`**：圆角 20px，描边 1.5px。白影 `120vmax`、透明度 .62，盖住框外。和镜头同一条 820ms 缓动。
- **镜头 `#view`**：`translate + scale`，原点 0 0。走查时焦点偏在左边目录右侧。
- **目录 `#narrator`**：四步。当前黑，其余淡。点一步，手指过去，蓝圈闪一下。
- **蓝圈 `#ring`**：46px，`#2f6dff`，520ms 放大淡出。

## 可学 / 收窄 / 启示

- **可学**：先圈再运镜。周围变淡，被圈的那块才站出来。目录同时只亮一行。
- **收窄**：标本只收圈选和运镜。整卡巡游走 [bento](../bento/index.html)。
- **启示**：没有框，镜头只是在挪。框先告诉眼睛看哪，镜头才有东西可跟。
