# pattern-generator

含原作素材，只留本机。默认构图是按原帖视频关键帧的网格取样得到的 `data.js`，不公开、不推送。

来源：Tirth（@madtirth）2026-10-28 发帖 https://x.com/madtirth/status/2115552223111610590 ，帖子只放了 38 秒录屏，没有公开页面。

## 机制（从录屏逐段量出，源码未公开，这些都是推断）

| 时间 | 画面 | 做法 |
|---|---|---|
| 0–7s | 浅灰底上色块岛屿长大，边缘散落淡出的小方块，叠黑色走线和节点 | 单格 18.5px；帖子关键帧按格取样；两帧之间每格在各自时刻切换 |
| 7–12s | 白底上大方格从中间逐个亮起，半色调圆点和噪声色块混合 | 大格 96px、点距 4.36px；每个大格各自跳到下一状态 |
| 12–17s | 黑底上红黄绿蓝色带，叠短曲线 | 单格 9.27px；短曲线是本页程序生成，位置和原版不同 |
| 17–27s | 五条竖向渐变、颗粒、像素热区和带拖尾的方块，然后换成蓝色色板 | 全程序绘制，色值从帧上取；颗粒是 256 噪点贴图 overlay 16% |
| 27–33s | 细格变粗像素的草地和天空 | 单格 11.58px，取样；高频区叠细网格和点 |
| 33–38s | 彩色代码标签聚拢、再滑到右下铺满行宽 | 文字逐条抄自录屏，JetBrains Mono 22.3px，标签高 31px |

点画布切到纯噪声生成（换种子），时长和分段不变。纯噪声的构图不会和原版一样。`?t=秒` 定格，`?seed=` 指定种子，`?noise` 直接用纯噪声。

## 可学

- 同一套手法换色板就是另一种情绪：第四、五段版式完全相同。
- 不同尺度的方格叠在一起时，靠白色 1px 网格线把它们统一起来。
- 硬切，不做转场，节奏靠内容生长。

## 不学

- 默认构图依赖取样数据，换内容要走纯噪声，那部分的质感比取样版弱。
- 七段全跑在 Canvas 主线程上，第二段首次预渲染有约 1 秒开销。
