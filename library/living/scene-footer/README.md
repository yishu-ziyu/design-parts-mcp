# scene-footer — 铜版画风景当页脚背景

来源：[x.com/elayadesigns/status/2101943446789673427](https://x.com/elayadesigns/status/2101943446789673427)，复刻日期 2026-11-05。原帖 7.9 秒，1044×720。

## 机制逐条

- 整幅蓝白铜版画铺满页脚，比例 1440:992，没有卡片和底板。
- 四列链接和品牌位都放在画面上方的天空留白处，靠留白保证能读。
- 画面里只有四样东西在动：船从左向右、水面波纹、云缓慢飘、树梢微动。文字完全不动。
- 文字层是真实 HTML，字号用 cqw 随容器缩放：标题 1.12cqw，链接 0.81cqw，行距 2.156cqw。
- 减少动态时隐藏视频，换成静止的第一帧。

## 素材怎么来的

用 ego-browser 按 0.1 秒一张截视频，共 79 张，用 OpenCV 修掉原字，再编码成 `source-assets/scene.mp4`（10 帧插到 24 帧）。

## 可学 / 不学

- 可学：页脚可以只是一幅慢慢动的画，链接压在天然留白上。
- 不学：直接使用这幅原作；Logo 和品牌名。
