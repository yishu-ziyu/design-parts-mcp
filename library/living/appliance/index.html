#hand
手绘质感是一个 SVG 滤镜套在整张图上：feDisplacementMap（scale 0.94，viewBox 单位）把直线推出轻微抖动；feTurbulence baseFrequency 2.29、3 octave 经色阶矩阵压到 0.84–1.14 当纸纹，再叠一层低频斑驳（0.85–1.15）做墨色不匀，都用 multiply 叠，最后 in 合成回原形状。原作的位移图和斑驳是两张预烘的 PNG，这里换成 feTurbulence 现算。
#art
等轴画法：所有部件都在“面内坐标”里画，再用一个 matrix() 贴到三个可见面上——顶面 (c,.5,-c,.5)、亮侧面 (c,-.5,0,1)、暗侧面 (c,.5,0,1)，c = cos30°。文字、旋钮、刻度跟着面一起斜，不用手算每个点。线宽 0.27–0.9 个 viewBox 单位，三面颜色 = 主色提亮 / 主色 / 主色混墨 62%。
#actions
交互是一个很小的状态机：放面包 → 压杆 → 按焦度计时烤 → 叮一声弹起（带回弹）→ 取出。面包是立在槽平面里的切片，只裁出顶面以上的部分，下沉时自然“掉进”槽里；烤色随时间从米黄插值到焦褐。
#controls
底栏三组：手绘抖动滑杆直接改位移 scale（0 = 机器直线，3 = 很抖）；五个色点换机身主色，三面颜色按规则重算；视图里 Turntable 用 scaleX(cos t) 假装转台，Front view 复位。
#stage
画板 viewBox 229.5 × 172.2（与原作同比例），右下角缩放 60–160%。See-through 把三面填色降到 35% 透明，露出槽里的加热丝和整片面包；Labels 用细引线加等宽小字标出部件，标签放在滤镜外面保证可读。
