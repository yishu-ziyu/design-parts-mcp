## 机制

- 打字时用正则识别：含糊的界面词标橙，“数字px padding”标蓝；每个高亮只在第一次出现时做波动，重绘不重复触发，光标偏移重绘后恢复。
- 字母逐个上跳 3px，错峰 18ms，背景同时淡入；高亮有内边距，所以文字位置会被推开，这是有意的。
- 含糊词和数值都出现后，抽屉从输入卡内部长高，不弹新层。
- 抽屉先问“是不是这一块”：Yes 把含糊词换成绿色的确定对象；No、箭头按钮或左右方向键换下一个猜测。
- 预览里用斜线画出内边距带，宽度随数值实时变化。
- 四边数值可横向拖动，每 3px 变 1；也能展开成 xs 到 2xl 的令牌色阶点选，消息文字同步改。
- 发送时抽屉收起，消息上移进对话，回复淡入。

## 可学

把“我理解成了什么”放在发送之前，用真实界面的局部做确认。

## 不学

猜测列表和识别词表是写死的演示数据，真实产品要接界面结构；方向键提示徽标来自录屏的按键显示，产品里不一定需要。

## 和原版的差距

版式、尺寸、字号、配色和各状态并排几乎重合。差距：原视频的镜头推拉没做；第 3、4 个猜测的名称是我补的（视频只露出前两个）；顶部第一条用户消息的前半句被裁切，是我补写的；字母波动时长和抽屉弹簧按视频估计；字体用 Inter，原版可能是相近字体。

## 素材处理

自绘小面板，文案沿用原帖；没有品牌素材。
