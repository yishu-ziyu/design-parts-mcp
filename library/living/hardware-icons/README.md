# 硬件拟物图标组

来源：https://x.com/abduzeedo/status/2113044699762290913（@abduzeedo（作品：Lu Yan、Zhiyi Zhang，Rams System Icons））
相关页面：https://abduzeedo.com/lu-yan-crafts-dieter-rams-inspired-system-icon-design
复刻日期：2026-11-05

## 机制

- 原作是 3D 渲染的静态图，这里用 SVG 基本形状和渐变重画了 19 个图标和一张相机放大图。
- 外壳分三层：外沿亮到暗的渐变、内缩 4px 的深色细线、细噪声纹理。
- 橙色是唯一的强调色，只用在旋钮和侧边按键。
- 厚度靠径向渐变加两层柔和投影。
- 液晶数字用多边形拼七段，音响孔用规则方点阵。
- 原作的品牌字样换成占位字 HAUS。

## 可学

一种浅灰外壳加一种橙色就能把十几个不同的东西统一成一套；统一的细线和字样位置比形状更能让它们成组。

## 不学

不收原品牌字样；原作是静态图，所以这里没有加交互和动效，SVG 也做不出 3D 渲染的真实光影。

## 和原版的差距

版式、每个图标的位置和尺寸、配色都接近。差距在材质：原作是 3D 渲染，这里是 SVG，光影更平，浮雕、镜片和风扇的层次明显少；品牌字样按规定换成 HAUS，字形不同。只复刻了帖子 3 张图中的前 2 张的版式。
