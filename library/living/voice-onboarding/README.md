# 语音问卷引导

来源：https://x.com/julesforrest/status/2104278316618244179（@julesforrest，2026-09-27）

复刻页：`index.html`。并排核对图：`原料/x-收藏/originals/2104278316618244179/compare.jpg`。

## 机制

- 灵感来自密码校验：要求项随输入逐条满足。
- 新词先浅后深，关键词说完才上底色，最多留三行，旧行上移。
- 当前要求项圆环随进度走，值在关键词命中时写入；答完打勾，变主题色，堆到上方。
- 已完成项在顶部渐隐，只留最近几项。
- 换题时卡片颜色 500ms 过渡，文字模糊淡入。
- 结束后是汇总表，点任一行开底部抽屉改值。

## 可学

把“还差什么”放在说话的同时显示，用户不用记问题；关键词高亮证明系统听懂了。

## 不学

数值推断（“我、伴侣和儿子”得到 2 adults, 1 kid）是写死的，真实版要接语音和模型；全程没有错误纠正，只能在汇总页改。

## 和原版的差距

手机、问题卡、列表、汇总表、底部抽屉并排几乎重合，取色来自原视频逐题采样。差距：没有接真实语音，转写是脚本播放；我只按 6 秒一帧看了视频，部分转写句子是按画面补全的；衬线字体用 EB Garamond，非常接近但可能不是原字体；“Al Dente”换成占位的 Pantry；波形和状态栏图标是自绘。

## 素材处理

手机外壳和图标自绘；转写里的 NYT Cooking 等只是原帖的示例文字，没有使用标志。
