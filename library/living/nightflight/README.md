# nightflight — 夜航 · 深夜观测工作台（可见相机穿行，自定美学版）

来源：机制源自 [flycam](../flycam/index.html)（可见相机 rig + 真透视穿行 + 双向时间轴 + reduced-motion，已验收）。**本页不是复刻**：相机、时间轴、同步方式原样沿用，世界、色板、内容、字体角色全部重做，不绑定任何用户项目。

调性一句话：一台仪器在深夜的观测台里缓缓飞过别人的工作台面——暖纸、黄铜、月色压在深夜蓝上。

## 世界设定

深夜天文观测者的工作台。三个层次：**深夜**（底）、**暖纸**（物）、**黄铜**（细节）。左窗格是这台仪器的编辑视图（更暗的 `#0C121E`，墙上一排夜间摄影小照片），右窗格是它看见的夜空（`#101827` 渐变 + 极淡星尘）。纸卡在深底上发光，红绳只有一根。

## 色板与字体角色

| 角色 | 值 | 用在哪 |
|------|-----|--------|
| 夜底 | `#101827` | 右窗格底色（上更深）、星图卡/终卡卡面 |
| 夜底（暗） | `#0C121E` | 左墙面、窗口条、时间轴、装订底色 |
| 纸 | `#F2E9D8` / 暗面 `#E7DCC6` | 手记卡、月相卡；纸感 = 色调差 + 1px 描边，不靠阴影堆 |
| 墨 | `#1B2333` | 纸上文字、月相阴面、纸的描边 |
| 黄铜 | `#C99A3C` | 图钉、长尾夹、角件、刻度、进度条、细节描边 |
| 月色 | `#F7F3EA` | 纸上高光、星点、星轨弧、播放头、终卡正文 |
| 仪器黄 | `#FFD84D` | 仅左窗格：视锥线框、航线、路径点 |
| 红线 | `#C84B3B` | 全页只一根红绳（手记卡 ↔ 月相卡），别处不出现红 |

字体只有两个角色，不混：

- **纸的角色**（标题、手写字感）：`Georgia, "Noto Serif SC", "Songti SC", serif` —— 手记卡标题、逐字打出的天况、星轨片的「30 分钟长曝」、终卡大字。
- **机器的角色**（仪器标签、时间码、坐标）：`"SF Mono", ui-monospace, Menlo, monospace` —— 窗格标签、`LUNAR PHASE / WAXING GIBBOUS`、`ORION · 21:40`、路径点站号、时间码。
- 正文小字可用系统 sans；中文标点全角。

## 与 flycam 的复用 / 改写点

沿用（结构与手法一行未改）：`render(t)` 单函数驱动两窗格 + 时间轴；世界坐标 + 相机插值；左窗格 SVG 斜投影与防跳变手法；时间轴（菱形刻度点跳、拖拽 scrub）；播完停末帧 + 重播；`?demo=progress=X` 定帧；reduced-motion 分支；每帧重取窗格尺寸（红绳与 CSS 3D 中心对齐）。

改写（本页差异）：

- 世界：求职物件墙 → 深夜观星工作台；站位、航线、段节奏全部重算（6 个相机控制点 = 起点 + 五站，5 段；**路径点只有五站这 5 枚**，标号 01–05，起点只作虚线航线端点，不占点）。
- 色板：整体替换为夜蓝 / 暖纸 / 黄铜 / 月色。
- 字体角色：纸卡衬线 + 仪器 mono 两角色明确分工。
- 新增：月相双圆弧生成器（分界线半轴带符号 + 亮侧收口）、星点 ±0.1 脉动（仅星图卡与星尘）、银河带、红绳改二次曲线并**画在卡片之下**（被更近的纸正确遮住，不再浮空）。
- 左墙照片题材换成夜间摄影简笔，只用夜色/月色的 alpha 调出灰调。

## 可学之处

- 同一台相机能换一整个世界：只要站位和内容重做，`#rig / #flight / #timeline` 三件套一行不用动。
- 逐字打字的窗口可以落在「卡片正掠过镜头」的时段：字在纸上写，纸在飞——比停在原地打字更有夜航味。
- 月相这类图形用带符号的分界线半轴 + 亮侧收口就能一套参数画完八相，不必八个手绘图（见 lessons：sweep flag 的坑）。
- 红绳要画在卡片**之下**：投影正确但被更近的纸遮住才是「一根绳」，画在卡片之上必然出现浮空线段。

## 不学之处

- 不照搬 flycam 的求职内容，也不照搬其巴黎源片任何词。
- 不用位图假照片：左墙 9 张与 5 站全部代码绘制，零网络请求。
- 星点闪烁只给星图卡与星尘 ±0.1，别处不闪；纸卡不做多层阴影堆。

## 启示

- 叙事运镜的关键帧是「站位」不是「画面」：先把五站的观看距离（约 170–250 世界单位）定下来，卡的大小与掠过节奏就自然了。
- 打字、闪烁、银河这些「活的细节」全部写成 t 的纯函数，scrub 到哪都逐像素一致（同进度两次截图已比对为 0 差异）。
- 色板纪律可以先写死成常量再写页面：本页 9 个 hex 全覆盖，色板外一个都不出现。

## 可拆

机制同 flycam，零件沿用 `#rig` / `#flight` / `#timeline`（页尾「可拆」芯片同）。本页可单独拆走的差异件：月相生成器、星点脉动、银河带、红绳（二次曲线 + 下层遮挡）。要换世界改 `WPTS / SEGS / CARDS` 三个数组即可。
