#reel
键帽场渲染：36×22 个圆角键帽，每帧按深度从远到近画。每个键先画朝向相机的侧面，再画圆角顶面。远处按深度混向底色当作景深雾，上下两条再叠一层模糊副本当移轴景深。高度场 heightAt(i, j, t) 是每一幕唯一要写的东西。
#scrub
整片只认一张时间表 CONFIG.scenes。画面、文字、声音都从同一个 t 算出来，所以拖动进度条能停在任意一帧，声音事件也读同一批时间点。
#play
相机：关键帧之间用 E.cam（0.48, 0.1, 0, 0.9）插值，慢起、约 27% 处最快、长收尾。只有相机两头都缓，入场用 E.outSoft，出场用 E.exit。
#sound
声音全在代码里合成：键落是 2.4 kHz 高通噪声 + 180 Hz 正弦，6–60 ms；相机甩动是带通噪声扫频；文字落定一声 880 Hz 软音。一行字只配一声，不是每个词一声。
#controls
工厂接口 createLaunchReel(el, options) 返回 { play, pause, seek, setSound, destroy, duration }。减少动态效果时不自动播放，停在第二幕落定的那一帧。
