# launchreel — 一片白色键帽当舞台，蓝键升起拼出轨迹和字形，短句从遮罩里升上来，声音全部用代码合成

## 来源

原帖：https://x.com/LexnLin/status/2111618614444892331 （Leon Lin，2026-10-18，"Cinetic v1.1 is here!"）。帖子里的 30 秒视频是用他的 skill Cinetic 做的，仓库 github.com/Leonxlnx/cinetic。

找到的（事实）：

- 帖子原话：v1.1 的改动是文字元素更短、默认节奏更慢（calm），每个声音都用他的另一个工具 earshot 在代码里做出来。
- 仓库是一个给 agent 用的 skill：`skills/cinetic/references/*.md` 是方法文档，`assets/remotion-starter` 和 `assets/hyperframes-starter` 是两套起步工程。缓动、弹簧、节奏都写在 `src/lib/anim.ts`，本页用的缓动曲线（`E.out` `E.outSoft` `E.exit` `E.cam` `E.glide` `E.smooth`）和 detent 弹簧参数直接取自那里。
- 时间表的做法取自 `hyperframes-starter/timeline.js`：所有时间点写成 60 fps、120 BPM 网格上的帧号，画面和声音都读同一份 cue。
- 视频画面（从帖子视频抽帧看到的）：白色圆角键帽铺满地面，低机位透视；蓝色键帽沿对角线升起成一条轨迹（1 s）；相机甩动带运动模糊（3.5 s）；蓝键拼出像素数字 "1.1"，左下是黑色产品名（6 s）；近乎俯拍，一颗黑键旁边有一条空槽，两个词一黑一蓝（8.5 s）。

没找到 / 推断：

- 视频本身的工程文件没有公开，各镜头的具体关键帧、键帽尺寸、相机参数都是我从抽帧里估的。
- 原片大概率是 3D 渲染（有景深和真实阴影）。这里用 Canvas 2D 自己做透视投影加画家算法，景深用"远处混向底色"代替，属于近似。
- `hitPulse` 的确切公式没读到，这里自己写了一个"快速上升 + 指数衰减"的包络。
- 视频只抽到 0–9 s 的帧（浏览器只缓冲到 9 s），后面的镜头是按同一套语言自己编的。

## 怎么做的

1. `CONFIG.scenes` 是唯一的时间表：五幕，每幕有起止时间、一种高度场（trail / glyph / press / ripple / lockup）和一行字。
2. 每帧对 36×22 个键算 `heightAt(i, j, t)`，得到高度和颜色（白、蓝、黑）。
3. 相机在 `CONFIG.camera` 的关键帧之间用 `E.cam` 插值（目标点、偏航、俯仰、滚转、距离）。自己写的透视投影把键帽的 8 个角投到屏幕上。
4. 先画抬起键的接触阴影，再按深度从远到近画键：朝向相机的侧面（按世界坐标里相机在哪一侧判断），再画圆角顶面。远处按深度混向底色。
5. 文字是 DOM：每个词放在 `overflow: hidden` 的遮罩里，从 112% 升到 0。第三幕的字锚在黑键的屏幕投影右侧，相机动它就跟着动。
6. 声音事件从同一张表推出来：键落、重击、相机甩动、一行字落定。点 Sound 后才建 AudioContext，按当前时间把后面的事件一次排进 WebAudio。

## 关键判断

1. **侧面可见性判断错了，黑键画成了旗子形。** 一开始用屏幕空间叉积判断侧面朝向，俯拍时符号反了。改成在世界坐标里比较"相机位置 - 面中心"与面法线的点积。对比 8.5 s 的截图，黑键恢复成方块。
2. **第一幕的轨迹方向和原片相反，而且 1 s 时只升了一颗。** 原片 1 s 时轨迹已经铺满对角线、往左上远处退。把偏航改到 118°，轨迹头部在 1.9 s 内用 `E.out` 跑完，并改成"低的蓝色轨道 + 每三格一根高柱"。对比 1 s 截图，方向和密度对上了。
3. **雾按绝对深度算，相机一拉远整片就白了。** 改成按相机距离的比例（0.8×–2.4×）算雾，第四、五幕的键重新可见。
4. **字形键整根涂蓝，比原片重。** 原片 6 s 的数字是蓝色顶面、白色键身。加了一套 capped 配色（蓝顶 + 灰白侧面），高度从 1.5 降到 1.25 个键宽，再对比 6 s 截图，轻重接近了。

## 和原作的差距

- 没有真正的景深模糊和运动模糊。原片 3.5 s 的甩镜有很重的模糊，这里只是快速插值。
- 键帽只有平面侧面和圆角顶面，没有原片那种柔和的环境光遮蔽和顶面倒角高光。
- 原片第二幕的数字旁有一根倒下的长条键，这里没做。
- 声音是我按 sound.md 里的事件种类自己合成的，没有听到原片声音，不是 earshot 的音色。
- 0–9 s 以后的原片镜头没有抽到，后两幕是自己编的。

## 接入

```html
<div id="reel" class="reel"></div>
<script>
  const reel = createLaunchReel(document.getElementById('reel'), { loop: false });
  reel.setSound(true);   // 需要在用户点击里调用
  reel.seek(6.9);        // 停在任意时间点
  reel.destroy();
</script>
```

返回 `{ play, pause, seek(t), setSound(on), time, playing, duration, onTick(fn), destroy }`。

`CONFIG` 里能改的：`grid`（列数、行数、键大小、圆角、底高）、`colors`（白 / 蓝 / 黑三套顶面和侧面色、阴影）、`fog`、`scenes`（每幕的种类、起止、字形、文字和强调词下标、文字位置 bl / tl / anchor / center、字号角色）、`camera`（关键帧）、`type`（1080p 下的字号）、`duration`、`posterTime`（减少动态效果时停的帧）、`loop`。

file:// 直开，运行时零网络，字体用系统无衬线。
