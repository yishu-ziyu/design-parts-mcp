# Controller Explore

含原作素材，只留本机。

来源：The Bugged Dev（@thebuggeddev）https://x.com/thebuggeddev/status/2092808398391902341 ，公开代码 github.com/thebuggeddev/controller（线上 controller-gules.vercel.app 2026-11-05 查看时已暂停）。

## 机制
- 版式 token 按 1600×1000 画布算，全部用 clamp 和 vw；CSS 直接来自原仓库。
- 三款手柄换款时，整页颜色、背景光晕、标题、右侧卡片和规格一起切换。
- 右侧只放“没在看”的两款：领先卡宽 1 倍高 1.316 倍，后一张宽 .786 倍高 1.113 倍，间距 .133 倍。
- 标题逐行离场：上移 42%，.3 秒，错峰 30 毫秒；再从 62% 处升起，.72 秒，错峰 50 毫秒。
- 水平拖动转手柄：这里用视频帧逐帧切换（18、18、10 帧），松手 .6 秒回正面。原版是 three.js 实时渲染 glb。

## 和原版的区别
- 原版 Archivo 字体本机没有，标题用 Inter 760。
- 品牌名和 Logo 换成占位（XS、Gilt、Glacier、Lord of War）；手柄上的小标志是截图自带的。
- 手柄和背景来自视频帧，分辨率和压缩痕迹也跟着带来；拖动只能在视频里录到的角度之间切。

## 可学
- 只留一个 clamp 体系，不同屏幕比例不变。
- 右侧卡片只放下一步的选择，不重复当前商品。

## 不学
- 用帧序列代替 3D 只能应付固定角度，真要转动要用模型。
