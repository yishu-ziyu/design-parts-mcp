# physics-notes

含原作素材，只留本机。开头的笔记页和中段的插图、课页是从原帖视频截的，不公开、不推送。

来源：Nathan（@nathan_liow）2026-10-29 发帖 https://x.com/nathan_liow/status/2115872171226718427 ，一个物理交互教科书的 33.6 秒宣传片。帖子外链 atlas-of-physics.vercel.app，现在跳到 atlasclass.app（已改名并收费），页面和视频里的不完全一样，所以本页按视频做。视频里的字体从现站读到是 EB Garamond、JetBrains Mono、Inter。

## 机制（从视频每 0.25 秒一帧看到）

| 时间 | 画面 |
|---|---|
| 0–3.4s | 174 页笔记平铺，压一张说明卡 |
| 3.4–7s | 红色手绘圆环上叠出会动的三维圆环，文字逐词淡入 |
| 7–10s | 同一个圆环在课页里，再缩进右侧插图卡；矢量每帧重算 |
| 10–21.5s | 版式不变，插图和编号约每 0.5 到 1.5 秒换一次：抛体、逃逸、势能曲线、振动、旋转、伯努利、磁场、带电粒子、偶极子、基尔霍夫、感应、LC 振荡 |
| 21.5–24.25s | 课页跨页，点开某个量后左页换成说明，右页推近并暂停 |
| 24.25–26s | 滚动翻页 |
| 26–28.4s | 练习题，选项选中后变绿 |
| 28.4–33.6s | 首页目录，片尾标题 |

## 可学

- 插图卡的四角信息固定：编号、一句话、操作提示、实时读数。换图不换框。
- 大字衬线标题配等宽小字，页面不靠颜色也有层次。
- 红色只留给力和加速度，不做装饰。
- 用同一个对象把“旧笔记”和“新产品”接起来：红圈上直接长出三维圆环。

## 不学

- 三维插图的线和底色都很淡，投影时可能看不清。

## 和原版的取舍

- 0–10 秒的说明卡、红圈和圆环，28.4 秒之后的首页，都是本页实时绘制；说明页和练习页的左页文字也是实时的。
- 10–21.5 秒的白卡内容、21.5–22.75 和 24.25–26 秒的跨页、说明页和练习页的右页，都是原帖截帧，每 0.25 秒一张逐帧播放，比原版的连续运动卡顿。
- 原版是可拖动的真三维，本页不能转动也不能点开。
- 产品名换成 Physics Notes，网址换成占位。

`?t=秒` 定格。
