# Design parts index

设计零件库的检索入口。每条笔记是 `living/<name>/index.html`，一个能打开的活笔记。

发明表回答「这页是什么」。零件表回答「我要做这一块，打开哪一页的哪一处」。
打开 HTML 看正在转的。不要只抄表。
